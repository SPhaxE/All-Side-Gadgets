### 引擎要点

- **参数化 G2 身体**：小橙由「曲率半径随法向角的分布 ρ(θ)」定义——ρ 处处为正且光滑 ⇒ 处处外凸、曲率连续；去掉 ρ 的一阶谐波 ⇒ 任何参数都精确闭合；静止形还原教程几何（圆 r60 + 角 r9 + 两条 51 的边）。噼啪的五个角各自可伸缩、弯折，整体可变尖、旋转。
- **锚点**：每帧按当前参数生成稠密样本，乘以预计算的拟合矩阵得到锚点（小橙 16 个、噼啪 15 个；眼 12、嘴 20）。参数跟着特征走，锚点永远落在同一特征上（打开「显示锚点」可见）。
- **连续性**：实测小橙在所有状态下轮廓曲率都不变号（无拐点），噼啪恒为设计中的 10 次（5 凸角 + 5 凹谷）；每帧圆角守护 + 外凸角色的凸性守护（凸控制多边形 ⇒ 凸 B 样条）。
- **旋转**：整体刚体旋转，脸一起转；整圈旋转单独累加，转完无缝归零；光照方向固定在世界。
- **其他**：脸是刚体、眼睛以下眼睑为基准；填色回应指针 / 点击 / 拖拽 / 落地 / 情绪；特效带滞后；物理抛落回弹；果冻余震用 2 瓣 / 3 瓣平滑模态。
