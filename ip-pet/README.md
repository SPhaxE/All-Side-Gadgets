## Part 3 · 三只桌宠

| | 小橙 | 糯糯 | 噼啪 |
|---|---|---|---|
| 性格 | 元气、好奇 | 慢热、害羞、爱困 | 调皮、急性子 |
| 剪影 | 水滴（右上收尖） | 云朵软糕：宽、矮、平底、顶上三个鼓包 | 软五角星：尖角朝上，两条腿着地 |
| 配色 | 红 → 奶黄 | 薄荷 → 深青 | 紫 → 莓粉 |
| 脸（全部白色纯色简单形） | 胶囊眼 + ω 嘴（按原图） | 大圆眼 + 弧形笑嘴 | 竖椭圆眼 + 半月咧嘴 |
| 时间系数 T / 夸张 | 1.0 / 1.0 | 1.4 / 0.9 | 0.75 / 1.3 |
| 被戳 | 挤扁回弹 | 化成一滩，再偷看 | 五个角鼓起，生气跳起 |
| 被拎起 | 睁大眼，微拉长 | 闭眼，被拉得很长 | 开心，鼓角 |
| 开心 | 连跳两下 | 左右摇摆 | 鼓角连跳三下 |
| 入睡 | 20 s | 12 s | 35 s |

没有头顶装饰、腮红、眼睛高光；差异只来自外形、面部、填色、性格。

### 引擎要点

- **锚点即一切**：身体 14～16 个锚点、眼 10 个、嘴 20 个，全部是闭合均匀三次 B 样条（C2 ⇒ G2）。锚点由最小二乘拟合得到，参数按「弧长 ×（1 + 2·曲率）」分配，锚点自动集中到急弯处。
- **外形变化只靠锚点**：每只角色画了 7 个身体关键形（静止、压扁、拉长、左倾、右倾、融化、鼓起），所有关键形用同一组生成器参数拟合，锚点一一对应，且在设计阶段把面积对齐到静止形。运行时身体 = 静止形 + Σ 权重 ×（关键形 − 静止形）+ 每个锚点的小幅果冻抖动。没有缩放、拉伸、剪切、旋转变换。
- **脸是一个整体**：只随身体平移（加一点滞后和视线偏移），不随身体变形，眼—嘴三角区稳定。所有眼睛表情拟合后都把最低点钉回下眼睑。
- **填色会回应互动**：指针靠近时体内亮起一块跟随指针的光斑，按下更亮；点击处荡开一圈色波；拖动时色团按加速度反向晃荡，渐变轴随速度转向并提亮；落地时色团下压；开心变暖、困了变冷、出错褪灰。
- **特效有滞后**：Z、思考点、感叹号、汗滴、键帽画在舞台上的独立图层里，锚点用弹簧滞后跟随宠物头部；Z 和汗滴生成后独立飘落。每个特效出现/消失都是从同点数的小圆点过渡到字形。
- **抗锯齿**：身体用 `<mask>`（不是 `clipPath`）裁切填色，边缘是 alpha 抗锯齿；SVG 设 `shape-rendering: geometricPrecision`。
- **物理**：拖拽时宿主用弹簧跟随指针；松手后按抛出速度走抛物线，落地按冲击速度偏向压扁形并回弹，直到站稳。
- **状态机**：沿用 pet-forge state-map 的 14 个状态名和 A/B/C 语义；状态只设关键形权重、表情、冲量的目标，任意打断都平滑续接。

### pet-forge 对应

0. 拓扑清点（只有身体和脸）→ 1. 基础形象（教程即小橙设计稿；手写 SVG，没有跑 png2svg / vtracer）→ 2. 可编辑矢量（少量 B 样条锚点）→ 3. hello-idle 约定（`viewBox 0 0 200 200`、`<g id="pet">`、`--breath-period`、`--blink-min-gap` 等变量名）→ 4. 关键形 × 锚点弹簧逐动作迭代 → 5. 按 Agent 事件映射接入运行时（`UserPromptSubmit→thinking`、`PreToolUse→working-typing`、`PostToolUseFailure→error`、`PermissionRequest→notification`、`Stop→happy`）。
