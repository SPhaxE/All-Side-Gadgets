IP 复刻 · pet-forge SVG 路线

暖橙水滴和它的两个朋友

先按原教程 8 步把形象用 SVG 复刻出来；再按 pet-forge 的 SVG 路线做成桌宠，并扩展出两只性格、形态、配色都不同的伙伴。三只共用一套引擎：轮廓全是 G2 连续的 B 样条，表情与形变都靠锚点驱动，动作节奏按迪士尼 12 条动画法则来做。

Part 1 · 逐步复刻

8 步绘制

这一部分忠实还原教程本身（教程里的圆角矩形是 G1 拼接）；桌宠形态在 Part 3 里改成了 G2 曲线。悬停单张看原图，或切到「原图」整排对照。

Part 2 · pet-forge 流程

按 SVG 路线逐项落地

  1. 0 · 拓扑清点只给角色有的部件做 rig小橙：身体、双眼、ω 嘴、高光。糯糯多一根嫩芽，噼啪多一根天线。都没有四肢，动作靠身体挤压拉伸、表情和附属物的跟随。
  2. 1 · 基础形象教程 8 步 = 小橙设计稿源图是矢量教程，手写 SVG 复刻，没有跑 png2svg / vtracer。糯糯、噼啪是在同一画风下发散的新设计。
  3. 2 · 可编辑矢量G2 轮廓 + 锚点表情身体、眼、嘴、高光、腮红、特效都是闭合均匀三次 B 样条（C2 ⇒ G2）。每个表情是同点数、同起点、同绕向的一组锚点。
  4. 3 · hello-idle 基线沿用模板约定viewBox 0 0 200 200、<g id="pet">、--breath-period、--blink-min-gap 等变量名照旧，由引擎读取。
  5. 4 · 逐动作迭代14 个状态 × 3 种性格状态名取自 state-map，A 循环 / B 一次性回原姿态 / C 过渡链接。同一状态，三只的节奏、幅度、反应各不相同。
  6. 5 · 接入运行时事件 → 状态按 state-map 的 Agent 事件映射接线；宿主元素负责位移和物理，SVG 只做形变表演。

三只桌宠

    附 · 动画法则

    迪士尼 12 条法则在哪里

    法则做法在哪里看
    挤压与拉伸身体锚点按竖向系数 sy 形变，横向取 1/sy 保持面积（底部比顶部摊得更开）；空中按速度拉长，落地按冲击速度压扁。甩出去落地、被戳、跳
    预备动作跳、醒、旋转、打哈欠之前先反向下蹲或收缩，时长随性格缩放。连点 3 下、PermissionRequest、叫醒
    演出布局换角色时从空中落下亮相；舞台上只有一只；特效放在头部右上，不挡脸。点角色卡
    连续动作与关键姿势状态只给关键姿势（目标锚点），中间帧由弹簧逐帧求解；拖拽和下落是逐帧物理。打开「显示锚点」
    跟随与重叠五官相对身体晚半拍；体内色团反向晃荡；嫩芽、天线是阻尼摆，停下后还要再摆几下。拖着糯糯、噼啪左右晃
    缓入缓出所有锚点、参数都由阻尼弹簧驱动，起止速度为 0，中途被打断也从当前姿态续接。任意切换状态
    弧线视线的 x / y 弹簧刚度不同，眼睛走弧线；抛出后按抛物线飞行。指针绕着桌宠转
    次要动作体内色团持续流动、呼吸、随机眨眼、腮红渐显。静置观察
    时间节奏每只有自己的时间系数和弹簧参数：小橙 1.0、糯糯 1.4（慢、软、晃得久）、噼啪 0.75（快、硬、干脆）。对同一状态切换角色
    夸张噼啪的夸张系数 1.3，被戳会转体跳；糯糯被戳压扁到 0.72 躲起来。点击
    扎实绘图五官、高光、腮红和身体共用同一个形变场，形变时一起被压扁、倾斜，面积守恒。被戳瞬间
    吸引力三种轮廓（水滴、软糕、蛋形）、三套配色互不撞色；所有曲线 G2，没有折角。角色卡缩略图
