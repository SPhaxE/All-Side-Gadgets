IP 复刻 · pet-forge SVG 路线

暖橙水滴和它的两个朋友

先按原教程 8 步把形象用 SVG 复刻出来；再按 pet-forge 的 SVG 路线做成桌宠，并发散出两只外形、面部、配色、性格都不同的伙伴。外形与表情的每一次变化都是锚点在关键形之间过渡，没有缩放和拉伸；节奏按迪士尼 12 条动画法则来做。

Part 1 · 逐步复刻

8 步绘制

身体、眼睛按教程几何还原（教程里的圆角水滴是圆弧拼接，只有 G1）；ω 嘴按原图量取的几何构造，再用 20 个 B 样条锚点拟合。悬停单张看原图，或切到「原图」整排对照。

Part 2 · pet-forge 流程

按 SVG 路线逐项落地

  1. 0 · 拓扑清点只有身体和脸三只都只有身体轮廓、两只眼、一张嘴。没有头顶装饰、四肢、腮红，差异全部来自外形、面部、填色和性格。
  2. 1 · 基础形象教程 8 步 = 小橙设计稿源图是矢量教程，手写 SVG 复刻，没有跑 png2svg / vtracer；ω 嘴按原图量取的几何重建再拟合。糯糯、噼啪是同一画风下的新设计。
  3. 2 · 可编辑矢量少量锚点 + G2身体 14～16 个锚点、眼 10 个、嘴 20 个，全部是闭合均匀三次 B 样条（C2 ⇒ G2）；用遮罩做抗锯齿边缘。
  4. 3 · hello-idle 基线沿用模板约定viewBox 0 0 200 200、<g id="pet">、--breath-period、--blink-min-gap 等变量名照旧，由引擎读取。
  5. 4 · 逐动作迭代关键形 × 锚点弹簧每只角色画了 7 个身体关键形（静止、压扁、拉长、左倾、右倾、融化、鼓起），状态只设各关键形的权重目标，锚点由弹簧过渡。
  6. 5 · 接入运行时事件 → 状态按 state-map 的 Agent 事件映射接线；宿主元素负责位移和物理，特效在独立图层上带滞后跟随。
Part 3 · 交互验收

三只桌宠

选一只放到舞台上。指针靠近时体内会亮起一块光，点一下会从点击处荡开一圈色波（react-poke），1.5 秒内连点 3 下是 happy；拖起来甩出去，体内色团会随速度晃荡，落地压扁回弹。不理它会犯困睡着，点一下叫醒。

    附 · 动画法则

    迪士尼 12 条法则在哪里

    法则做法在哪里看
    挤压与拉伸不缩放：每只角色单独画了「压扁」「拉长」关键形（面积与静止形一致），锚点在关键形之间过渡；空中按速度偏向拉长形，落地按冲击速度偏向压扁形。甩出去落地、被戳、跳
    预备动作跳、醒、打哈欠之前先反向过渡到压扁形或拉长形，时长随性格缩放。连点 3 下、PermissionRequest、叫醒
    演出布局换角色时从空中落下亮相；舞台上只有一只；特效在头部右上方，不挡脸。点角色卡
    连续动作与关键姿势状态只给关键形权重和表情（关键姿势），中间帧由弹簧逐帧求解；拖拽和下落是逐帧物理。打开「显示锚点」
    跟随与重叠拖动时身体偏向倾斜形、上半部分滞后；整张脸比身体晚半拍；体内色团反向晃荡；特效图层带滞后跟随，粒子飘出后独立运动。拖着左右晃
    缓入缓出所有锚点和权重都由阻尼弹簧驱动，起止速度为 0，中途被打断也从当前形续接。任意切换状态
    弧线视线的 x / y 弹簧刚度不同，脸走弧线；抛出后按抛物线飞行；Z 字沿弧线飘起。指针绕着桌宠转、睡觉
    次要动作体内色团持续流动、呼吸、随机眨眼；指针光斑、点击色波。静置、靠近、点击
    时间节奏每只有自己的时间系数和弹簧参数：小橙 1.0、糯糯 1.4（慢、软、晃得久）、噼啪 0.75（快、硬、干脆）。对同一状态切换角色
    夸张噼啪被戳会把五个角鼓出来再跳；糯糯被拎起会被拉得很长，被戳会化成一滩。点击、拖动
    扎实绘图关键形保持面积；脸是一个整体，只随身体平移，眼—嘴三角区不变形；眼睛永远以下眼睑为基准。被戳瞬间、闭眼
    吸引力三种剪影（水滴、云朵软糕、软五角星）、三套配色；脸都是白色纯色简单形，所有曲线 G2。角色卡缩略图
