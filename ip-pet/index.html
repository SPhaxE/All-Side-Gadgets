Part 2 · pet-forge 流程

按 SVG 路线逐项落地

  1. 0 · 拓扑清点只给它有的部件做 rig身体（水滴）、双眼、ω 嘴、高光、投影。没有四肢、耳朵、尾巴，所以不做肢体骨骼，动作全靠身体挤压拉伸和表情。
  2. 1 · 基础形象教程 8 步 = 设计稿源图本身是矢量教程，直接手写 SVG 复刻，没有跑 png2svg / vtracer 描摹。
  3. 2 · 可编辑 SVG分层命名shadow / body / highlight / eyes / mouth 各自独立，滤镜 id 按实例加前缀，避免冲突。
  4. 3 · hello-idle 基线沿用模板约定viewBox 0 0 200 200、<g id="pet">、--breath-period、--blink-min-gap 等变量名，呼吸 + 随机眨眼。
  5. 4 · 逐动作迭代14 个状态取自 state-map 模板库，按 A 循环 / B 一次性回原姿态 / C 过渡链接三类实现。
  6. 5 · 接入运行时事件 → 状态按 state-map 的 Agent 事件映射接线；拖、戳、长时间无事件入睡都在下方舞台可试。
