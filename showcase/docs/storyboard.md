# 20 种视效演示 · 分镜与音效脚本

> 由 `tools/gen-storyboard.js` 根据 `src/timeline.js` 生成，时间码与视频一一对应（1080p / 30fps / 90s / 2700 帧）。音效阶段尚未制作，本文件是下一阶段的制作依据。

## 全局约定

- **节拍网格**：106.67 BPM、4/4。每个特效 = 8 拍 = 4.5s；全片 160 拍 = 40 小节 = 90s，**循环点正好在小节线上**。每个转场居中于特效边界（前后各 0.6s，共 1.2s），所以“下一个特效的第 1 拍”落在转场中点。
- **无缝循环**：视频第 0 帧是场景 1 的 s=0.5s（20→1 转场已结束），最后一帧后直接接回第 0 帧。音频也必须在 90s 处循环：混响尾巴要做交叉淡化（建议 1 小节），结尾的上行扫频落回开场音色。
- **转场音效**：每个转场都是对应前后特效的专属设计，音效也应沿用前后两段的声音素材（见每段“转场”一栏），不要用通用 whoosh 一把梭。
- **画面里不显示音频元素**，HUD（左下编号/名称、右下拨盘）仅作视觉识别，不需要配声。
