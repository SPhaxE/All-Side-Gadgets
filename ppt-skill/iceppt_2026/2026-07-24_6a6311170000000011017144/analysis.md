# 就是这股淡淡的精英感：模型页模板合集（017-019、052-053）

## 本篇主旨
本篇展示 SOP 式"思维模型一页纸"系列。每个模型都是"模板页 + 真实案例页"的组合，用统一的米白底、浅绿灰和深绿色调做出克制的精英感。已读的 01-03 共 3 张长图，每张都是 3 张 16:9 左右的幻灯片上下拼接，总计 9 页。笔记正文没有文字，只有标签。

## 逐页拆解
共同版式：整张图底色是淡青灰，内部是白色圆角大卡片，每页一张，页间距约 30px。每页顶部固定为"左：英文模型名大标题；右：@ICEPPT 水印 + 三位数编号"。标题下是一个圆角描边的"定义条"：加粗一句"中文名 - 一句话 slogan"，再接 2-3 行灰色小字说明。

- 版式：左约 60% 是 2x2 象限，右约 35% 是 Key Insights 时间轴。
- 象限：横轴"低价值感 ↔ 高价值感"，纵轴"专业性 ↔ 大众化"。四格各用不同淡色底：左上灰蓝紫，右上淡紫蓝，左下淡粉，右下淡灰蓝。

## 提炼出的设计规则
1. **模板页 + 案例页成对**：同一模型先给"定义 + 结构 + 怎么用"，再用一个知名品牌案例走一遍。案例页副标题格式固定为"- CASE STUDY：公司 + 结论式问句"。
2. **页头三件套固定**：左上英文大标题、右上 @ICEPPT 水印 + 三位编号、下接一个圆角描边的"定义条"（加粗 slogan + 2-3 行灰色小字）。
3. **一句话结论前置**：案例页标题下用黑圆点 + 加粗一句讲清"做了什么 → 得到什么数字"。
4. **三栏结构**：案例页常用"1 定位/2 分析/3 价值"三栏，栏头为浅灰条加大号细数字。
5. **强调只用一个色相**：深绿 + 浅绿底，高亮 = 绿柱 / 绿线 / 绿色数字 / 绿底句。其余全是灰，包括非重点的图表柱。
6. **图表去装饰**：无网格线或极淡，只留 2-3 个坐标刻度，标签 6-8px，数据线 1.5-2px。
7. **每个小图下方配一行灰底"结论小字"**，让图表自带 so-what。
8. **KPI 数字化**：关键数字用 20-30px 级的绿色大字，下面压一行灰色单位说明（如 ~45%、+210% YoY、2.3x）。
9. **编号系统**：圆圈数字（黑底白字或深绿）、字母 A/B/C（蓝圈）、超大浅灰数字 01-04 作背景，让结构一眼可扫。
10. **矩阵区分用淡底色**：象限用 4 种极淡底色，重点象限用"浅绿底 + 深绿描边"加强。
11. **信息密度很高但层级分明**：标题 > 加粗小标题 > 灰色要点 > 更浅的注释。
12. **版式留白**：卡片外边距约 30-40px，卡内边距约 20px，圆角 15-20px；栏间用细线或浅灰条而非重边框。

## 字体与字号层级
- 标题：粗黑无衬线（疑似思源黑体 / 微软雅黑 Bold 类，不确定）。英文大标题约 20-24px 视觉尺寸。
- 干系人矩阵的象限标题（Keep Satisfied 等）是衬线体，如 Times / 思源宋体 Bold 类，不确定具体字体。
- 水印 @ICEPPT 是宽字距的衬线体 / 等宽感大写字，绿色。
- 栏头数字（1. 2. 3.）和左侧标签（Definition / Scenarios）是细体大字，与粗标题形成对比。
- 层级大致为：页标题 > 定义条加粗句 > 小标题粗体 > 正文灰字 > 注释浅灰。具体 pt 值不确定。

## 出现的思维模型 / 框架
- **Competitive Positioning Map（竞争定位图）**：选两个关键维度画 2x2，找空白象限。案例：OLIPOP 占据高价值差异化位置。
- **Jobs To Be Done（JTBD）**：用户买的是"雇它完成一项任务"，拆成 8 个维度。案例：麦当劳奶昔，早餐销量提升 7 倍（1.0x → 7.0x）。
- **Scenario Planning（情景规划）**：围绕北极星方向设 4 个情景，并用"识别驱动因素→锁定关键不确定性→设计应对动作→建立预警信号"4 步使用。只有模板页，没有案例页。
- **Make or Buy Decision**：四步过滤（战略重要性 / 供应商能力 / 内部能力 / 盈亏平衡）。案例：Apple A 系列和 M1 自研芯片（"3x Higher" 性能、年节约约 $38B）。
- **Stakeholder Power/Interest Matrix（Mendelow 矩阵）**：权力 x 利益 2x2，各象限对应 Keep Satisfied / Manage Closely / Monitor / Keep Informed，并给出 15% / 80% / 1% / 4% 的资源投入建议。只有模板页。
