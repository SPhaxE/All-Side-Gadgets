## 提炼出的设计规则
1. 标题统一格式："2-4字加粗主题词：+一句含数字的结论"，约20-30pt，主题词加粗、结论常规字重；读者只读标题即得结论。
2. 每页顶部放9项章节导航条，约8-9pt灰字，当前项加黑色下划线；右上角放页码。长篇汇报用此法让人不迷路。
3. 一页只讲一个故事，通常"左图+右图+底部要点/结论"三段式；底部固定放 Insight / Key Takeaway / Conclusion 白卡，左侧加2-4pt深绿或酒红竖条。
4. 大数字法：KPI用36-40pt粗体，下方12pt中英双语标签，再下方8-9pt灰字放YoY/目标。多个KPI横排等宽，交替白/浅灰绿底。
5. 图表默认全灰，仅用1个强调色标出关键数据（瀑布图只有一根绿柱、堆叠柱只有2025用酒红框）；其余全是灰阶。
6. 图内直接标注代替图例（面积图系列名写在色块上），关键点用气泡、虚线框、箭头、批注卡解释"为什么"，批注卡左侧用红/绿竖条表正负。
7. 目标线+背景色分区（CAC图：¥200线上浅红、下浅绿），一眼看出达标与否；预警用酒红，达标用深绿。
8. 套经典框架（BCG矩阵、AARRR、K=i x c、增长公式、UE单位经济、同期群、RFM）作为页面骨架，每个象限/因子配"现状/Action/策略"。
9. 热力表用单色深浅渐变（浅绿到深绿）；敏感性表用"基准格白底描边+危险格浅红"。
10. 标签、小标题用中英双语（如"Revenue Analysis / 营收增长引擎"），增加nerdy感。
11. 卡片用圆角+轻阴影+细灰边，卡片间留白，章节小标题用灰色箭头条或"圆点+标题"。
12. 页内信息密度高，但用对齐、分栏和色彩克制维持秩序；数字用粗体、说明用浅灰小字，形成三层字号。（观察：部分页如P2左下页码块与内容重叠，是瑕疵。）

## 字体与字号层级
- 字体：无衬线中文（疑似思源黑体/微软雅黑一类）+英文无衬线，粗体数字有较重的字重；个别页英文有斜体点缀（Insight、Impacts of inflation）。具体字体不确定。
- 层级（估算）：KPI大数字 36-48pt（P2的"90%"约60pt）> 页面标题 20-26pt > 卡片标题 14-16pt > 正文/标签 10-12pt > 注释/脚注 7-9pt。

## 出现的思维模型/框架
- BCG 增长份额矩阵：电商=金牛、SaaS=明星、AI=问号、传统广告=瘦狗；同一框架在渠道效率矩阵中复用于渠道（Google Search/LinkedIn/Display/TikTok）。
- 红绿灯复盘 Key Wins / Key Loss + Solution：赢的3项、亏的2项，每个亏项配对策。
- 增长归因瀑布：6.8亿到8.5亿，按季度或驱动因素拆解，再深挖ToB（Depth）/ToC（Breadth）。
- UE（单位经济）模型：AOV-COGS-履约-CAC=边际贡献，配AOV x CAC敏感性矩阵。
- 同期群分析 + RFM策略（复购）。
- AARRR 海盗模型（A/B测试5个实验：获客/激活/留存/变现/推荐）。
- 增长公式：Revenue = Traffic x Conversion x ARPU；病毒系数 K = i x c（K>1为指数增长）。
- 流量"黄金交叉点"：免费流量超过付费流量的拐点。
- Blended CAC = 总营销花费 / 总新客数；回本周期对比。
