# 每次pre都是一次被看见的机会（咨询/金融风 PPT 版式模板合集，7 张拼图共 21 页幻灯片）

## 本篇主旨
笔记正文几乎无文字，只有标题和话题标签。内容是一套"数据可视化 PPT 模板"：用同一套骨架（面包屑、粗下划线标题、灰/绿/酒红三色、小标题编号）覆盖流程图、各类图表、表格和矩阵。重点是让每页成为"结论先行 + 一页一个核心观点"。

## 逐页拆解

- 栏小标题带编号：酒红方块白字的 1/2/3，或灰色竖块，下接细灰线。
- 图中次要元素是灰，主角是酒红，辅助是灰绿。

## 提炼出的设计规则
1. 每页只用 3 个主色：灰（背景/次要）、灰绿（积极/对比）、酒红（唯一重点）。重点元素每页只有一两处。
2. 标题写成结论句，不写话题名。页面结构为：面包屑 → 结论标题 → 粗黑线 → 编号小标题（最多 3 个）。
3. 图表的重点用酒红，其余统一灰色。例如 100% 条里只有关键段为酒红，折线图里重点线为酒红、其余灰。
4. 重点的圈示方式：红色虚线框、红椭圆、红框标签、红色箭头。同一页只用一种，不叠加。
5. 对比关系的画法：Before / After 用大数字加中间三角箭头，Existing / Expected 用左侧竖向灰块，实线 / 虚线折线用实心 / 空心点。
6. 图下方配 Key insights 框（虚线或浅灰底），写 2 条分析。关键词用斜体或粗体强调。
7. 分组和层级主要靠浅灰 / 浅绿底色块加虚线框来分隔，几乎不用实线外框。
8. 表格：只留水平细线，表头用深酒红，重点列用浅灰底，重点行用红虚线框。
9. 图表通用：灰色坐标，数值直接标在柱上，图例放在图表上方或左上，历史 / 预测用不同颜色，中间用虚线分隔。
10. 左右分栏约各 50%，中间可以放虚线竖线。栏内标题使用编号方块（1/2/3）或灰色竖块。
11. 预测值用更浅或空心的颜色（浅绿空柱、空心点、虚线）区分，和实际值区分开。
12. 反馈和强调的色阶：重点 = 酒红深 / 次重点 = 浅粉红 / 正向 = 灰绿 / 中性 = 灰。

## 出现的思维模型/框架
- 结论先行（Conclusion first）：每页标题就是该页结论，如 "market size will double in 2027"，下面 1/2/3 分别是支撑证据。
- 三栏论证：同一页用 3 个编号小标题拆解论点（如 02.jpg 上页：谁是客户 → 最关心什么 → 购买模式）。
- 漏斗 / 阶段式客户策略（01.jpg 中页）：Potential → Customer Absorption → Regular Customers，每阶段分线上 / 线下两个动作。
- Before / After 对比与 Existing / Expected 对比（02.jpg 下页）。
- Think Global / Act Global 两步框架 + Strategy / Product / Business 三层（01.jpg 下页）。
- 供需对照：Demand 544M vs Supply 350M，用 ">" 符号直接得出结论（03.jpg 中页）。
- Input → Model → Output 流程（07.jpg 中页）。
- 上下限区间表（04.jpg 下页）：上限 / 目标 / 下限。
- 每页还有 "Write one sentence summary for this page" 的占位，提示作者先写一句话总结。
