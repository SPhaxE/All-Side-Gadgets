# Less is more：SCR / BAB / 高管摘要 / 燃烧平台 四个汇报框架页（编号 096-100）

## 本篇主旨
本篇是 iceppt 的"汇报思维模型"系列页（096-100）：每个框架用"上半页讲框架（定义+结构图+核心原则）、下半页用一个商业案例演示"的方式，把 SCR、BAB、Executive Summary、Burning Platform 四种汇报/提案结构落成可直接套用的 PPT 版式。note.md 只有标题（Less is more）和话题标签，没有正文 tips，所以所有方法都来自图片。

## 逐页拆解

本篇实际阅读 2 张图（01.jpg、03.jpg），每张均为三张幻灯片上下拼接（1080 宽，约 1837 高；外层是浅青灰底色，内部白色页面，每张幻灯片带圆角细灰边框）。

### 01.jpg 上：SCR Framework（编号 096，框架讲解页）
- 页面角色：定义 SCR 模型并讲清三步结构，是一个"框架说明页"。
- 版式与网格：
  - 顶部是标题条：左侧大号英文标题 "SCR Framework"，右侧 "@ICEPPT 096"（@ICEPPT 为衬线/等宽感小字，096 为粗黑大字）。
  - 标题下是一个圆角说明框：第一行是带红色下划线的 "Situation-Complication-Resolution (SCR 模型)" + "- 咨询汇报标准开头"，其后是 2 行灰色小字说明。
  - 中部是横向时间轴：一条深绿粗线 + 右端实心箭头，轴上三个空心圆节点（S、C、R）。
  - 底部一行"核心原则"：左侧灰色标签 "核心原则"，右侧三个带绿色圆形数字 1/2/3 的原则，等分三列。
- 图表类型与画法：横向箭头时间轴（不是数据图）。S/C/R 的英文大词（"S · Situation"、"C · Complication"、"R · Resolution"）用浅细字体、绿色，放在轴线旁；S 与 R 在轴线上方，C 在轴线下方，形成错落（S 上、C 下、R 上）；每个节点向上或向下拉一条细灰竖线，连到该步的中文小标题 + 灰色说明 + 三条圆点要点。
- 强调手法：右侧 R（Resolution）区域铺一块大面积浅绿色矩形底色（约占整页宽度的 40%、中部高度），把"结论/答案"区域用底色整块突出。
- 配色用法：深绿用于轴线/箭头/数字圆/英文大词；浅绿用于 R 区底色；黑色用于标题和小标题；灰色用于说明文字；红色仅用于标题下划线。
- 字体字号层级：最大是页面标题 "SCR Framework"（粗黑无衬线，约 24-26pt 视觉量级）；其次是 S/C/R 大词（浅细、约 20pt 视觉量级）；中文小标题（"建立场景""引入冲突""给出答案"）粗黑小号；说明与要点为更小灰字。具体字体名不确定。
- 关键文字原文摘录：
  - "Situation-Complication-Resolution (SCR 模型)　- 咨询汇报标准开头"
  - "三步走完一个完整的说服逻辑：先建立共识（我们都认可的现状），再引入张力（但有个问题打破了平衡），最后直接给出答案（所以我们的结论是）。适合高管汇报——对方时间有限，不需要铺垫，需要的是"问题是什么、答案是什么"。"
  - 建立场景：描述现状、背景与已达成的共识；要点"市场规模持续增长 / 品牌保持行业领先 / 用户需求正在变化"
  - 引入冲突：指出现状中的异常、挑战或风险；要点"用户增长放缓 / 获客成本持续上升 / 利润率开始下降"
  - 给出答案：提出解决问题的核心观点或行动方案；要点"聚焦高价值用户 / 优化产品组合 / 提升会员运营效率"
  - 核心原则：①"Situation只讲必要背景"（提供必要信息、建立共同语境、避免信息堆砌）②"Complication必须足够尖锐"（指出真正的问题或矛盾，没有冲突就没有关注）③"Resolution必须回应Complication"（答案必须直接解决提出的问题，让结论成为唯一合理的选择）

### 01.jpg 下：BAB Framework（编号 097，框架讲解页）
- 页面角色：定义 Before-After-Bridge 并给出三个角色的提问清单。
- 版式与网格：
  - 与第一页同样的标题条（"BAB Framework" + "@ICEPPT 097"）和圆角说明框（红色下划线的 "The Before-After-Bridge BAB 模型 (现状-愿景-桥梁)" + "- 向客户/老板索要资源或预算"，下面是 2 行灰字说明）。
  - 左上"核心原则"：左侧文字 + 竖线 + 三条绿色对勾 + 灰字原则。
  - 主图：一座山形（浅灰绿面积图/山丘剪影），从左低到中间高峰再到右下降，山下沿一条底线；山前后分布三个虚线框的文字卡片：左下"现状 | 痛点"、山顶上方"路径 | 方案"、右中"愿景 | 目标"。
  - 山体上的大词：左下 "Before"、中上 "Bridge"、右下 "After"，均为绿色粗体英文，字号约 18-20pt。
  - 底部居中一句灰字引语。
- 图表类型与画法：山形/拱桥示意图（概念图），用浅色填充山体表达"桥"的意象；三个角色卡片用虚线圆角框 + 灰底，内部三条要点；卡片高度错落（Before 偏低、Bridge 最高、After 偏中），暗示从低到高再落地的叙事曲线。
- 配色用法：整页以白底 + 浅灰绿山体 + 深绿英文关键词为主，黑色标题，灰色说明。
- 字体字号层级：页面标题粗黑；"Before/Bridge/After" 绿色粗体较大；卡片标题（"现状 | 痛点""路径 | 方案""愿景 | 目标"）中小号粗黑；说明与要点灰色小字。字体名不确定。
- 关键文字原文摘录：
  - 说明："在商业提案及预算申请场景中，最核心的误区在于开篇即聚焦产品优势或项目执行路径。决策者的关注焦点为自身状态的改善，而非方案的实现工具。BAB 框架要求汇报者首先客观呈现观众当前的痛点现状（Before），继而描绘清晰的理想未来（After），通过两种状态间的认知张力激发求决动力，最后顺理成章地提出作为解决方案的战略或预算方案（Bridge）。"
  - 核心原则：真实呈现现状，不夸大不隐瞒；愿景清晰具体，具备吸引力；桥梁可行可信，有清晰路径
  - 现状 | 痛点：客观呈现当前状态，建立共识，唤起改变的必要性；"现状是什么？存在哪些问题或挑战？为什么需要改变？"
  - 路径 | 方案：提出可行的解决方案，说明如何从现状走向未来；"我们如何实现目标？关键步骤与行动计划是什么？为什么这个方案可行？"
  - 愿景 | 目标：描绘未来的理想状态，激发听众的向往与共鸣；"我们希望达成什么？改变后的价值是什么？未来将带来哪些积极影响？"
  - 引语："先让人看到问题，再让人看到希望，最后让人相信路径。"

### 03.jpg 上：Executive Summary Template（编号 099，模板页）
- 页面角色：给出"高管摘要页"的空白模板，即一页纸摘要的四区块结构。
- 版式与网格：标题条 "Executive Summary Template" + "@ICEPPT 099"；说明框内红色下划线 "Executive Summary Template (高管摘要页)" + "- 必须假设"老板只看这一页""，下面两行灰字。主体为四列等分：1. 背景与核心问题、2. 主要发现与结论、3. 战略建议、4. 下一步行动；每列顶部是"序号. 标题 + 灰色引导问句 + 一条绿色细横线"，下面是灰色底块（浅灰面板）承载占位内容。
- 各列内容：
  - 1 列：两组图标 + 文字——"业务背景"（一句话说明项目背景、现状，以及为什么要现在解决这个问题）、"核心问题"（我们需要回答的关键问题是什么？用一句话清晰定义）。
  - 2 列："关键结论（1-3条）"三个灰色圆点 + 灰色条形占位（结论1/2/3）；下面"关键事实/数据支撑"，示意一个环形图和一个柱状图的灰色占位，加"关键数据或趋势图 / 支持结论的最重要证据"。
  - 3 列："我们的建议：一句话总结核心建议（方向+策略）"；"建议选项（如适用）"选项A/B/C 三行（"核心思路与预期结果"）；向下箭头；"推荐方案"带图标，填空句"我们推荐：____，因为____。"
  - 4 列："关键行动清单"三个绿色对勾 + 行动项1/2/3；虚线；"时间计划"（关键里程碑与时间节点）、"责任人"（明确每项行动的Owner），各配圆形图标。
- 配色用法：灰色占位块 + 绿色细线、绿色对勾；整页非常灰淡（模板态），颜色只用作结构提示。
- 字体字号层级：页面标题粗黑；四列标题为手写感/细体的"1. 背景与核心问题:"（中等字号、黑色）；列内说明为更小灰字。字体名不确定（列标题看起来是偏手写风的衬线或细体，不确定）。
- 关键文字原文摘录：
  - "整份汇报的压缩版本——核心问题、关键结论、支撑逻辑、下一步行动，全部浓缩在一页之内。麦肯锡的标准是：一位没有参与过这个项目的高管，只读这一页，应该能完整理解"发生了什么、结论是什么、要做什么"。如果做不到，这页就没写好。结构通常包含四个区块：背景与核心问题、主要发现、战略建议、下一步行动。顺序可以调整，但缺一不可。"

- 配色用法：绿色数字圆、绿色表格线/横线、灰色面板；图表（瀑布图、甘特图）以灰/浅绿为主，没有大面积彩色；极度克制，强调靠结论句与编号。
- 字体字号层级：结论句粗黑；列标题粗黑；表格与图表内为很小的无衬线（约 6-8pt 视觉量级）；底部大数字相对较大。字体名不确定。

### 03.jpg 下：The Burning Platform（编号 100，框架讲解页）
- 页面角色：讲"燃烧的平台"模型：用来回答客户最深的抗拒——"我们现在在挺好的，为什么要变？"
- 版式与网格：标题条 "The Burning Platform" + "@ICEPPT 100"；说明框内红色下划线 "The Burning Platform (燃烧的平台)" + "- 用来回答客户最深的抗拒："我们现在在挺好的，为什么要变？""，下面是 2-3 行灰字。主体是一个"目标 + 左右结构"：

## 提炼出的设计规则
1. 系列化的"双页结构"：每个框架 = 上页"讲清框架"（定义 + 结构图 + 核心原则）+ 下页"案例演示"（同一版式换成真实业务数据），观众先学模型再看实例。
2. 每页顶部固定三件套：左侧英文大标题 + 右侧品牌/编号（@ICEPPT + 3 位粗体序号）+ 下方一个圆角说明框，框内第一句 = 红色下划线的"英文名（中文名）+ 一句定位语"，后接 2-3 行灰色解释。
3. 案例页标题格式固定为"框架名 - CASE STUDY：具体场景：一句话冲突"；紧接一行"黑色实心圆点 + 粗体结论句"，结论句一次说清"问题 + 原因 + 对策"，全页内容都是对它的论证。
4. 强调靠"块"，不靠"多色"：整页只用一个主强调色（深绿）；最重要的区域（如 SCR 的 Resolution）用浅绿整块底色圈出；强调色面积控制在整页约 10% 以内，其余用黑/灰/白。
5. 红色只作"否定/警示"信号：红色下划线（标题关键词）、红色"✗"（问题短语、常见误区），其余地方不出现红色，从而让红色有信息含量。
6. 用"数字 + 胶囊标签 + 红叉短语"三件套呈现问题证据：大数字（68% / -32% / 6个月）+ 灰色胶囊说明指标 + 一句"✗ 结论"。
7. KPI 条写法：大号细体数字（¥1.8B）+ 小灰字标签 + 更小的同比（↑15% YoY），三个一排，用细竖线分隔；数字用品牌深绿。
8. 图表只做证据，不抢结论：折线图小、灰、淡，只标最关键的 1-2 个点（如 -6%）并用一句话命名（连续销售额负增长）；图标题放在灰色倒梯形/矩形标签里。
9. 概念图用"错落 + 虚线卡片"：SCR 轴线上下错落放三个节点；BAB 的三个虚线卡片按山形高度错落，高度本身表达叙事走向。
10. 每个角色/步骤配"提问清单"：每个节点放 3 条以问句形式写成的要点（如"我们如何实现目标？"），让读者直接复用于自己的内容。
11. "核心原则"固定放在页面底部或左上，以 3 条短句呈现，使用绿色数字圆或绿色对勾作为统一标记。
12. 一页纸摘要（Executive Summary）用四列等分：背景与核心问题 -> 关键结论 -> 战略建议 -> 下一步行动；每列头 = 绿色序号圆 + 粗体标题 + 灰色引导问句；底部用一条横线加"预期影响"4 个数字收尾。
13. 复杂信息用统一的灰底分块容纳：表格、瀑布图、甘特图都放在浅灰底卡片里，列头风格一致，避免一页里出现多种视觉语言。
14. 数据要有对标：关键指标表用"公司 / 行业 / 差距"三列（如 6.2% vs 11.2% -> -510bps），让差距成为结论的证据。
15. 小字号只用于说明和要点（图中表格/图表字约 6-8pt 视觉量级，放映时难读），正式使用时建议把表格字号提高到 10pt 以上，或每页减少元素（这是对样例的改进建议，不是原图做法）。
16. 英文关键词当"视觉锚点"：Before / Bridge / After、Final objective / Key Factors / Common fallacies、S · Situation 等用深绿色较大字号（浅细或粗体），配灰色中文副标，作为页面的视觉层次起点。
17. 引语收尾：讲解页最底部可以放一句居中的灰色金句（如"先让人看到问题，再让人看到希望，最后让人相信路径。"）作为记忆点。

## 出现的思维模型/框架/方法论
- SCR（Situation-Complication-Resolution）：先建立共识（S，只讲必要背景）、再引入尖锐冲突（C）、最后直接给答案（R）。适合高管汇报。案例：某零售连锁 Q3 董事长汇报"表面繁荣下的危机"——S 是营收 ¥1.8B、利润 ¥180M、门店 350 家的增长；C 是同店销售额连续负增长（-6%）、客单价跌幅 32%、现金流预计 6 个月枯竭；R 是老店复兴、客单价重建、扩张策略重置三大举措。
- BAB（Before-After-Bridge，现状-愿景-桥梁）：先呈现痛点现状，再描绘理想未来，最后用方案作为桥梁。用于向客户/老板索要资源或预算。要点：真实呈现现状、愿景清晰具体、桥梁可行可信。本篇只有框架讲解页，没有案例页（在已读图片中）。
- Executive Summary（高管摘要页）：一页纸、四区块（背景与核心问题、主要发现与结论、战略建议、下一步行动），假设"老板只看这一页"；麦肯锡标准是未参与项目的高管只读这一页就能理解"发生了什么、结论是什么、要做什么"。案例：某中型工业制造企业扭亏为盈战略（成本结构高于行业 18%、低毛利产品占 35%、营运资金周转天数多 23 天；三项措施；3 年后 EBITDA 利润率 +6.8pp）。
- The Burning Platform（燃烧的平台）：来自变革管理顾问 Daryl Conner，用数据和事实让对方意识到"维持现状本身才是最大风险"。四步：揭示现状真实代价 -> 外部趋势加速压力 -> 未来状态对比冲击 -> 出发行动的临界点。关键要素：紧迫性、相关性、真实性；常见误区：泛泛而谈、只讲危机不给希望、夸大其词。
- 辅助方法：YoY 同比、bps 差距、CCC（现金转换周期）、瀑布图、甘特图、EBITDA 利润率等财务指标式汇报语言。
