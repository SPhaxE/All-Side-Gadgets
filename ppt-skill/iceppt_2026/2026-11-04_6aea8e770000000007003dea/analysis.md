# 手搓ppt独有的感觉：用五个汇报框架做 Done / Well Done 对比

## 本篇主旨
PPT 的"人感"来自取舍：每页都在表达"我怎么看这些内容、希望你怎么理解"。用 STAR、Burning Platform、BAB、PREP、Why-How-What 五个框架，各做一组"Done（四栏平铺的文字模板）"与"Well Done（按内容重新设计的版面）"对比，说明三件事：结构里有主张、画面里有节奏、细节里有照顾。

## 逐页拆解

## 提炼出的设计规则
1. **先决定重点，再决定版面。** 同一套四栏内容，不要四栏等宽等重；重点栏做成最宽，并用唯一的粗边框或实心色块标出（例：STAR 的"行动"栏深绿粗框）。
2. **强调色只给 1–2 个对象。** 一页里实心绿块/粗边框不超过 1 处，其余用细边框、浅绿底、绿色文字；强调色面积大致控制在 10% 以内（估算，作者未明说）。
3. **把最关键的一个数字单独抽出来做大。** 如 "GMV ▼ 12%" 做成整块实心色块、"▲2.3x" 做成卡片底部大号数字，不要埋在句子里。
4. **统一页头骨架。** 圆角描边标题条（"方法名 - CASE STUDY：场景"）+ 右上角品牌标记和页码 + 下一行黑色圆点开头的一句话摘要。全套页保持同一位置、同一字重对比（英文方法名粗体，中文说明常规）。
5. **摘要句写结论，不写主题。** 如 "服务收入占比可从8%跃升至25%"，而不是"服务业务介绍"。
6. **框架的结构本身就是版式。** PREP 用 0s/30s/60s/90s 圆点时间轴；Burning Platform 用树状图；BAB 用三栏加大 V 形箭头；Why-How-What 用弧线圆环。优先用框架的逻辑形态做骨架，而不是把框架名放在四个文本栏的列头上。
7. **图表按主张重画，不照搬默认图。** 折线图改柱状图以强调"差距与目标"；柱子用浅灰；去掉网格线；数值标在柱顶；只保留一侧刻度。
8. **占比类数据用最简单的水平条。** 92% vs 8% 用两根灰条，不用饼图。
9. **表格极简化。** 只留横线、去掉竖线与灰色表头；用 ✓/✗ 代替"是/否"文字；目标列用绿色小点标出。
10. **对比用同构的左右卡片。** 同样的行（What/How/Why）、同样的卡片大小，只靠 ✗/✓、红/绿边框区分好坏。
11. **留白就是缓冲带。** Well Done 里文字块之间留出整行空白，英文大标签用细体放大，中文说明缩小，形成"一大一小"的节奏；大块文字区与大图形区交替排布，不要全页都密。
12. **细节都有照顾。** 阶梯式缩进（BAB 左栏）、统一圆角、线条图标放在浅绿圆底里、小号注释放在卡片角落（如标签胶囊、"vs 目标14天"小字）、正文里用括号统一补充说明。
13. **文字量按层级递减。** 主结论（粗体/大号）→ 小标题（粗体小号）→ 说明（灰色极小号）；说明性文字用灰色，不与结论抢注意力。
14. **箭头/连接符也要配色。** 连接栏位的箭头用浅灰或浅绿粗箭头，而不是默认黑色细箭头，且大小服务于"流程"感而不抢焦点。
15. **页面比例：** 16:9，页面四周留白约 3–5%（按图估算，不确定）。

## 字体与字号层级
- 字体：中文是无衬线黑体（观感类似微软雅黑/思源黑体，不确定）；英文方法名、页码"090/100"为粗体几何无衬线（具体字体不确定）；"Final objective""Why""How""What"为细体（Light）无衬线；"@ICEPPT"为带字距的等宽/打字机风格字体（具体字体不确定）。
- 字号层级（估算，以 13.33in 宽幻灯片 1px≈1pt 换算，仅供参考）：
  - 页码：约 24–28pt，粗体，右上角。
  - 页头标题：约 18–20pt，英文名粗体，"CASE STUDY：…"常规。
  - 摘要句：约 9–10pt，粗体，黑色圆点开头。
  - 框架大英文标签（Why/How/What、Final objective）：约 24–30pt，细体，绿色。
  - 列头/小标题：约 9–11pt，粗体或常规。
  - 正文要点：约 7–9pt，灰或黑。
  - 脚注/说明：约 6–7pt，灰色。
- Done 版：标题约 22–26pt 粗体，副标题约 11–12pt，正文约 9–10pt。
- 总体：Well Done 的正文反而更小，靠大块留白与强对比层级维持可读；若作为课件投屏使用，字号需要放大，此处不确定作者的实际用途。

## 出现的思维模型/框架/方法论
- **STAR（背景-任务-行动-结果）**：用于复盘一次事件，把事件拆成 S/T/A/R 四栏；案例是某大厂产品经理复盘一次失败的推荐功能迭代（GMV 下滑 12%，9 天修复，目标 14 天），附"可复用方法论"（数据分层分析、小流量 A/B、灰度发布）。
- **Burning Platform 燃烧的平台（Daryl Conner）**：用于变革沟通，让客户意识到"不改变的代价＞改变的成本"；三个关键要素（紧迫性、相关性、真实性）、三个常见误区（泛泛而谈、只讲危机不给出希望、夸大其词）、四步构建（揭示现状真实代价 / 外部趋势加速压力 / 未来状态对比冲击 / 出发行动的临界点）。
- **BAB 框架（图中标注为 BAB Framework）**：用于说服类汇报，现状（服务拖累增长）→ 目标状态（2028 服务业成为第二增长曲线）→ 转型路径（智能化 IoT 设备监控、服务产品化维保套餐订阅、数据变现预测性维护）；案例是工业设备制造商的售后服务转型，服务收入占比 8%→25%，服务收入 1.2→5.4 亿元。具体 Before / After / Bridge 的对应关系为按版面推断。
- **PREP（观点-原因-案例-重申观点）**：用于 90 秒电梯汇报，按 0s / 30s / 60s / 90s 分配每一步；案例是电商退货率从 15% 升到 28%，原因是尺码标准缺失（43.6%）与商品描述失真（31.2%），建议建立商品质量分级体系，目标 Q3 退货率降至 18%。
- **Why-How-What 黄金圈叙事（Golden Circle）**：用于品牌、领导力沟通、产品营销、投资路演、个人品牌；先说信念再说方法再说产品；案例对比"普通公司"（What→How→Why，结果：价格竞争）与"伟大公司"（Why→How→What，结果：品牌忠诚），以 Apple 与 Dell 的差别说明（Think Different）。
- **Done vs Well Done 对比法**：同一内容做"朴素版"与"设计版"的前后对比，用作教学和展示。
