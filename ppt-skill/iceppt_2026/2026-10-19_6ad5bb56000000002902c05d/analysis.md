# 手搓的ppt用着不烧心——7页「思维模型 × 案例」信息密集型PPT的原生可编辑做法

## 本篇主旨
展示一套"思维模型/框架名 + CASE STUDY 案例"的整页信息图式 PPT 模板（STAR、Kano、Why-How-What、SCQA、MECE Tree、Brand Identity Prism、Ghost Deck 共7页）。卖点不是内容而是工程质量：全部元素原生可选中、整齐无乱码、图表数据双击即用 PPT 内置 Excel 编辑（"手搓"而非贴图）。

> 版面说明：本篇7张图全部是"上下拼图"，但**上半 = 干净成品页，下半 = 同一页在 PPT 编辑态下全选后的样子**（满屏选择框/控制点，部分页面弹出内置 Excel 数据表），并不是 Done/Well Done 式的内容前后对比。下半的作用是"证明每个元素都是可编辑的原生对象"。

## 逐页拆解

### 通用页面骨架（7页共用，先列出避免逐页重复）
- 画幅：16:9，上下各留大片灰白底（拼图留白），幻灯片本体约占宽度 83%。
- 顶部"标题栏"：一个细黑描边的**圆角胶囊长条**，左侧 = 框架名（英文粗黑体，大）+ " - CASE STUDY：中文案例名"（常规字重，略小），右侧 = 页码式编号（090/035/093/088/089/030/095，粗黑大号）；多数页在编号左侧有绿色小字 "@ICEPPT"（水印/署名，字形偏衬线/等宽，不确定具体字体）。
- 标题栏下方一行"黑色实心圆点 + 粗体结论摘要句"（1~2行），写明用框架做了什么 + 结果。
- 主体：多栏/多模块，模块之间靠**浅灰/浅绿底色块 + 细线框**分组，不用重阴影；每个模块小标题带竖线或灰条。
- 绿色是唯一主色，其余全灰阶，极少量橙/红做警示。

### 01.jpg —— STAR Method（编号 090）
**上半（成品页）**
- 角色：用 STAR 复盘一个失败的产品迭代案例（某互联网大厂产品经理，抖音电商"兴趣推荐"功能）。
- 标题："STAR Method - CASE STUDY：某互联网大厂产品经理复盘一次失败的产品迭代"；摘要句："利用 STAR 框架还原产品决策全链路，通过极速的数据拆解与 A/B 测试回滚，展示了在巨大的商业影响压力下，牺牲短期 GMV 以换取核心模型重构的战略级止损。"
- 版式：**4等宽列**（事件背景 / 任务 / 行动 / 成果与复盘），每列顶部一条浅灰色表头条；列与列之间用**浅绿色实心箭头（chevron）**串联，体现 S→T→A→R 顺序。
  - 事件背景：浅灰绿底面板，3组"小标题+灰字说明"（产品线 / 团队规模：跨职能团队12人（产品2+研发6+设计2+数据2）/ 核心问题：停留时长下降18%，GMV下滑12%），底部一个浅绿实心色块 "GMV ▼ 12%"（白字）作为情境的核心数字。
  - 任务：顶部一个细线框"核心目标：7天内定位问题根因 / 14天内推出修复方案"，下接4个等宽细线框约束条（时间压力：CEO周会倒计时；技术债务：算法黑盒难调试；商业：日均损失¥200万；组织复杂：需协调3个BU）。
  - 行动：**深绿粗边框大框**（本页视觉重心），内分 01.数据拆解 / 02.快速验证 / 03.方案迭代，小号字；关键决策句用绿色粗体强调："决策：牺牲短期GMV，优先修复用户体验"。
  - 成果与复盘：浅青绿圆角描边卡片，"核心指标恢复"3行带图标的前后对比（停留时长 2%→18%；GMV -12%→4%；修复周期 9天 vs 目标14天），下方"可复用方法论"3条打勾（绿色✓）。
- 图表类型：无传统图表，用"数字前后对比 + 箭头"表达结果。
- 配色：深绿框=主动作，浅绿/浅灰底=背景信息，GMV 色块用中绿。正文以灰色小字为主，仅关键数字/决策用黑或绿加粗。
- 字号层级：框架名最大 > 摘要句 > 列表头 > 正文（很小，约为标题的 1/3）> 脚注灰字。
**下半（编辑态）**：全页每个文本框、色块、箭头、图标都有独立选择框，可见层级分明的对象结构；无Excel弹窗（本页无图表）。

### 03.jpg —— Why-How-What（编号 093）
**上半**
- 角色：用 Why-How-What 拆解 Patagonia 创始人30亿美元捐赠案例，并给出量化商业回报。
- 标题："Why-How-What - CASE STUDY：Patagonia创始人30亿美元的捐赠"；摘要："依托 Why-First 价值锚点，通过理念具象化落地构筑差异化心智壁垒，驱动品牌实现 40% 溢价空间、年营收突破 1.5 亿美元的商业化兑现。"
- 版式：**三栏**：左窄栏"时间线"、中栏 Why/How/What 三段纵向堆叠、右宽栏"仪表盘 + 洞察"。
  - 左：灰绿色**半透明蒙层覆盖森林照片**作为背景（图片被做淡化，文字仍清晰），三个深绿胶囊时间标签 1973 / 1985 / 2022 + 一个向下的大灰色箭头贯穿；每节点下是小字说明。
  - 中：①Why? ②How? ③What? 三个描边圆形序号 + 绿色粗标题；每段先一句话、再2~4条要点；每段末尾一个**圆角描边的"结论胶囊"**放关键数字（"客户复购率60%，行业均值仅25%"；"2022财年全年营收超15.8亿美元"）。
  - 右上："商业成果仪表盘（量化回报）"，**3×3 KPI 卡片网格**：每卡 = 小灰标签 + 大号黑色数字（$1.5B+、73、+40%、95%、60%、$280、$140M+、+40%、860+）+ 绿色上升箭头与涨幅（↑12%、↑143%、↑58%、↑140%、↑133%、↑28%）+ 底部灰字行业对比（Vs 行业增速+8% 等）。
  - 右下："战略洞察 | Why-First 如何驱动商业成功"，3张并排 Insight 卡（Insight1 客户终身价值(LTV)溢价；Insight2 反常识策略的悖论〔Don't buy this jacket 广告〕；Insight3 终极why-First决策：拒绝IPO/拒绝私募投资/选择【地球是唯一股东】），每卡顶部绿色小胶囊标签，底部浅灰绿底的一句"小结"。
- 配色：绿为强调（胶囊、箭头、标签），数字黑色加大；背景照片仅用作氛围，做了去饱和 + 白蒙层。
**下半（编辑态）**：每张 KPI 卡、数字、箭头、时间线胶囊均为独立对象；无 Excel 弹窗。

### 05.jpg —— MECE Tree（编号 089）
**上半**
- 角色：用 MECE 拆解树分析某区域咖啡连锁（127家门店）2023年净利率从8.2%暴跌到2.1%的原因并给出行动方案。

- 版式：**左（树）/ 中（3张图）/ 右（诊断+行动）三栏**，栏间有极淡的竖向虚线分隔。
  - 左：**真正的树状图**：根节点"净利润率 2.1% ▼-6.1pp（2022: 8.2%→2023: 2.1%）"（2.1% 用深红大字）→ 第二层"营收 ¥428M""总成本 ¥419M（+12.4%，占营收97.9%）"→ 第三层营收下拆"客流量12.8M人次""客单价¥33.4"，总成本下拆"原材料成本 ▲+18.7% ¥167M 占营收38%""人力成本 ▲+15.2% ¥141M 33%""租金成本 ▲+6.8% ¥111M 28%"；节点为灰底圆角方块，线为细直角连线；增长/占比用绿色小字。左下**绿色点状虚线框"MECE验证"**：ME（相互独立）：营收≠成本；CE（完全穷尽）：营收-成本=净利润；¥428M-¥419M=¥9M (2.1%)，带绿色大✓。
  - 中：3张小图，每张前缀灰色小三角▶ + 标题 + 灰字副标：①**100%堆叠横条**（2023 vs 2022 成本结构 38%/33%/26%/2% vs 35%/30%/25%/10%），带黑色圆角批注"原材料价格+4pp 咖啡豆价格+28%"；②**营收下滑瀑布图**（465→客流量 -24→客单价 -14→428，首尾柱灰色深浅区分，中间负向柱细），批注"双重下滑 客流-5.1% 客单价-3.3%"；③**直方图**（门店数量 vs 盈利区间 -5%~0%/0%~3%/3%~5%/5%~8%/8%~10%/10%~% ，柱用极浅绿），黑色批注"53家门店亏损（<2% margin）占比42%"，用**竖向虚线**标出盈亏分界。（注：第①和③的图标题文字都是"同店销售增长趋势变化 2022 vs 2023"，疑似模板复制未改，原图如此。）
  - 右上："根因诊断"（**橙色**圆点+橙色标题，唯一用橙的页面），淡米色底卡片3条编号结论（原材料暴涨/人力成本刚性/客流量流失）。

### 06.jpg —— Brand Identity Prism（编号 030）
**上半**
- 角色：纯框架讲解页（无 CASE STUDY 字样，标题栏只写 "Brand Identity Prism"），讲 Kapferer 品牌识别棱镜六维模型。

## 提炼出的设计规则
1. **统一页面骨架**：每页固定"圆角胶囊标题栏（框架名 + CASE STUDY 案例名 + 右侧大号编号）+ 黑点结论摘要句 + 主体模块"。系列页只换内容不换骨架，翻页零学习成本。
2. **标题 = 框架名 + 案例名，摘要 = 结论句**：摘要句必须同时包含"用了什么方法 + 得出什么结果/数字"（如"牺牲短期GMV以换取核心模型重构的战略级止损"），而不是话题名。迷你页标题同理写成结论（"高价值会员贡献过半"而非"用户分层"）。
3. **单一强调色**：全页仅用一种主绿（深绿 #0B7A5E 左右）+ 灰阶。强调色面积控制在约 10-15%，且只落在"最关键的一个模块"上（如 STAR 的"行动"列深绿粗框、Prism 的 Culture 格深绿胶囊、Kano 的 Switch 曲线）。
4. **警示色只用来表达语义且每页≤1处**：红色=负面/危机（"急转直下"竖线、收入仅+3%、"投入核心创意资源"批注）；橙色仅出现在 MECE 的"根因诊断"标题。其余一律不用。
5. **"主角深色 / 对照浅灰"做图表**：突出系列用深绿实线/深灰条，对照系列用浅灰虚线或浅灰条（Kano 曲线、SCQA 条形图）；直接在线/条旁标注系列名，省略图例。
6. **图表必须原生，数据可双击编辑**：折线、条形、瀑布、直方、帕累托、环形全部用 PPT 内置图表（数据在内置 Excel），不贴图；文字、色块、箭头、图标、表格全部为独立对象，不合并成图片、不出乱码。
7. **每个图表配一句结论**：图下方用圆角灰框/描边框写1句"So what"（"完全避开红海参数战，开辟蓝海价值曲线。""帕累托图分析：价格+可及性=70%流失原因"），或在图内用黑色圆角批注框标出关键数字（"53家门店亏损占比42%"）。
8. **数字分级**：KPI 用"大号黑色数字 + 小灰标签 + 绿色↑涨幅 + 灰色行业对比"四件套；前后对比用"旧值→新值"箭头写法（2%→18%）；关键转折数用大号字单独拎出（"2022 Q2 急转直下"）。
9. **叙事结构用形状编码**：顺序=chevron/箭头串联（STAR、转型路线图）；并列=等宽卡片网格（KPI 3×3、Insight 3卡、Ghost Deck 2×3）；层级=树状图；对立=强弱对比表；排除=✗药丸；验证=✓+绿点虚线框。
10. **模块分组靠底色而非边框堆叠**：灰条表头 / 浅灰绿底面板 / 细描边圆角框三种容器，圆角统一、线宽≤1pt；避免阴影与渐变。
11. **图片只当氛围背景**：照片需去饱和并盖白色/浅绿蒙层（Patagonia 森林），保证文字对比度。
12. **信息密度高但层级清楚**：正文可低至约 7-9pt，靠"粗体小标题 + 灰色正文 + 关键数字加粗"三档拉层级；留白少，但靠栏间距、淡分隔线和统一对齐保证"整齐"。
13. **用"灰色问号/大引号/大箭头"做大号装饰字符**，以浅灰色放大，充当视觉锚点而不抢内容（SCQA 的"?"、Kano 的引号、Patagonia 的下行箭头）。
14. **加入"思考/诊断/验证"侧栏**：每个框架页附一个小模块（Thinking、棱镜诊断、MECE验证、可复用方法论、Ghost Deck 筛选），把"如何用这个模型"也呈现出来，使页面既是案例又是教程。

## 出现的思维模型/框架/方法论
- **STAR Method（情境-任务-行动-结果）**：四列从左到右 + chevron 箭头；案例：某大厂PM复盘"兴趣推荐"功能失败，目标7天定位/14天修复，决策牺牲短期GMV优先用户体验；结果停留时长 2%→18%、GMV -12%→4%。
- **Kano Model（卡诺模型：基本型/期望型/兴奋型）**：X=功能具备度，Y=用户满意度，三条曲线分区 + 编号散点；案例：任天堂 Switch 放弃性能/画质、押注形态切换与第一方大作。
- **蓝海价值曲线 / 差异化战略曲线**：多维度折线对比竞品，Switch 与 PS4/Xbox One 走势相反；结论"避开红海参数战，开辟蓝海价值曲线"。
- **横井军平"枯萎技术的水平思考"（Lateral Thinking with Withered Technology）**：用成熟便宜旧技术做新组合，保护硬件毛利（页面"Thinking"框内容）。
- **Why-How-What（Why-First 价值锚点）**：Why（为了拯救地球）→How（捐赠/拒绝非环保供应商/终身维修等）→What（外服+环保行动主义产品）；案例：Patagonia 创始人将价值30亿美元的股权捐出；用9项KPI（营收$1.5B+、品牌溢价+40%、复购率60%等）+3条洞察（LTV溢价、反常识广告 Don't buy this jacket、拒绝IPO）量化回报。
- **SCQA（情境-冲突-问题-答案）**：S=业务背景（5,360店/37%份额/¥38客单价/预期同店+10%）→C=2022Q2同店销售-14%、营收-44%、股价-9.8%→Q=疫情冲击还是结构性衰退→A=三阶段转型（止血/稳定/增长）。
- **帕累托分析（80/20）**：2400+样本，价格+可及性=70%流失原因（累计折线 42%→70%→88%→96%→100%）。
- **MECE 拆解树（ME相互独立/CE完全穷尽）**：净利润率 = 营收 - 总成本，营收 = 客流量 × 客单价，总成本 = 原材料 + 人力 + 租金；用 ¥428M-¥419M=¥9M (2.1%) 做验证闭环；案例：咖啡连锁净利率8.2%→2.1%，行动方案含成本优化（供应商集中采购、砍掉12个低毛利SKU）与营收增长（会员订购、非高峰折扣、外卖25%）。
- **瀑布图（营收归因）**：465 → 客流量 -24 → 客单价 -14 → 428。
- **Brand Identity Prism（Kapferer 品牌识别棱镜）**：六维（Physique/Personality/Culture/Relationship/Reflection/Self-image），纵轴"形象发出者↔接收者"，横轴"外在化↔内在化"；Culture 是核心底座；配"棱镜诊断"清单与"强弱对比"表；案例：可口可乐、耐克、亚马逊、谷歌、红牛、保时捷。
- **Ghost Deck / Storyboard（先搭故事线再做分析）**：5步演化——提出问题 → 列假设 → 筛选主线（划掉不成立假设）→ 6页故事骨架（现象/用户分层/会员流失/根因分析/增长机会/战略建议）→ 一句话结论；每页用"结论式标题"。案例：门店+21%、用户+18%、收入仅+3%，结论为资源由拉新转向会员经营（70%拉新/30%会员 → 30%/70%）。
