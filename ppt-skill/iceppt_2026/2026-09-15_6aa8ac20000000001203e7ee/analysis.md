## 本篇主旨
以"思维模型/图表类型百科"形式输出系统化的商业分析模板库：每个模型一页（或一页配一页案例），统一结构为"定义结论句 + Core Idea（核心问题/适用场景/逻辑）+ 可视化 + 案例拆解"。本次读到的图片（01/02/03/04/06）均为三页纵向拼图，涵盖图表类（阶梯成本曲线、哑铃图、箱线图、漏斗图、桥形图、桑基图）与框架类（标杆分析、DMAIC、SCR、市场进入、Buy vs Build）。

注意：note.md 文字清单列的是 001-020 号模型（SWOT、波特五力等），而本次读到的图片编号是 050/051/062/063/068/069/074/075/077/086/096，二者并不对应，图片里的模型不在文字清单中，文字清单对应的页面多在未读图（含已跳过的重复图）里，不确定。

## 提炼出的设计规则
1. 每页固定四件套：标题条（英文名 + 页码）-> 一句结论/定义句（加粗）-> 图/框架主体 -> 注释/行动项。读者看完第一行即可知道结论。
2. 案例页的结论句用"黑色实心圆点 + 一句话含数据与判断"（如"流失率高达92%…敲定…策略"），定义页用"模型名(中文) - 一句定义"，且英文名加红色下划线。
3. 左 Core Idea 右图表的双栏范式（约 38%/62%）用于图表类型介绍页；左栏固定三块：核心问题 / 适用场景 / 逻辑，小标题统一用"英文 | 中文"并带白底标签。
4. 案例页范式：左图右三步（Step 1 核心命题 -> Step 2 拆解逻辑 -> Step 3 战略行动）或左问题右处方，Step 标签为圆角小标签。
5. 强调色面积严格克制：整页绿色占比约 5-10%，只用于关键数字、被选中项、对勾、标题下划线与关键流带；其余全部灰/浅灰。
6. 强调手法多样但不加色数：整列色带（桥形图"主要责任区"）、粗描边（Buy 方案）、大号数字（30%-50%、40%/60%、$1 Billion）、浅绿底块（SCR 的 R 区），一页最多 1-2 处。
7. 对比用"灰化被否决项 + 红叉 + 绿勾/绿描边选中项"，不用两个鲜艳色互相竞争。
8. 双组对比（Male/Female）用一对有区分度的色（紫+绿），并直接用同色文字标在图顶，省去图例框。
9. 图表尽量去掉装饰：浅灰网格或无网格，坐标刻度极小极淡，只标注与结论有关的数字（如阶梯图只标价格，不标全部数值）。
10. 标注框（callout）用细线引到图上对应位置，白底/浅灰底 + 细描边，一个图 2-3 个即可；框内三行结构：标题 / 核心数据 / 补充。
11. 流程类使用箭头连接的 2x2 环或横向五段 chevron，段内用超大衬线斜体字母（D/M/A/I/C）做视觉锚点，下方等宽五列，每列结构固定（核心任务/关键动作/交付物）。
12. 时间线类（SCR）上下交错放置标签与说明，避免同侧拥挤；对应"答案"的区域用整块浅色底放大面积。
13. 把"风险/陷阱"做成独立警示卡（如 "The Me-Too Trap"），放在右栏底部，描边卡区别于普通灰块。
14. 页脚/结语放一条浅灰通栏总结（核心原则、框架教训、"Time > Money"），三条以内，带圆形序号。
15. 密度很高：每页的正文字号小（约 8-10px 级，按 1080 宽图估算），属于"小红书图文 / 收藏型长图"风格，不适合直接用于现场演示，复用时需放大到演示级字号（不确定原 PPT 页面尺寸）。
16. 关键数据结论用大号细体绿色数字单独放（28-36px 级），与小字形成 3-4 倍字号反差，建立层级。

## 出现的思维模型/框架/方法论
图表类型（可视化方法）：
- Step Chart / Cost Curve（阶梯成本曲线，086）：用阶梯展示数量折扣与累计资金，标出"最优承诺量"而非最低价；案例：OEM 寻源谈判。
- Dumbbell Chart / Gap Chart（哑铃图，075）：两个端点 + 连线表现差距；案例：某社区大学男女入学率25年的剪刀差。
- Box and Whisker Plot（箱线图，074）：五数概括（最小值、Q1、中位数、Q3、最大值）+ 1.5×IQR 异常值；用法：剥离平均值陷阱；案例：Alex 成绩 82 分的位置、三区域销售额分布。
- Funnel Chart（漏斗图，077）：逐步转化 + 每步留存/流失；案例：SaaS 14天免费试用到付费，10,000 -> 800，整体转化 8%，流失 92%，诊断出 "Friction" 和 "Aha Moment" 缺位。
- Bridge Chart（桥形图/瀑布偏差图，068）：从预算到实际的因子分解（量-价-利 PVM）；案例：Q3 利润预算 $100M vs 实际 $80M，按销量/价格/组合/成本偏差拆分责任。
- Sankey Diagram（桑基图，069）：流量守恒，节点流入=流出；案例：渠道 -> 页面 -> 行为 -> 结果的用户流转。

分析/决策框架：
- Benchmarking Framework（标杆分析法，062）：四类（竞争性/职能性/内部/通用流程）+ 四步闭环（精准定位、深度采集、剖析差距、内化与超越），警惕 "Me-Too" 陷阱；案例：GroupM 向华尔街高频交易学习程序化购买（CPA 平均下降 30%-50%）。
- Six Sigma DMAIC（063）：Define / Measure / Analyze / Improve / Control，每段对应一个口语化问题（到底哪疼/量一量有多疼/为什么会疼/吃什么药/怎么防止复发）；帕累托（80/20法则）、鱼骨图、SIPOC、SPC 控制图为配套工具。
- SCR Framework（096）：Situation-Complication-Resolution，咨询汇报开头；三条原则：Situation 只讲必要背景、Complication 必须足够尖锐、Resolution 必须回应 Complication。
- Market Entry Framework（050）：Q1 市场值得进吗？Q2 我们能赢吗？Q3 怎么进才对？三问决策；案例：Uber 进入中国（Q1 Pass，Q2 No-go，实际选择了独立运营导致失败；40% 做错进入决策 + 60% 致命缺陷拆解）。
- Buy vs. Build Matrix（051）：2x2（战略控制需求 x 自建时间/成本），Build/Buy/License/Partner 四象限 + 五大诊断问题；案例：Facebook 10亿美元收购 Instagram（"Time > Money"）。
