# 抓住注意力的秘诀是“讲对方在意的事”：给每页PPT一个明确的问题（Done vs Well Done 对比案例集）

## 本篇主旨
汇报不要从“我做了哪些分析”开始讲，而要从“这些分析能帮听众判断什么”开始；给每一页 PPT 找到一个明确的问题，让分析、图表、结论围绕它展开。配图用 5 组“Done（文字表格堆砌的普通版）/ Well Done（视觉化重构版）”对比，演示同一内容如何从“信息罗列”升级为“有版式、有图形、有层级的页面”。

## 逐页拆解

### 01.jpg（蓝海战略案例：Nintendo Wii，编号 020）
**上半 Done（普通版）**
- 角色：模型案例页，信息全以文字+表格呈现。
- 版式：白色卡片，左对齐；标题 + 下划线 + 一句副标题；下方四个编号模块（1 从性能竞争转向家庭娱乐 / 2 ERRC 四步行动框架 / 3 竞争要素对比 / 4 案例结果与启示），2x2 近似网格（1、2 通栏，3、4 并排）。
- 图表：①两个灰框+箭头（原竞争边界 → 新市场空间）；②ERRC 三列表格（动作/调整重点/具体做法，4 行）；③竞争要素对比表（高/中/低文字，传统主机 vs Wii）；④三条要点文字。
- 配色：纯灰白黑，模块标题为浅灰底条，无强调色。
- 字体：标题黑体加粗约 24pt 级，副标题一句话约 14pt，表格字很小（约 8-9pt 级，不确定具体值）。
- 原文摘录：“蓝海战略案例：Nintendo Wii”“通过价值创新，把游戏机重新定义为全家都能参与的体感娱乐设备。”“1. 从性能竞争转向家庭娱乐”“2. ERRC 四步行动框架”“3. 竞争要素对比”“4. 案例结果与启示”。

**下半 Well Done（重构版）**
- 角色：同一内容的设计版，顶部标题条 + 一句话结论 + 左右分栏。
- 版式：整页圆角白卡；顶部圆角描边标题栏“Blue Ocean Strategy - CASE STUDY：Nintendo Wii 如何用 ERRC 四步法找到家庭娱乐蓝海？”，右上页码“020”；标题栏下一行黑圆点引导句“不与 PlayStation / Xbox 在性能红海中正面竞争，而是通过价值创新，把‘游戏机’重构为‘全家都能参与的体感娱乐设备’。”；下方左窄右宽两栏（约 1:2）。
- 左栏：“红海困局”（4 条带红色 × 图标的列表）→“新蓝海在哪里？”（两个浅灰/浅绿框+箭头：原竞争边界 → 新市场空间）→ 三个带图标的小标题（用户扩容 / 商业结果 / 战略意义）+ 一句说明。
- 右栏：“ERRC四步动作框架”，2x2 色块矩阵：Eliminate/Reduce/Raise/Create，每格顶部深绿色标签条（白字英文），格内大号首字母 E/R/R/C（细体浅灰）+ 中文动词“删除/减少/提升/创造”+ 2-3 条要点，格底有淡化的场景图作背景。
- 图表：矩阵下方为“关键竞争要素”点线图（斜率图/价值曲线）：左右两条刻度轴（低-中-高），传统主机（灰点灰线）vs Wii（绿点绿线），四个要素（画面性能·硬核内容 / 价格门槛 / 上手友好度 / 家庭互动），用折线呈现价值曲线差异。这是把上半的“高/中/低”文字表格转成图形。
- 配色：深绿（约 #0E7C66）作强调与标签条；灰点灰线作对照；红色 × 作负面标记；其余黑、灰、白。
- 字体：英文标题 Blue Ocean Strategy 粗黑无衬线约 20pt 级，后接细体副标题；模块小标题（红海困局等）为居中小字、带阴影细框；首字母 E/R/R/C 为大号细体；正文很小（约 8pt 级，不确定）。
- 关键文字：“红海困局”“新蓝海在哪里？”“ERRC四步动作框架”“Eliminate 删除：对顶级画质与超强算力的追逐 / 对硬核玩家的单一定位”“Reduce 减少：硬件规格复杂度、单机价格门槛 / 学习成本与控制器复杂度”“Raise 提升：上手友好度 / 家庭互动与客厅参与感、身体动作参与和娱乐感”“Create 创造：体感控制（Wii Remote）/ 面向全家人的休闲游戏场景 / 新非玩家需求：老人、女性、亲子、聚会娱乐”。

### 02.jpg（情景规划 Scenario Planning，编号 019）
**上半 Done**
- 角色：方法论介绍页（定义+情景表+步骤+价值）。
- 版式：单栏纵向堆叠四块：1 明确方向（文字框）/ 2 四种可能的情景（4 行 4 列表格：情景、主要变化、应对重点、示例动作）/ 3 使用步骤（4 个并列方框+箭头 ①→④）/ 核心价值（一行三段）。
- 配色：纯灰白黑。
- 原文摘录：“情景规划（Scenario Planning）”“战略不是预测未来，而是减少措手不及。”“识别关键不确定性，构建 2-4 个合理的未来情景，并为每种情景准备应对方案。”“情景 A：稳健扩张 / B：加速爆发 / C：监管收紧 / D：价值受质疑”“① 识别驱动因素 → ② 锁定关键不确定性 → ③ 设计应对动作 → ④ 建立预警信号”“思维转变：从押注一个答案，转向准备多种结果”。

**下半 Well Done**
- 版式：左侧窄栏为“行标签”（Definition 模型定义 / Scenarios 可能发生的情景 / How to use 模型怎么用 / Value 核心价值），英文细体较大（约 16pt 级）+ 中文灰色小字；右侧为内容区，行与行之间用细线分隔。这是“左标签列 + 右内容”的行式矩阵版式。
- 顶部：英文标题 Scenario Planning（粗）、右上 @ICEPPT 绿色衬线小字 + 页码 019；下方圆角描边“定义框”，内含红色下划线的模型名“Scenario Planning（情景规划）- 战略不是预测未来，而是减少措手不及”，之后一小段灰色长文解释（核心逻辑、与传统预测区别）。
- Definition 行：深绿横条“North Star Direction（大方向）”，下列 3 条要点，右侧放放大镜图标 +“例：企业未来三年进入 AI 驱动增长阶段”。
- Scenarios 行：四列并排卡片（Scenario A|稳健扩张 ... D|价值受质疑），列头为浅米灰底，每列 3 条要点 + “重点：…” + 底部灰色圆形徽标（中/高/中/高，概率或影响度标记，具体含义不确定）。
- How to use 行：四步 1.-4. 绿色序号数字 + 加粗步骤名 + 灰色说明，浅灰底带。
- Value 行：三段，每段一个线条图标（相机/靶心/列式图标）+ 标题 + 小字说明。
- 配色：深绿强调（定义条、序号、@ICEPPT），浅米灰/浅灰底，灰色圆徽标，红色下划线仅用于模型名。
- 字体：英文行标签约 16-18pt 细体；正文约 7-8pt（不确定）。

### 03.jpg（情景规划案例：Tesla 五年计划 2024-2028，编号 019）
**上半 Done**
- 角色：案例页，时间轴 + 大表格。
- 版式：标题 + 副标题 + 灰注“教学案例：以下为情景假设与应对示例。”；一行 5 个灰框带箭头（第 1 年 / 2024 → … 第 5 年 / 2028）；下方 4 列表格（年份 / 分析主题 / 关键情景（假设）/ 应对动作（示例）），每年 2 行，共 10 行；底部灰字“规划思路：识别不确定性 → 准备备选动作 → 持续监测与调整”。
- 配色：纯灰白黑。
- 原文摘录：“特斯拉五年情景规划（2024—2028）”“围绕需求、产品、供应链、监管与生态，提前准备关键情景与应对动作。”，如“需求下滑，Model 3/Y 降价后毛利率低于 15%”“加快低价车型 Model 2 的推进，以销量换取利润”。

**下半 Well Done**
- 版式：矩阵泳道。顶部圆角标题栏“Scenario Planning - CASE STUDY：Tesla（特斯拉）5年计划（2024-2028）”，右上 @ICEPPT + 019；黑圆点引导句“围绕需求、产品、供应链、监管与生态五类不确定性，提前规划2024-2028关键情景与应对动作。”。
- 主体：5 列（year 1-5，顶部为超大号细体数字 1-5，旁边竖排小字 “year”）× 5 行（左侧行标签 Phase 1 市场渗透 / Phase 2 产品扩张 / Phase 3 供应链韧性 / Phase 4 监管与竞争 / Phase 5 长期生态）。每列为竖向浅灰渐变长卡片，内容卡片按所属 Phase 的纵向位置放置，空位留白，形成“对角线/阶梯分布”，一眼看出各年份的关注重点随时间迁移。
- 卡片内：每张分上下两部分，上为灰色问号图标 + “情景（风险/假设）”，下为绿色对勾图标 + “应对动作”。
- 配色：灰白底渐变卡 + 绿色对勾；整体比 01/02 更克制，几乎无大色块。
- 字体：年份数字约 36-40pt 细体（极大）；Phase 标签约 16pt 细体 + 灰色中文小字；卡片文字极小（约 6pt 级，不确定）。
- 关键文字：“Phase 1 市场渗透”“Phase 2 产品扩张”“Phase 3 供应链韧性”“Phase 4 监管与竞争”“Phase 5 长期生态”。

## 提炼出的设计规则
1. **每页一个问题**：标题/引导句回答“这页帮听众判断什么”，不写“我做了XX分析”。Well Done 版每页都有一句黑圆点结论引导句（如“不与 PlayStation / Xbox 在性能红海中正面竞争，而是……”）。
2. **三层信息结构**：顶部标题条（模型名+副题）→ 一句话结论/定义框（红下划线标出模型名）→ 主体可视化 → 底部 Insight/价值。固定位置，每页复用。
3. **用图形替代表格**：把“高/中/低”文字表改为点线价值曲线（01）；把时间+主题表改为年份×阶段矩阵（03）；把漏斗改为阶梯条并用颜色区分新旧（05）；把 8 维度表改为带序号的宫格卡片（04）。表格只在需要精确数值时保留。
4. **行标签列版式**：用左侧窄列放“Definition / Scenarios / How to use / Value”等英文细体行标签，右侧放内容，每行用细线分隔，使方法论页结构可扫读（02）。
5. **强调色克制**：深绿只用于标签条、序号、关键节点，面积约≤10%（04 页甚至<3%）；其余用灰阶；负面用红×，下划线用红，且都是小面积。
6. **灰=旧/弱，绿=新/重点**：对比页用同一套色分配语义（05 页 AIDMA 灰、AISAS 绿；01 页传统主机灰线、Wii 绿线）。
7. **英文大标签+中文小注**：行标签、模块标题用“英文细体大字 + 中文灰色小字”双语，形成视觉层级与 nerdy 感。
8. **超大数字/首字母做装饰锚点**：大号细体数字（03 的 1-5）、大号首字母（01 的 E/R/R/C，05 的 A-I-S-A-S）作为版面锚点，同时帮助记忆框架。
9. **关键节点加记号**：用虚线框+星标（05 的 Search/Share）、徽标（02 的中/高）、对勾/问号图标（03 的 假设/应对）标出重点与状态。
10. **留白与稀疏分布也是信息**：03 页卡片按阶段在对角线分布，空位保留，让“关注点随时间迁移”可见。
11. **页码与署名固定在右上角**：数字页码（018-025）+ @ICEPPT 绿色衬线小字，做成系列感。
12. **卡片化**：整页是圆角白卡，内部模块用细描边/浅灰底分区，圆角+轻阴影，保持统一。
13. **文字密度**：单格要点 2-3 条，每条不超过一行；长解释只放在定义框，用灰色小字，降低权重。

## 字体与字号层级
- 标题：黑体/无衬线粗体。Done 版中文标题约 24pt 级；Well Done 英文标题（Blue Ocean Strategy、Marketing Funnel 等）粗无衬线约 20pt 级，后接细体副题。具体字体名不确定（中文疑似思源黑体/微软雅黑类，英文疑似 Arial/Helvetica 类）。
- 行标签/大标题装饰：英文细体（Light 类），约 16-20pt；03 页年份数字约 36-40pt。
- 署名页码：@ICEPPT 绿色衬线大写字母间距拉开，页码粗体数字约 18pt。
- Insight/强调词：绿色衬线体（Georgia/Times 类，不确定），约 16pt。
- 正文要点：约 7-9pt 极小字号（由 Well Done 版在手机图上的观感判断，真实 PPT 字号不确定），说明文字用灰色。
- 层级：标题（粗黑）> 行标签（细体大字）> 模块小标题（加粗小字）> 要点（常规灰小字）> 注释（浅灰）。

## 出现的思维模型/框架/方法论
- **蓝海战略 / ERRC 四步动作框架（Eliminate-Reduce-Raise-Create）**：用于从红海竞争转向新市场空间；案例 Nintendo Wii：删除对顶级画质/算力的追逐，提升上手友好度与家庭互动，创造体感控制与全家娱乐场景；用价值曲线对比传统主机与 Wii。
- **情景规划 Scenario Planning**：先确定“North Star Direction”，构建 2-4 个情景（A 稳健扩张 / B 加速爆发 / C 监管收紧 / D 价值受质疑），再设计应对动作并建立预警信号；四步：识别驱动因素 → 锁定关键不确定性 → 设计应对动作 → 建立预警信号。价值：思维转变（从押注一个答案到准备多种结果）、讨论落地、行动前置。
- **Tesla 五年情景规划案例（2024-2028）**：年份×五个 Phase（市场渗透、产品扩张、供应链韧性、监管与竞争、长期生态）的情景-应对矩阵。
- **JTBD 任务驱动理论（Jobs To Be Done）**：八个维度（核心任务、情境、用户角色、功能任务、社交任务、情感任务、成功标准、替代方案）；经典案例：奶昔（早晨通勤中需要打发时间并填饱肚子，竞争对手是其他奶昔、香蕉、面包，以及“不买”）；使用步骤：挖掘真实进展需求 → 关注情境与约束 → 比较所有替代方案 → 围绕任务设计方案。
- **营销漏斗 AIDMA / AISAS**：AIDMA（Attention-Interest-Desire-Memory-Action，传统媒体时代）vs AISAS（Attention-Interest-Search-Action-Share，互联网时代）；启示：Search 与 Share 是关键，重点转向 SEO/SEM 与口碑管理（KOL/KOC）。
- **Done → Well Done 重构法**：同一内容先文字+表格，再改为结构化可视化版式。

## 正文金句与方法
- “讲对方在意的事。”
- 准备汇报时容易从“我做了哪些分析”开始讲；但听众更关心“这些分析，能帮我判断什么？”
- 分析名 → 听众问题的改写示例：
  - 「市场分析」→ 这个市场，现在还值得进入吗？
  - 「用户画像」→ 下一阶段，我们应该优先服务谁？
  - 「护城河分析」→ 同样卖饮料，这个品牌凭什么被选择？
- 方法：“给每一页 PPT 找到一个明确的问题，再让分析、图表和结论围绕它展开。”
- “让听众知道这页与自己有什么关系，才能抓住他们的注意力。”
- 标签：pre、ppt、ppt模版、思维模型、数据可视化、storytelling、工作汇报、高效生产力、汇报技巧、商赛。
- 备注：正文讲的“问题导向”原则，与配图的版式重构（Done vs Well Done）是两条线；配图主要展示版式升级，而问题导向体现在 Well Done 版每页的“结论引导句 / 定义框”中（此为基于图片的推断）。
