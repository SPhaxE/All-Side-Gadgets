# 对独生脑好一点怎么了！——「认知卸载」与100思维模型+100案例外置思考库

## 本篇主旨
用「认知卸载」概念包装 iceppt 的 100 思维模型 + 100 案例可编辑 PPT 库：先用模型拆问题，再用案例演示落地，图表版式可直接沿用。本篇共12图，实际读到 3 张（05/07/08），均为「上：模型总览页 / 中：案例页（CASE STUDY）/ 下：另一个模型页」的三页纵向拼图（每张含 3 页，不是两页）。

## 提炼出的设计规则
1. 固定「总览页 + 案例页」成对：同编号同模型，上页讲框架（定义→结构→要点），下页用真实案例填数字，结尾 Insight 一句话。
2. 每页顶部三件套：模型名（粗大）/ 编号+水印 ID / 圆角定义条（1句粗体定义 + 2行灰字释义），释义不超过 2 行。
3. 层级用「颜色深浅 + 位置缩进」表达重要性（AARRR 由浅绿到深灰；Laggards 灰化），重点层用 2px 深绿描边+红色箭头/标签强调，一页只强调 1 处。
4. 数字单独放大：百分比/金额用衬线字体浅绿大字（约为正文 3-4 倍），指标名用小号灰字，实现「一眼看数字」。
5. 树/流程图每列顶部加圆角胶囊标签（Level1-4 / 阶段名）；列内卡片等宽、等间距，连线用细灰线或虚线箭头。
6. 虚线框 = 辅助/待验证/过渡内容（行动、断层、对照箭头）；实线框 = 主体内容。
7. 同一卡片内部结构模板化（用户画像→特征→策略→清单），横向多栏时每栏字段完全对齐。
8. 中英文双语并置：英文大/衬线、中文小/灰，英文承担「设计感」，中文承担信息。
9. 结论条（深绿描边/带星标/黑圆点句）每页最多一条，位于页底或标题下。
10. 图表首选「示意图而非数据图」：韦恩图、同心圆、阶梯条、钟形卡片、树状图，均为形状+文字，可在 PPT 内直接编辑。

## 出现的思维模型/框架
- Value Driver Tree（价值驱动树）：把企业价值层层拆到一线可执行动作；案例：SaaS ARR $10M 拆到 Win Rate/SQL/NRR/Churn 与4个行动。
- 3C's Model（大前研一战略三角）：公司/顾客/竞争对手，三者交集为战略甜蜜点（本篇未读到案例页）。
- Adoption Curve（创新扩散曲线 + 鸿沟）：五类人群占比 2.5/13.5/34/34/16%；案例：Zoom 靠「一键加入」+疫情黑天鹅跨越鸿沟。
- TAM-SAM-SOM：市场规模逐级收窄，强调 SOM 自下而上估算；本篇未读到案例页。
- 4C Model（劳特朋）：4P 到 4C 视角转换；案例：海底捞（翻台率 4.0x，NPS +70）。
- AARRR Funnel（海盗模型）：获取/激活/留存/变现/推荐，留存为「增长基石」；本篇图中无案例页。
- 另在 note.md 标签出现：SWOT分析、安索夫矩阵（对应图未读，不确定内容）。

## 正文金句与方法（note.md）
- 「认知卸载，就是把一部分信息交给外部工具整理，让大脑专心做判断。」
- 「当大脑同时处理内容和呈现，注意力会被来回切换的任务占满。」；「方案思路已经有了，打开空白PPT还是会卡住，因为结构也在等你现场搭建。」
- 方法：模型先把问题拆开，案例再演示思路怎样落地；遇到具体 case，顺着场景找合适框架，散着的信息很快接起来。
- 每个案例做成可编辑页面，图表版式直接沿用：「内容想清楚以后，PPT也顺手完成了。」
- 结尾钩子：「给大脑配一套外置思考库」。数据：47赞/44收藏，12图，标签含 #数据可视化ppt #ppt模板。
