# 审P积累：PREP / FAB / BAB / Answer First / 蝴蝶图 / 气泡图 模型页拆解（编号 091-098、071-072）

## 本篇主旨
本篇是"nerdy 风"PPT 模板库的又一批积累：把汇报与表达思维模型（PREP、FAB、BAB、Answer First）和数据可视化图表（蝴蝶图、气泡图）做成统一版式的"理论页 + 案例页"。每个模型先用一页讲清定义、为什么有效、步骤，再用一页真实案例（电梯汇报、售后转型、商务谈判、两代职场人价值观）演示怎么落地。

note.md 说明：标题"审P积累中……"，正文只有 10 个话题标签（数据可视化ppt、思维模型、汇报技巧、工作汇报、商赛、PPT排版、nerdyppt 等），没有文字 tips。共 13 张图，本次只读 01-03（04-13 为重复图）。

**01-上：PREP Framework（编号 091，理论页）**
- 页面角色：思维模型"理论页"，讲 PREP（观点-原因-案例-重申）。
- 版式与网格：
  - 顶部一条标题栏：左"PREP Framework"粗黑体，右"@ICEPPT 091"（@ICEPPT 为衬线/等宽感绿色小字，091 为大号粗黑数字）。
  - 标题栏下方是圆角描边的"定义框"：第一行"PREP Framework (观点-原因-案例-重申) - 即兴发言/Short pre"，"观点-原因-案例-重申"带红色下划线；下面两三行小字定义。
  - 左下小块"为什么PREP有效？"，列 4 条编号要点（①符合认知规律 ②时间效率 ③记忆锚点 ④灵活扩展），每条"粗体小标题 + 灰色说明"。
  - 右上一排 5 个圆角胶囊标签（电梯推销、危机公关、投资人路演、快速汇报、媒体采访）= 应用场景。
  - 主体图：四列"阶梯"卡片，从左到右 Point / Reason / Example / Point Restate，高度错落（Example 最高，被放大、绿色描边加阴影，作为重点）。每张卡片结构：顶部大号细体英文词（约 36-40px 视觉大小）+ 中文小标题（观点/原因/案例/观点（重申））+ 白色圆角内框写要点 + 底部灰底"示例："小块。
- 图表类型及画法：非数据图，是"四步流程卡片"；用卡片高低错落表达节奏，案例卡片突出。
- 配色：白底 + 浅灰卡片底（约 #F2F2EE）+ 深绿描边/淡绿填充（Example 卡片）+ 黑字。
- 字体层级：英文大词细体（最大）> 页标题粗黑体 > 卡片中文小标题粗体 > 正文小字灰 > 示例文字更浅灰。
- 关键文字原文摘录：
  - "PREP 强迫你把结论前置，让听众在第一句话就知道你要说什么。"
  - "开门见山，直接抛出你的主张或结论。避免铺垫，让听众立即知道你的立场。"
  - "用逻辑或数据支撑你的观点。回答「为什么」，建立因果链条，让听众理解你的推理路径。"
  - "用具体事实、数据或故事佐证你的原因。让抽象逻辑变得可感知、可验证，增强说服力。"
  - "回到起点，用更简洁、更有力的语言重申观点。强化记忆，推动行动。"
  - 示例："我们应该立即启动 B2B 转型。""因为 C 端市场增长停滞，而企业客户 LTV 是个人用户的 12 倍。""Slack 从游戏公司转型 B2B SaaS 后，估值从$0增长到$27B。""所以，B2B 转型是我们的唯一出路，建议下周启动战略评估。"

**01-下：FAB Model（编号 092，理论页）**
- 页面角色：FAB（属性-优势-利益）理论页，产品推销话术/价值主张。
- 版式与网格：标题栏同上；定义框同上（"FAB Model (属性-优势-利益) - 产品推销话术/Pitch/价值主张"，"属性-优势-利益"带红下划线）。主体是一个半透明灰色大箭头从左下向右上爬升，三个圆形字母 F / A / B 沿箭头逐级升高：F 最小、最低（白底绿描边）；A 中等（浅绿底绿描边）；B 最大最高（深绿实心、白字）。每个圆下方：英文词（细体大字）+ 中文小字、一个"第一级：产品本身 / 第二级：竞争差异 / 第三级：客户价值"圆角标签，再往下是"核心定义"+ 点线框 + 要点列表 + 底部"示例："框。
- 图表类型：阶梯上升箭头 + 圆形节点，大小/颜色深浅 = 价值层级递增。
- 配色：F→A→B 由白→浅绿→深绿渐变，表达"越往右越重要"。
- 关键文字摘录："Feature｜特征 第一级：产品本身""Advantage｜优势 第二级：竞争差异""Benefit｜利益 第三级：客户价值"；B 的核心定义："产品为客户带来的实际价值与情感满足，回答「对我有什么好处」"；A："产品相对于竞品的差异化优势，回答「为什么选择你们」"；F："产品的客观属性、技术参数、功能配置，回答「这是什么」"。示例（F）："这款笔记本电脑搭载 M3 芯片，16GB 内存，512GB SSD。"；示例（A）："M3 芯片比上一代性能提升 40%，同时功耗降低 30%，续航时间延长至 18 小时。"；示例（B）："你可以连续工作一整天不充电，在咖啡厅、飞机上随时高效办公，不再为电量焦虑。"
- 定义文字中提到：FAB 由美国销售学者 E. K. Strong 提出，后经 Xerox 等企业销售培训体系发展成型（此为图中原文，未核实）。

## 提炼出的设计规则
1. 理论页统一"五段式"骨架：页标题栏（模型名 + 编号）→ 圆角定义框（中英文名 + 一句话用途 + 2-3 行定义）→ 主体示意图 → "为什么有效/适用场景/步骤"侧栏 → 示例。固定骨架让整套页面一眼可识别。
2. 理论页 + 案例页成对出现：理论页讲"是什么"，案例页用同一模型的真实场景套一遍（标题格式 "模型名 - CASE STUDY：具体场景"）。
3. 案例页标题下必须有一行"黑色实心圆点 + 粗体"的一句话总结，写结论与量化结果（例："服务收入占比可从8%跃升至25%"）。
4. 全页只用"绿 + 灰 + 白"三色体系；强调色（深绿）用在最重要的 1-2 个元素上（节点圆、关键数字、重点卡片），目测面积约 ≤10%-15%；其余信息用浅灰、浅绿底衬。
5. 图表里"只染关键，其余灰"：蝴蝶图中仅被强调的条（如 91/87/88）用绿色，其余全部浅灰；BAB 柱状图全部浅灰，把颜色留给右侧指标数字。
6. 关键数字放大并上色（约为周围文字 2 倍字号，绿色/橙色），带 ▲▼ 前缀与单位（35%、18pct、2.3x、+23%、$2.6M）。
7. 在图上直接做注释：用圆角小标签（"弹性办公优先""2x 胜出"）和带指示点的白底注释框，代替图例与长说明；高亮带（浅绿矩形底）圈出被强调的几行。
8. 用递进/高低错落表达层级：PREP 四张卡片高度错落且重点卡（Example）放大加描边；FAB 三个圆沿上升箭头由小到大、由浅到深。大小 + 颜色深浅 = 重要性。
9. 对比表用 ✓（绿）/ ✗（红）矩阵，红色仅用于负面标记；变化列统一用"绿色圆点 + 绿色百分比"。
10. Before / After / Bridge 三栏用灰色大 chevron 箭头连接，左栏灰（现状压抑）→ 中栏绿字目标 → 右栏浅绿底面板承载"路径"，颜色由灰到绿暗示状态改善。
11. 图标统一为细线条、灰/绿单色线稿，放在圆形浅绿底或白卡左侧；不使用彩色插画。
12. 长英文标题字（Point / Reason / Core Idea / Insight）用细体大字号，与粗体中文标题形成粗细对比，增加设计感；中文正文保持小字灰色。
13. 所有说明区块用"圆角卡 + 浅灰底/细描边"分组，卡内再用小标签条（The Core Problem｜核心问题）做区块头，保证高密度信息仍可扫读。
14. 蝴蝶图技巧：按数值降序排列使两翼呈漏斗；中轴用深色细竖线；类别标签居中、英文灰小字在上、中文黑粗字在下；左翼数据输入负数（图中小注明确提示）。
15. 气泡图技巧：面积（非半径）正比于数据；用虚线十字划四象限并给每象限命名，直接导出战略动作；只把一两个目标气泡上绿色，其余灰。

## 出现的思维模型/框架/方法论
- PREP（Point-Reason-Example-Point restate）：用于即兴发言、电梯汇报、投资人路演、快速汇报、危机公关、媒体采访。案例：90 秒电梯汇报讲抖音电商退货率（0s 观点 / 30s 原因 / 60s 案例对比 / 90s 重申+行动）。示例：Slack 从游戏公司转型 B2B SaaS，估值增长至 $27B。
- FAB（Feature-Advantage-Benefit）：产品推销话术、Pitch、价值主张。用法：从产品属性→相对竞品优势→客户获得的利益逐级升级，最后落到"对我有什么好处"。案例：M3 笔记本（芯片→性能提升 40%/功耗降 30%→一整天不充电）。
- BAB（Before-After-Bridge）：现状→目标→路径。案例：工业设备制造商把售后服务从拖累业务（占比 8%）转为第二增长曲线（目标 25%），路径为智能化、服务产品化、数据变现。
- Answer First（答案先行，麦肯锡式）：结论先行→背景简述→关键证据（2-3 个）→细节补充；适用于邮件、PPT 每页首句、即兴问答、对高管沟通。案例：B2B 工业设备企业商务谈判，先答 ROI 再展开，利润率 +23%、提案胜率提升 45%。
- 蝴蝶图（Butterfly / Tornado Chart）：双向对比两类群体在同一组维度上的差异。案例：Gen Z vs Millennials 工作价值观。
- 气泡图（Bubble Chart）+ 四象限：X/Y 两变量 + 面积第三变量，如麦肯锡/GE 矩阵、BCG 矩阵（问题业务/瘦狗/现金牛）。案例：战略业务组合分析。
- 其他：Core Problem / Application / Logic 三段式讲图法（用于每个图表理论页的左侧栏）。
