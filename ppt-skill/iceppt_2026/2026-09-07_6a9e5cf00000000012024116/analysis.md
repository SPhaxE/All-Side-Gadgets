# 我将无条件拥护nerdy绿（NSM / Ansoff / 3 Horizons / 箱线图 / 阶梯成本曲线 / 哑铃图）

## 本篇主旨
以统一的"nerdy 绿"（浅青灰底 + 墨绿强调）展示一套"思维模型 + 数据可视化"PPT 模板页（编号 008、013、014、074、075、086）。每页 = 框架/图表名 + 案例标题 + 一句结论 + 图 + 右侧/下方解读，面向工作汇报场景。笔记正文只有标签，没有 tips 文字。

### 01.jpg 上：008 NSM（North Star Metric，北极星指标）
- 页面角色：概念科普页（框架介绍页，不带案例数字）。
- 版式：页面外框为白底圆角描边大卡片。顶部左为标题 "NSM（North Star Metric）"，右上角为大号页码 "008"。其下是一条圆角描边的"定义条"，内含带下划线的中英文名称 + 副标题 "唯一重要的指标" + 两行小字说明。
- 中部为"左—中—右"三栏：
  - 左栏：5 步流程（序号圆点 1~5，右对齐），每步为"粗体小标题 + 灰色小字说明"。小标题：明确核心价值主张 / 识别关键用户行为 / 定义可衡量的指标 / 验证与筛选 / 持续优化与迭代。
  - 中栏：浅灰圆形 "North Star Metric"，外有同心细圆环，左侧有提问气泡"如何找到北极星指标？"，圆下方有一个小图标。
  - 右栏：浅青绿色的大梯形/扇形底块（由圆向右展开），5 行"墨绿圆点 + 粗体标签 + 一句话"：本质 / 作用 / 数量 / 特点 / 举例。
- 底部：一条墨绿细横线分隔，下方一行"常见误区"，左为粗体标签，右为 5 个"线性圆形图标 + 粗体小标题 + 两行灰字"：把过程指标当NSM / 有多个NSM / 与长期价值相关 / 团队无法影响 / 一成不变。
- 图表类型：无数据图，是概念图（圆 + 放射梯形 + 流程列表 + 图标行）。
- 配色：背景浅青灰；卡片白；强调墨绿（圆点、分隔线、标签）；右侧大块用浅青绿；正文黑/深灰；左栏说明用浅灰（弱化）。
- 字体字号：标题粗黑体，约 24pt 级；定义条名称约 14pt 粗体；正文 8-10pt 级；页码最大且粗。无衬线黑体。
- 关键原文摘录：
  - "NSM（North Star Metric）"、"North Star Metric（北极星指标） - 唯一重要的指标"
  - "它的核心逻辑是：一家公司在任何阶段，都应该找到唯一一个最能反映用户真实获得价值的指标，并以此作为全公司对齐的增长方向。"
  - 右栏："本质 衡量用户价值的核心指标"；"作用 指引方向，驱动长期增长"；"数量 1个（其他常见指标往往是多个）"；"特点 与长期价值强相关，可被团队直接或间接影响，随产品阶段可能变化"；"举例 Spotify：有效播放时长 / LinkedIn：产生有意义的职场关系数"
  - 误区："把过程指标当NSM：如注册数、活跃用户数，它们是结果，不是价值"、"有多个NSM：会导致团队分散资源，失去聚焦"、"与长期价值相关：短期好看但不创造长期价值，无法驱动可持续增长"、"团队无法影响：如果团队无法影响该指标，就无法驱动增长"、"一成不变：不同阶段的NSM可能不同，需要持续校准"

  - 市场渗透："提升份额 / 提高频次 / 强化渠道效率；使用方法：优先做低风险，可快速兑现的增长动作"

  - 常见局限："只提供方向，不直接回答优先级"、"忽略组织能力与利润结构差异"、"多元化不等于一定成功"

## 提炼出的设计规则
1. 全套模板固定骨架：左上 "框架/图表名（粗体）+ - CASE STUDY：…（常规体）" 同一行，右上角超大粗体页码（如 008/013/074），标题栏下方一条结论句。
2. 案例页必有一条以黑色实心圆点开头的"结论句"（加粗，一句话讲清结论/洞察，整行横跨版心，约 1~2 行），先结论后图。
3. 概念页（008、013）在标题下加一个圆角描边的"定义条"：粗体带下划线的中英文名 + 一句 slogan（"唯一重要的指标""企业制定增长战略时的标准起点"）+ 2 行小字说明。
4. 页面分区：每张幻灯片是白色圆角卡片，内部再用圆角细描边/浅底分块；块间距统一，按"标题区 → 图区 → 解读区"从上到下、从左到右阅读。
5. 墨绿（强调色）只用于：关键数据、重点图形、标签胶囊、对勾图标、分隔线；大面积用白 + 浅青灰。强调色面积保持在整页约 10%~15% 以内。
6. 图表中"只给要讲的对象上色"：其余图元统一灰/墨绿细线，需要对比的两个对象用不同色相（橙 vs 紫、紫 vs 绿），并在图顶用同色文字标注角色（High Variance / Consistency Engine；Male / Female）。
7. 图上直接做批注：用白色圆角带阴影的批注卡 + 虚线引导线指向图中位置（阶梯图的三张卡），卡片内结构固定为"标题（粗）→ 核心数据（灰小字）→ 3 行键值对（关键数字用强调色）"。

9. KPI 前后对比用"旧值灰 → 新值墨绿粗体"的卡片行（如 16.8% → 19.2%），每卡一个指标名 + 一对数字，4 张并排等宽。
10. 步骤/流程型信息用"Step 1/2/3"胶囊标题 + 白色阴影卡片纵向叠放；每卡内部用"小标题 + 灰底条 + 要点"分层（现象 → 拆解 → 行动）。

12. 概念页收尾加"常见误区"一行：5 个图标+小标题+两行说明等分横排，用线性圆形图标（统一线宽、单色）。

## 出现的思维模型/框架/方法论
- NSM / 北极星指标：用法"5 步找指标（价值主张→关键行为→可衡量指标→验证筛选→迭代）+ 5 个误区"；案例 Spotify（有效播放时长）、LinkedIn（有意义的职场关系数）。
- Ansoff Growth Matrix 安索夫增长矩阵：用法"产品 x 市场 的 2x2，四象限=市场渗透/市场开发/产品开发/多元化，风险递增：市场渗透 < 市场开发 ≈ 产品开发 < 多元化"；每象限给"使用场景"。
- 3 Horizons 三层次增长：用法"H1 守住核心利润，H2 孵化第二曲线，H3 验证未来机会"；案例"某工业设备制造商布局 AI 预测维护"，配 KPI 前后对比 + 3x3 地图 + 每层任务/关键动作。
- Box and Whisker Plot 箱线图：用法"用中位数/四分位识别'均值陷阱'，区分机会主义者与稳健产能引擎"；案例"销售业绩审计 Jardine vs Smith"。
- Step Chart / Cost Curve 阶梯成本曲线：用法"用阶梯报价 + 累计资金找'最优承诺量'，对比保守/最优/极限三种量级"；案例"OEM 寻源谈判"。
- Dumbbell / Gap Chart 哑铃图：用法"两端点对比 + 差距随时间变化"，揭示总量掩盖的结构性分化；案例"社区大学男女入学率剪刀差"。
- 分析叙事套路："现象 → 拆解 → 行动"（Step 1 核心命题 / Step 2 拆解逻辑 / Step 3 战略行动）；"结论先行 + 图 + 解读"。
