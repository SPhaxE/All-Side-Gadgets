# cozy vibe（思维模型信息图合集：金字塔 / SIPOC / 哈维球 / CLV-LTV / MOT / 帕累托）

## 本篇主旨
用统一的"绿灰 nerdy 信息图"模板，把 6 个常用商业思维模型（Pyramid Principle、SIPOC、Harvey Balls、CLV/LTV、MOT、Pareto）各做成一页"定义 + 图解 + 案例/应用"的知识卡，适合做汇报、商赛的框架参考。note.md 只有标题和标签，没有正文 tips。

说明：01.jpg、02.jpg 各是上中下 3 张幻灯片竖向拼成，外面是淡青灰底的大画布，每张幻灯片是白底圆角描边卡片。每页右上角有编号（087/064/078/027/040/056），应是模型库序号。

### 01.jpg 上：The Pyramid Principle（087）
- 角色：思维模型知识卡，讲"结论先行、以上统下"。
- 版式：标题行（左英文大标题，右上编号）；下方一个圆角框放"中英文名 + 一句话定位"，再用小字写定义；主体左右分栏，左约 60% 画金字塔，右约 40% 放"7±2 chunks"和"战略应用场景"。

- 右栏：绿色手写体风格的"7 ± 2 chunks"，下面是加粗副标题和 2 条要点；再下面是灰色渐变横幅"战略应用场景"；再下面是 3 个绿色圆底白字编号（1/2/3）列表，每条"粗体标题 + 灰色小字解释"。
- 配色：浅绿金字塔、深绿数字圆点和线、灰字正文，全页以绿 + 灰为主。
- 字体：英文标题粗黑无衬线（约 24-28pt 量级）；模型名行粗体带下划线样式；正文极小字号灰色，约 7-8pt 量级；手写体仅用于"7±2 chunks"。
- 关键原文：
  - "The Pyramid Principle (金字塔原理) - 结论先行，以上统下"
  - "由麦肯锡首位女咨询顾问芭芭拉·明托(Barbara Minto)提出……金字塔原理反转了人类'先讲过程，再出结论'的自然表达习惯，强迫汇报者采用'自上而下'的倒叙结构。"
  - "7 ± 2 chunks / 人类短期记忆容量有限"；要点：线性叙事导致信息过载与逻辑迷失；听众无法快速抓取核心结论与支撑逻辑
  - 应用场景：咨询报告撰写（先结论后依据，确保高管快速理解）、战略提案演讲（自上而下展开，避免听众迷失）、复杂问题拆解（MECE分组，确保逻辑完整无遗漏）

### 01.jpg 中：SIPOC Model（064）
- 角色：流程管理模型知识卡。
- 版式：标题行 + 定义框；主体是 5 等分横向卡片（S/I/P/O/C），每张卡上方一个圆形字母徽章，下方是灰色标题条，再往下是白色内容区，最底是浅绿色"举例"条；底部整行"战略启示"灰底说明。
- 图表画法：5 列并排卡片，列间距相等；"P Process"这一列用深绿粗描边圆角框突出，其他 4 列是灰细线框。每列结构统一：定义、关键追问（或核心要求/核心准则）、举例（咖啡店）。
- 配色：灰底卡片 + 白内容区 + 浅绿举例条；强调列用深绿描边，面积占比约 1/5。
- 字体：标题粗体；列内正文约 6-7pt 量级；字母徽章是细线圆圈里一个大号灰黑字母。
- 关键原文：
  - "SIPOC Model (流程图谱) - 以极其精简的五步全景视角，界定业务流程边界与上下游关系的'上帝地图'。"
  - Supplier 关键追问："谁是这个流程的发起者？(内部的 IT 部门，还是外部的原料商？)"
  - Input："如果缺少了什么，这个流程根本无法启动？"
  - Process 核心要求："极度克制。只能写 5-7 个宏观步骤，绝对不要写细枝末节的判断分支。"举例：接收订单 → 研磨咖啡 → 萃取浓缩 → 打发牛奶 → 混合出杯
  - Output："这个流程的核心交付物到底长什么样？"
  - Customer 核心准则："客户不一定是付钱的消费者，也可能是公司的下一个环节"
  - 战略启示：顶级顾问在实操时往往采用 COPIS（反向构建法）：先明确谁是最终客户(C)，再倒推需要什么输出(O)、什么流程(P)、什么输入(I)、什么供应商(S)。"以终为始"是避免设计出"完美的无用流程"的唯一法则。

### 01.jpg 下：Harvey Balls - CASE STUDY（078）

- 版式：标题行"Harvey Balls - CASE STUDY：利用哈维球高效进行比稿决策（3家不同的 AI 风险评估系统供应商）"；标题下一行以黑色实心圆点开头的结论句；下方左右分栏，左约 55% 是评分矩阵表，右约 45% 是"Kill Criteria"和"Insights"。三个模块用灰底方块数字 1/2/3 编号。
- 图表画法：
  - 矩阵：行是评估维度（技术与算法、实施与合规、商业条款 3 个类目，各含 1-2 个指标，中英双语），列是供应商 A/B/C；表头为灰色填充白字；类目行是浅灰条；单元格里放哈维球（空心、1/4、半、3/4、全满），**球用深绿色**。右上方有图例"Attractiveness: Strong ● ... ○ Weak"。
  - Kill Criteria：左边 3 个维度（模型透明度、本地部署、全球实施经验）用灰描边小框，经虚线箭头指向右侧"Yes / Yes / No"，Yes 红字、No 黑字。

- 配色：灰表头、深绿哈维球、红色 Yes（只用在最关键的判定词上），整体仍是绿灰。

- 关键原文：
  - 结论句："多维评估矩阵清晰暴露了头部方案的合规风险与传统方案的技术短板，最终锁定在算法透明度与本地化部署上具备压倒性优势的供应商 B 为最优解。"

  - 2："Kill Criteria（一票否决项）"，维度 / 是否一票否决
  - 3："Insights"：致命红线——淘汰 A 与 C；决定性长板——入围 Vendor B；风险对冲计划——建议银行法务部在与 Vendor B 签署合同时，加入严苛的 SLA(服务级别协议)延期罚款条款。

### 02.jpg 上：CLV/LTV - CASE STUDY：Netflix（027）
- 角色：案例页，讲 Netflix 如何通过降低流失率把 LTV 提到 CAC 的 3 倍以上。
- 版式：标题行 + 黑点结论句；下面分左右两大块：左约 30% 为"The Unit Economics 单客经济模型"的 STEP 1/2/3 竖向公式卡；右约 70% 为"Strategy to boost LTV 提升LTV策略"的 2×2 卡片网格。两个区块顶部各有一个带阴影的灰色标签条。
- 图表画法：
  - 左侧三步：STEP1 Calculate CAC（获客成本，公式 CAC=总营销费用÷新增付费用户数，Netflix: ~$40-$50）；STEP2 Calculate LTV（LTV=(ARPU×Gross Margin)/Churn Rate，ARPU 月费 ~$15，流失率 <2.5% 以红字加橙色小标注，Lifetime ~40 Months，LTV≈$290）；STEP3 The Ratio（LTV : CAC = 6 : 1，对勾图标，"极度健康（网飞借钱拍片的底气）"）。每步为灰色粗边框卡片，步骤名用浅灰小字、卡标题用斜体衬线。
  - 右侧四格：Strategy 1 Original Content 的大数字 $17B（每年投入金额，代表作《怪奇物语》《鱿鱼游戏》）；Strategy 2 Pricing Power 的 $9-$15（价格演进，每2-3年涨价一次）；Strategy 3 Global Expansion 的 190+（国家覆盖）；第四格 Churn Rate Comparison 是横向条形图：Netflix 2.4%、Hulu 4.5%、Disney+ 5.2%，Netflix 条为浅棕黄/米色，其余灰色。每个大数字格底部有一条白色"原因/机制"小条（Lower Churn 降低流失 等）。
  - 条形图下方有绿灰色圆角提示框："对于 Netflix 来说，流失率是最大的敌人。只要流失率降低 0.1%，LTV 就会显著提升……"
- 配色：大数字用**浅绿色细体大字**（约 40pt 量级），卡片底为米灰；条形图 Netflix 用暖色米黄以区别于灰色竞品；少量红/橙作警示。
- 字体：大数字细体无衬线、字号最大；卡标题斜体衬线（Calculate CAC 等）；其余小字号。
- 关键原文：
  - 结论句："通过巨额内容投入降低流失率(Churn Rate)，Netflix 将单客终身价值(LTV)提升至获客成本(CAC)的 3 倍以上。"
  - Churn Rate Comparison：Netflix 2.4% / Hulu 4.5% / Disney+ 5.2%
  - Strategy 3 机制："Scale (规模效应) 分摊了内容制作的固定成本，提高了毛利率"

### 02.jpg 下：Pareto Principle (80/20)（056）
- 角色：模型知识卡 + 图表，讲 80/20 法则。
- 版式：标题行 + 定义框（粗体名称、一句话定位、小字定义）；下方左约 62% 是"The Pareto Chart 帕累托图解"，右约 38% 是"Application 三大核心应用场景"，两栏之间有一条竖向浅灰分割线。
- 图表画法：双轴帕累托图。左 Y 轴为 Revenue（¥ Million，营收百万元，0-250），右 Y 轴为 Cumulate %（累积百分比，0%-120%）；X 轴是 Prod. A 到 Prod. H 共 8 个产品，按营收降序：约 220、180、120、80、50、30、15、5。柱子为极浅灰/白色细柱，累积线为深绿色折线带圆点，标注累计占比 31%(A) → 57%(A+B) → 74%(A+B+C) → 85% → 92% → 96% → 98% → 100%。80% 处用一条纵向虚线 + 一个棕黄色实心大圆点标出，上方气泡"杠杆点 (The Leverage Point)"。图上有两个虚线框注解："关键少数 (20%) 贡献 80%营收"和"无用多数 (80%) 贡献 20%营收"。图例在底部（单产品线营收 / 累计产品线营收）。
- 右栏三段："产品组合优化""客户关系管理""质量控制与流程优化"，每段为浅灰条标题，前面带一个渐淡的灰绿三角（▶，深→浅），段内先"现象："再"战略动作："。
- 配色：折线和关键标注深绿，强调点用棕黄/橙，柱子用极浅灰，使折线成为主角。
- 字体：标题粗黑；图表轴标签小字；右栏"现象/战略动作"小字，"战略动作"为粗体。
- 关键原文：
  - "Pareto Principle (80/20) (帕累托分析) - 揭示投入与产出之间极度不平衡现象的资源聚焦框架。"
  - 定义：源自意大利经济学家维尔弗雷多·帕累托……大约 80% 的结果往往源自于 20% 的原因……强调决策者将极其有限的资源集中投注在那些能产生最大杠杆效应的"关键少数 (Vital Few)"上，同时无情地砍掉外包那些"无用多数 (Trivial Many)"。
  - 产品组合优化：仓库里塞满了上千种商品，但分析后发现，只有 20% 的核心品贡献了 80% 的优质利润。战略动作：设立产品组合健康审查，识别贡献不足平均 20% 收入的"尾部 SKU"，将释放出的资金和精力重新投入到爆款的迭代升代中。
  - 客户关系管理：销售团队每天忙于应付所有的客户投诉，但 80% 的营收其实是由 20% 的头部大客户带来的。战略动作：非对称资源分配……对于剩下 80% 的散客，引导使用"自助服务"或标准化产品。
  - 质量控制与流程优化：生产线上每天出现 10 种不同的残次品，工程师疲于奔命试图解决所有问题。战略动作：抓大放小。集中整个团队的火力彻底解决这根源问题，整体良品率将获得跃升。

## 提炼出的设计规则
1. **统一"知识卡"骨架**：每页固定为 标题行（左英文模型名 + 右上编号）→ 一行"中文名 + 一句话定位"→ 小字定义 → 图解主体 → 应用/启示。多页之间换内容不换骨架，形成系列感。
2. **案例页多一句结论**：案例页标题格式"模型名 - CASE STUDY：公司名 + 一句话"，下面紧跟黑色实心圆点 + 粗体结论句（一句话说清"做了什么、得到什么数字"）。结论先行，与 Pyramid Principle 自洽。
3. **一个主色 + 灰阶**：整套只用深绿（强调）+ 浅绿（填充）+ 灰（其他），强调色面积控制在每页约 10-20%；红/橙/棕黄只在 1-2 个关键点出现（Yes 判定、流失率<2.5%、80% 杠杆点）。
4. **用颜色/描边区分"重点 vs 非重点"**：SIPOC 只给 Process 列加深绿粗描边；MOT 只给 SMOT/UMOT 实心点和卡片加绿描边；Netflix 条形图只给 Netflix 一根暖色条，其余灰。同一组元素里只突出 1-2 个。
5. **大数字当视觉锚点**：关键指标（$17B、$9-$15、190+、365、75%）用细体大字号（约为正文的 4-5 倍），旁边只配一个中文单位词和一行要点，其余信息放下方白色小条。
6. **两栏+注释引线**：图解放左（约 55-65%），文字结论放右；图上的概念注释用细线引到图中位置（金字塔的"结论先行/MECE分组/逻辑递进"），避免在图里堆字。

## 出现的思维模型/框架/方法论
- **The Pyramid Principle 金字塔原理（Barbara Minto）**：结论先行、以上统下；论点用 MECE 分组，层层递进支撑。案例：进入东亚市场（市场规模大/竞争强度低/政策环境友好 → 各自下挂数据）。注：7±2 chunks 说明人类短期记忆容量有限。
- **MECE**：相互独立、完全穷尽，用于金字塔同层论据分组。
- **SIPOC（Six Sigma）**：Supplier / Input / Process / Output / Customer 五步全景图，流程宏观步骤限 5-7 步。案例：咖啡店。配套方法 COPIS（反向构建，以终为始）。
- **Harvey Balls 哈维球**：用 0/25/50/75/100% 填充的圆表示满足程度，做多维度比稿。案例：3 家 AI 风险评估供应商选型，加 **Kill Criteria 一票否决** 作先筛选。
- **CLV/LTV 与 CAC（单客经济模型）**：CAC=总营销费用÷新增付费用户；LTV=(ARPU×毛利率)/流失率；看 LTV:CAC 比值（图中 Netflix 6:1，结论句说"3 倍以上"）。案例：Netflix，三策略：原创内容、定价权、全球扩张。
- **MOT 关键时刻（Moment of Truth）**：ZMOT / FMOT / SMOT / UMOT（零/第一/第二/终极关键时刻）时间轴，找顾客顾虑并在最想不到处制造惊喜。案例：Zappos（365 天退换、预付退货标签、无脚本客服）。三支柱：Budget Reallocation、Empowerment、Under-promise Over-deliver。
- **Pareto 80/20（帕累托）**：关键少数 vs 无用多数，帕累托图（柱 + 累积折线 + 杠杆点）。应用：产品组合优化（尾部 SKU）、客户分层、质量问题抓大放小。
