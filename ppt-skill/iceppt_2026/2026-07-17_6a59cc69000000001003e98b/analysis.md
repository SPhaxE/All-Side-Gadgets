# Nerdy 风商业框架 slides 合集：一页一个模型，正反两面（框架页 + 案例页）

> 本篇 11 张图里，我读了 5 张（03/04/05/06/08）。每张都是上中下三张 16:9 幻灯片竖向拼接，共 15 页。

## 本篇主旨
这是一套"商业/战略框架速查"模板，编号 018 到 052，共约 200 页。每个模型固定做成"框架页 + 真实公司案例页"两页，用同一套版式、绿灰配色和信息密度，做出"高级感 + 可直接抄"的商赛 PPT。

## 提炼出的设计规则
1. 每个模型固定两页：框架页（定义 + 结构图）加案例页（一句话结论 + 数据 + 过程）。案例选知名公司（Zoom、Netflix、Amazon、Zappos、Facebook、麦当劳）。
2. 页头统一：左上英文大标题（粗体），右上 "@ICEPPT" + 3 位编号；标题下紧跟一条圆角"定义条"（标题加下划线，后接一句话总结 + 2 行说明）。
3. 案例页的结论前加黑色实心圆点 "●" 加粗体一句话，写清"做了什么 → 结果多少"。
4. 数字要大：关键数据（$17B、7.0x、75%、2.5%）用 40-60pt 级的细体或衬线绿色数字，说明文字缩到约 10-12pt。
5. 信息分块用"圆角浅底卡片 + 小标签"。同一页只用 2-3 种底色，层级靠留白和细线区分，不靠粗边框。
6. 强调采用三种手段：深绿描边加阴影（"当前最优项"）、虚线框（"假设 / 警示 / 事件"）、对勾和星标。弱化项直接变灰。
7. 结构复刻模型本身：钟形曲线用错落台阶，同心圆用于 TAM/SAM/SOM，时间轴用于 MOT，矩阵用于 2x2，飞轮用环形。
8. 巨大浅灰数字（01 到 04、0 到 3）当背景水印，既编号又增加层次。
9. 对比用条形图时，只高亮主角（米色或绿色），其余灰色，并直接在条上标数值，不画坐标网格。
10. 每个小模块配一句"Insight / 结论条"收束（浅绿底小字），例如"SOM 才是最具说服力的指标"。
11. 双语标题：英文大写或首字母大写在前，中文翻译在后用小号灰字。
12. 页面中文正文很小（约 8-10pt），属于"阅读型 / 商赛附录型"，不适合现场演讲投屏，要自己判断场景。

## 字体与字号层级
- 标题：无衬线粗体，约 28-32pt，字体不确定（疑似思源黑体类）。
- "@ICEPPT"：衬线字母，大字距，深绿。
- 编号：粗无衬线，约 24pt。
- 大数字：细体或衬线手写感，约 40-60pt，字体不确定。
- 案例斜体小标题（"Calculate CAC"）：斜体衬线。
- 正文：中文无衬线约 8-12pt。
- 层级大致是：大数字 > 页标题 > 模块标题 > 正文 > 灰色注释。

## 出现的思维模型/框架
- Adoption Curve（创新扩散）：按用户接受速度分 5 群，核心是跨越 Chasm。案例 Zoom。
- TAM-SAM-SOM：市场规模逐层收窄。
- CLV/LTV：LTV = AOV x F x GM% x LT，LTV:CAC=3:1 为健康线。案例 Netflix。
- Hook Model（上瘾模型）：触发 → 行动 → 多变奖赏 → 投入。案例：抖音、Instagram、拼多多。
- JTBD：用户"雇佣"产品完成任务。案例：麦当劳早餐奶昔。
- Scenario Planning：North Star 加 4 个情景。
- Growth Flywheel：Amazon 飞轮。
- MOT（关键时刻）：ZMOT / FMOT / SMOT / UMOT。案例 Zappos。
- Buy vs. Build Matrix：四象限（自建、收购、授权、合作）。案例：Facebook 收购 Instagram。
- Make or Buy Decision：四步过滤加盈亏平衡点。
