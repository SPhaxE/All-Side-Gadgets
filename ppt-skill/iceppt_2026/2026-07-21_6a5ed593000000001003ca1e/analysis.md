# 呼吸感slides（#012 BCG Matrix / #013 Ansoff Growth Matrix）

## 本篇主旨
用"呼吸感"的浅灰绿底、留白和细线框，把经典战略矩阵（BCG、Ansoff）做成"定义 + 矩阵 + 使用步骤/要点"的信息图版式；BCG 还配一页案例页，示范"框架页 → 案例页"的汇报闭环。note.md 只有标题、标签，没有任何正文方法论文字（11 张图，本次只需读 06.jpg）。

## 逐页拆解
06.jpg 是三张幻灯片上下竖向拼接，从上到下分别是 BCG 框架页、BCG 案例页、Ansoff 框架页。

### 上：#012 BCG Matrix（框架页）
- 页面角色：概念讲解页。圆角细线外框，左上粗黑英文大标题 "BCG Matrix"，右上 "@ICEPPT 012"，其中 012 为粗黑大号数字，@ICEPPT 为衬线灰绿。
- 版式：标题下一条圆角"定义胶囊"，首行加粗 "BCG Matrix（波士顿矩阵）- 逼迫管理层做出真正的取舍——不是所有业务都值得投入"，下接约 3 行小字释义。主体左约 55% 为 2x2 矩阵，右约 45% 为 "如何使用BCG矩阵" 的 4 步纵向列表。
- 图表（2x2 矩阵）：
  - 纵轴 "市场增长率"（高/低），横轴 "相对市场份额"（高/低）。
  - 四象限为浅灰绿底卡片，每格左缘有深绿竖线。
  - 每格结构：圆形线框图标 + 英文名（Star / Question Marks / Cash Cow / Dogs）+ 右侧小号中文名（明星业务 / 问题业务 / 现金牛业务 / 瘦狗业务）→ 一行粗体 "高增长/高份额" 等 → 细分隔线 → 3 条要点 → "典型业务" → 2-3 个圆角描边标签（云计算、新能源车、机器人业务、纸媒广告等）。
- 右侧 4 步：灰色圆底大号 "#1 - #4" + 粗体步骤名 + 小号灰字说明。步骤名依次为：绘制业务单元、识别象限归属、制定资源分配矩阵、动态追踪业务演变。
- 配色用法：整页白底，灰绿用于卡片底，深绿用于竖线与强调，黑色用于标题，灰色用于说明。
- 字号层级：大标题最大 → 定义首行粗体 → 象限英文名（较大）→ 象限小标题 → 正文要点（小，灰）→ 标签（最小）。

### 中：#012 BCG Matrix – CASE STUDY（案例页）
- 页面角色：用数字证明框架的应用结果。标题 "BCG Matrix - CASE STUDY：某消费科技集团如何重配资源？"，前面是实心黑圆点式的结论行："通过业务组合重构，公司在 12 个月内将资源向高增长赛道集中，推动整体营收增长 +14%，经营利润率提升 +3.2pp。"
- 版式：自上而下分三层。
  1. KPI 条："重构结果（12个月）" + 4 张灰绿大数字卡（+14%、+3.2pp、+19pp、+$6.8B，数字用细体特大字号，上方小灰标签），右侧叠 2 个带阴影的描边小卡（"高增长业务收入占比: 30%→43%"、"低增长业务收入占比: 36%→22%"）。
  2. 一条深绿短粗线作分隔。
  3. 三栏并列，用灰圆编号 ①②③ 标栏名：① 业务组合现状（数据表）、② BCG Matrix 业务组合分析（迷你 2x2，带两端箭头轴）、③ 资源重配与战略动作（4 张描边卡）。
- 图表：
  - ① 为极简表格，列为 业务线 / 营收占比 / 市场增长 / 相对份额，6 行（云服务 18% 22% 1.6x，AI终端 12% 28% 1.3x，智能家居 26% 6% 2.1x，办公打印 21% 2% 1.8x，家庭机器人 8% 24% 0.6x，低端平板 15% 1% 0.5x）。表格只有细横线，表头加粗，数字居中。表下为 "核心问题:" 加一句结论。
  - ② 为缩小版 BCG，同框架页，但把象限标签换成具体业务（Star = 云服务/AI终端；Q.Mark = 家庭机器人；Cash Cow = 智能家居/办公打印；Dogs = 低端平板），要点改为动作。
  - ③ 每张卡是 "大号灰图标（★ ? $ X）+ 粗体象限名 + 一句动作 + 关键数字用大号绿/黑字突出"：28%提升至40%、2个里程碑、$6.8亿、压缩35%SKU。
- 配色用法：关键数字卡用灰绿底，全页只用一个深绿色强调，没有其他彩色。
- 字号层级：KPI 数字（最大、细体）> 栏标题 > 卡片标题 > 表格正文（最小）。

### 下：#013 Ansoff Growth Matrix（框架页）
- 页面角色：概念讲解页，布局与 #012 框架页统一（同一标题区 + 定义胶囊）。定义首行："Ansoff Growth Matrix（安索夫增长矩阵）- 企业制定增长战略的标准起点"。
- 版式：左约 65% 矩阵，右约 35% 为 "使用要点"（对勾图标）、"常见局限"（感叹号图标）两组各 3 条要点，底部灰底框 "风险水平: 市场渗透 < 市场开发 ≈ 产品开发 < 多元化"。
- 图表：
  - 纵轴为 "Markets（市场）"，从 Existing（现有）到 New（全新）；横轴为 "Products（产品）"，从 Existing 到 New；两轴都是深绿药丸形轴标签，带箭头。
  - 中间是一个大圆角灰绿底块，由十字细线分四格。每格：英文名 + 白色药丸中文名（市场开发 / 多元化 / 市场渗透 / 产品开发）→ 3 条要点 → 灰绿色 "使用方法" 横条 → 勾选框样式的一句触发条件。

- 字号层级：与上两页基本同级；格内英文名最大，要点最小。

## 提炼出的设计规则
1. 同一系列固定模板：标题区（左大标题 + 右上 "@ICEPPT 编号"）+ 圆角定义胶囊 + 下方主体，每页都能直接识别为同一套。
2. 定义胶囊用 "中英文名 - 一句话价值主张" 做首行加粗，再接 2-3 行不超过约 120 字的释义。
3. 2x2 矩阵的每格统一为 "图标 + 英文名 + 中文名 + 策略句 + 要点(3条) + 例子标签"，信息结构可复制到任意 2x2 框架。
4. 左图右文：左 55-65% 放可视化，右侧 35-45% 放步骤或要点（"如何使用"、"使用要点/常见局限"），形成"看图 → 会用"。
5. 步骤用大号灰色 "#1-#4" 做视觉锚点，步骤名加粗、说明用小号灰字；灰色编号不抢主体。
6. 呼吸感来自：大量留白、浅灰绿大色块代替边框、细线与圆角、整页只用一个深绿色强调色，没有彩色图表。
7. 案例页的结构是 "先给结论行 → 一排大数字 KPI → 三栏(现状/分析/动作)"。KPI 卡数字用细体特大字号，标签用小灰字，4-6 个为宜。
8. 数字强调：在动作句里只把关键数字放大并加粗（28%→40%、$6.8亿、35%），其余保持小号灰黑字。
9. 框架页和案例页共用同一个编号（两页都是 012）：同一主题的概念页和案例页用同号绑定。
10. 用药丸形（圆角胶囊）承载轴标签、象限中文名和例子标签；用勾选框样式承载 "使用方法/触发条件"。
11. 表格去竖线，只保留表头下和行间细灰线，数字居中，列数控制在 4 列以内。
12. 页底用一条不等式或对比句收束（如 "市场渗透 < 市场开发 ≈ 产品开发 < 多元化"），把风险水平压成一行。

## 出现的思维模型/框架
- BCG Matrix（波士顿矩阵）：以市场增长率（纵）和相对市场份额（横）划分 Star / Question Marks / Cash Cow / Dogs；用法是四步（绘制业务单元 → 识别象限 → 制定资源分配 → 动态追踪）。案例：某消费科技集团 12 个月重配资源，营收 +14%、利润率 +3.2pp、研发投向高增长 +19pp，高增长业务占比 30%→43%、低增长 36%→22%。
- Ansoff Growth Matrix（安索夫增长矩阵）：产品（现有/新）x 市场（现有/新），得出市场渗透、市场开发、产品开发、多元化；使用要点是 "先看增长来源，再说执行动作"，局限是 "只给方向，不直接回答优先级" 等；风险排序 市场渗透 < 市场开发 ≈ 产品开发 < 多元化。
- 汇报结构：结论先行 → KPI → 现状/分析/动作 三栏（现状 → 框架诊断 → 行动）。
