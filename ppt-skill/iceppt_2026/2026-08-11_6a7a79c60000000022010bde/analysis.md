# 面试官：我们要的就是这个❕——思维模型 + 案例的 PPT 双页范式（VRIO / NSM / Hook / Brand Archetypes / OKR / SMART）

## 本篇主旨
面试 case 与汇报的核心是"识别问题 -> 套模型给出清晰逻辑 -> 用案例走通路径"。PPT 形式上固定为"模型页（概念+结构图）+ CASE STUDY 页（真实公司落地）"成对出现，结论先行、数据接住判断。

**页2：NSM（North Star Metric），概念页（008）**
- 角色：概念页。

- 底部："常见误区"横排 5 个图标 + 短文（把过程指标当NSM、有多个NSM、与长期价值弱相关、团队无法影响、一成不变）。

**页3：NSM CASE STUDY：Spotify 的增长飞轮（008）**
- 角色：案例页。

## 提炼出的设计规则
1. 固定"模型页 + CASE STUDY 页"成对结构；标题行 = 模型名（加粗黑）+ " - CASE STUDY：公司 案例"（常规字重）+ 右上序号。
2. 每页标题下一行放黑圆点结论句（约 1 行，20-35 字），先给结论。
3. 用 3-5 列等宽卡片做模型拆解（VRIO 4 列、SMART 5 列、Hook 4 步），列间距一致，每列同构（标题-问句-内容-结论）。
4. 概念页放"定义+来源"引言框（约 2 行小字），再放结构图，最后放"常见误区/使用步骤"收尾。
5. 强调靠"深绿 vs 灰"二元：关键项深绿填充或描边，其余灰阶弱化（如 OKR 公司层深绿、其余灰；Hook 的 STEP3；Apple 条）。
6. 数据用"大号数字 + 小号说明 + 涨幅箭头/红字"三件套（Spotify 三个 KPI、OKR 面板）。
7. 进度用细进度条（深绿填充+浅灰轨，右侧百分比），不用饼图。
8. 折线图只保留 3 条以内线，深绿/浅绿/灰区分，图例置底，图下加 3 条文字解读。
9. 对比用符号：红叉 vs 绿勾；是否判断用空心圆 + "结果：YES"。
10. 页面信息密度高但靠灰度分层：主信息黑/深绿，次要信息灰（约 #999），说明性小字约为标题的 1/3 大。
11. 页面角落放品牌水印 "@ICEPPT" + 序号，统一系列感。

## 字体与字号层级
- 字体：标题英文疑似无衬线粗体（类 Montserrat/Arial），水印 "@ICEPPT"/部分大数字疑似衬线体；中文无衬线（疑似思源黑体/微软雅黑）。具体字体不确定。
- 层级（相对）：页标题约 24-28pt；结论句约 12-14pt 粗体；列标题约 14-16pt；正文要点约 8-10pt；脚注/说明 6-8pt；大数字约 36-48pt。（按图片比例估计，不确定）

## 出现的思维模型/框架
- VRIO（价值/稀缺/不可模仿/组织）：4 问 + 是否判断，案例 Google。
- NSM 北极星指标：五步法确定指标 + 误区，案例 Spotify（有效播放时长）。
- Hook Model（触发/行动/多变奖赏/投入）：案例 TikTok。
- Brand Archetypes 品牌原型（荣格12人格、四象限）：案例 Apple（Creator + Outlaw，主 70% / 辅 30%）。
- OKR：目标+关键成果，案例某AI产品团队 Q3。
- SMART：S/M/A/R/T 五要素，用"普通目标 vs SMART目标"对比。
- 笔记提到：市场进入 -> 3C；增长问题 -> 对应增长框架。

## 正文金句与方法（来自 note.md）
- "很多岗位的面试到了最后，都会落到一个case。"
- "模型提供思考路径，案例则告诉你，这条路径在真实场景里应该怎样走。"
- "平时看过足够多的模型和案例，现场更容易判断题型。"
- "结论放在前面，数据接住判断，整份PPT自然会形成一条分析链。"
- "面试官想看到的，是你能接住一个模糊问题，并把它变成可执行的答案。"
