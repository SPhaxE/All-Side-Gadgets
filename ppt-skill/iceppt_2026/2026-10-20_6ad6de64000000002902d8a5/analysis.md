# 简单就是体现巧思的时候：基础图形（漏斗/金字塔/时间轴等）的“Done → Well Done”升级

## 本篇主旨
越基础的图形越能看出设计者是否真正理解内容。笔记用6类基础图形（漏斗图、金字塔、信息屋、流程图、四象限、时间轴）说明：同一份内容，从“常规画法”升级为“带观点的巧思画法”，关键是让图形形状本身承载结论（强调流失点、顶部结论、深色强调块、坐标维度、节点配图）。本篇读到的6张图实际是6个框架/模型页的 Done（灰黑常规版）vs Well Done（绿色升级版）对比，其中金字塔、漏斗两页直接对应文中❶❷，其余是汇报框架页（SCR、PREP、BAB）与用户画像案例页。注：note.md 提到的信息屋、四象限、时间轴三类图本批6张图中未见（可能在被跳过的07/08或其他笔记中，不确定）。

## 逐页拆解

### 01.jpg 金字塔原理（The Pyramid Principle）
整图为上下拼接，上为 Done、下为 Well Done，图中间有黑色粗体大字 "Done" / "Well Done" 作标签。

**上半 Done（灰黑常规版）**
- 页面角色：框架讲解页，讲“金字塔原理：结论先行，以上统下”。
- 版式与网格：三栏。左栏“表达原则”（编号1/2/3列表），中栏大金字塔，右栏“应用场景”（4个条目 + 底部一句提示）。标题下有一条细横线分隔；底部右下小字“结构示例，数据仅作演示。”
- 图表类型与画法：三角形切成三层（顶层核心结论 → 中层论据1/2/3 → 下层数据/事实），层间用细线分割，下两层用竖线分成三列。全灰黑线稿，无填充色。三角形仍是“传统金字塔”，文字小、挤在梯形里。
- 配色：纯黑/灰/白，无强调色。
- 字体字号：标题“金字塔原理（The Pyramid Principle）”最大、粗黑；副标题“结论先行，以上统下”加粗次之；说明灰色小字；栏目小标题（表达原则/应用场景）加粗、下有细线。
- 关键文字：“核心结论 进入东南亚市场”；“论据1 市场规模大 / 论据2 竞争强度低 / 论据3 政策环境好”；“6亿人口 GDP增速5%”“本地玩家弱 进入壁垒低 品牌认知空白”“税收优惠 外贸激励政策”；“印尼2.7亿人口 越南1亿人口”“本地市场占有率<15% 偏好国际品牌”“外资进入门槛低 企业所得税优惠”；表达原则：“结论先行 开头说明核心观点，让听众先知道答案”“MECE分组 同层说据相互独立、完全穷尽”“逻辑递进 每层内容支撑上一层结论”；应用场景：“咨询报告 先结论，后依据”“战略提案 自上而下展开，避免听众迷失”“复杂问题拆解 按MECE分组，检查逻辑完整性”“听众记忆容量有限，避免线性堆砌信息。”

**下半 Well Done（绿色升级版）**
- 页面角色：同内容的设计升级版，页码样式 “087”，右上 “@ICEPPT”（绿色衬线/等宽风格小字）。
- 版式与网格：顶部英文标题“The Pyramid Principle”（粗黑，左）+ 页码/署名（右）；下方一个圆角描边的说明框，内含“The Pyramid Principle (金字塔原理) - 结论先行，以上统下”（带红色下划线）与一段小字背景介绍（提到 Barbara Minto 提出）；主体左2/3为金字塔，右1/3为“7±2 chunks”与“战略应用场景”卡片。
- 图表类型与画法：金字塔改为渐变绿色分层（顶层浅/极淡，向下逐层变深的绿），每层之间加向下的白色箭头（表示“逻辑递进/支撑”）；论据层用圆角小白胶囊；顶部结论用“核心结论 / ‘我们应该进入东南亚市场’”白色圆角框；左右用带圆点端点的细绿线引出标注（“结论先行”在左、“MECE分组”“逻辑递进”在右）。
- 配色：主色为绿色（深绿 + 浅绿渐变），其余灰/黑；绿色同时用于“7 ± 2 chunks”大号数字标题与编号圆点。

- 关键文字：“7 ± 2 chunks 人类短期记忆容量有限”“线性叙事导致信息过载与逻辑迷失”“听众无法快速抓取核心结论与支撑逻辑”“战略应用场景”“①咨询报告撰写 先结论后依据，确保高管快速理解 ②战略提案演讲 自上而下展开，避免听众迷失 ③复杂问题拆解 MECE分组，确保逻辑无遗漏”；金字塔中“结论先行 顶层直接给出核心观点，无需铺垫悬念”“MECE分组 同层论据需相互独立，完全穷尽”“逻辑递进 自上而下逐层展开，每层支撑上层结论”；塔底数据“印尼2.7亿 越南1亿 印尼GDP+5.3% 越南GDP+6.5%”“本地市场占有率<15% 消费者偏好国际品牌”“外资进入门槛低 企业所得税10年减半”。

### 02.jpg 14天免费试用转付费漏斗（Funnel Chart）
上下拼接，Done 在上，Well Done 在下。

**上半 Done**
- 页面角色：数据分析页：14天免费试用转付费漏斗。
- 版式：左侧倒梯形漏斗（5层，从上到下逐层缩窄，灰色渐深），右侧“主要流失点与优化方向”分两组（1. 绑卡门槛；2. 首次价值体验），每组有灰底小标题条、两条要点、“优化方向”加粗；底部左下为转化率汇总。
- 图表画法：5层等高梯形，全灰（浅灰到稍深灰），层内居中写“1 注册试用 10,000人 / 2 强制绑卡 4,000人 / 3 创建首个项目 2,000人 / 4 邀请同事协作 900人 / 5 最终付费 800人”；每层间距均匀，没有任何强调。
- 配色：灰黑白。
- 字体：标题“14天免费试用转付费漏斗”大号粗黑；副标题“从10,000名注册用户到800名付费用户”次大；“整体转化率为8%，重点排查早期流失与首次价值体验。”灰小字。
- 关键文字：“各步转化率：40% → 50% → 45% → 88.9%；总体转化率：8% 累计流失率：92%（9,200人）”；右栏“10,000→4,000，流失6,000人。优先排查用户对绑卡和自动扣费的顾虑。优化方向：尝试无需信用卡的试用，让用户先体验核心功能。”“4,000→2,000，创建项目阶段再流失一半。检查新手操作是否复杂、核心价值是否出现过晚。优化方向：提供项目模板和引导步骤，缩短首次获得价值的时间。”“先改善早期体验，再评估引流与付费策略。”

**下半 Well Done**
- 页面角色：案例页，页码“077”，标题“Funnel Chart - CASE STUDY：解剖‘免费试用到付费’的死亡漏斗”，署名 @ICEPPT。
- 版式：顶部黑圆点 + 一句加粗结论“试用期流失率高达92%，SaaS运营通过精细化水平漏斗图，推翻流量不足的错误归因，敲定取消强制绑卡、前置用户价值感知的产品优化策略。”下方分左右两块：左“流失率超92%的死亡漏斗分析”（大圆角容器内的漏斗图），右“关键断点与解决路径”（两组：“Friction”“Aha Moment”）。
- 图表类型与画法（本篇“巧思”核心）：漏斗被改为“水平条形漏斗”，每一步拆成左右两段：左段“留存”（浅灰绿底），右段“流失”（更浅/白底），左右宽度对应人数，居中对齐漏斗；步骤间插入深绿色小标签显示“转化率：45%/44%/45%/89%”；步骤名（Step1 注册试用…Step5 最终付费转化）在左侧列出，Step3 旁有红色 ✗，Step4/5 旁绿色 ✓；底部深灰条汇总“整体转化率：8%（10,000→800）| 累计流失率：92%（9,200用户流失）”。在流失最严重的 Step2/Step3 用右侧虚线引出到右栏对应的解释。
- 对应笔记：“在流失最严重的一层拉开间距，制造视觉重点”——此图把留存/流失拆开并标红绿标记以突出。（注：实际画法与“拉开层间间距”略有差异，是把留存与流失并排显示，不确定是否同一手法。）
- 右栏：“Friction”（绿色引号大字、下方绿色细线）+ 小标题“操作摩擦力过大”+ 灰色解释 + 向下灰箭头 + 灰底结论框“立即实行‘无需信用卡的逆向试用’…”；“Aha Moment”同构：“Aha时刻缺位”+ 说明 + 箭头 + 灰底结论框“引入标准化自动化模板及引导式交互弹窗…”。
- 配色：浅灰绿 + 深绿标签 + 红/绿对错符号，灰底结论框。
- 字体：英文标题“Funnel Chart”粗体大号，“CASE STUDY：…”细体；页码 077 大号粗黑；右栏的“Friction”“Aha Moment”为绿色细体大字（带引号）。

### 03.jpg SCR 汇报框架

- 页面角色：汇报框架讲解。标题“SCR 汇报框架”，副标题“Situation—Complication—Resolution”，说明“先交代现状，再指出问题，最后给出答案。适用于需要快速讲清问题与建议的汇报。”

- 配色：深绿（箭头）、浅绿（R区域底）、灰黑文字。
- 字体：标题粗黑；S/C/R 标签细体较大的绿色英文；小标题加粗；说明灰色小字。

### 05.jpg BAB 提案框架
**上半 Done**
- 页面角色：框架讲解。“BAB 提案框架｜Before—After—Bridge：现状、愿景与实现路径”，说明“用于商业提案与预算申请。先呈现当前痛点，再描绘理想状态，最后提出连接两者的方案，让对方理解为什么值得投入。”
- 版式：三列，顶部灰底标签 “Before 现状 → Bridge 实现路径 → After 愿景”（注意：Bridge放在中间，与顺序“Before→After→Bridge”叙述不同，此处按框架标准顺序“先B→再A→后Bridge”还是按空间逻辑B-B-A，文中“表达顺序：先让人看到问题(Before)，再看到希望(After)，最后相信路径(Bridge)。”）；下面白底细边框卡片：现状与痛点（目前是什么情况？/有哪些问题或挑战，为什么需要改变？）、路径与方案（如何实现目标？/关键步骤和行动计划是什么？/为什么这个方案可行？）、愿景与目标（我们希望达成什么？/改变后会带来哪些积极影响？）；底部“使用原则”三条：现状真实（不夸大问题，也不隐瞒痛点）、愿景具体（明确价值，让目标具有吸引力）、路径可信（步骤清楚，方案具备可行性）。
- 配色：黑灰白。

**下半 Well Done**
- 页面角色：页码“097”，标题“BAB Framework”，副标“The Before-After-Bridge BAB 模型 (现状-愿景-桥梁) - 向客户/老板索要资源或预算”，下有长说明。
- 版式与图表：背景画一座灰绿色“山峰”剪影（面积图，起伏从左低到右），Before 在左下（山脚左侧，绿色粗体“Before”），Bridge 在山顶（中上，绿色粗体“Bridge”，意为“桥/翻山”），After 在右下（右侧山脚，绿色粗体“After”）；三处各有虚线描边的小文本框（现状|痛点、路径|方案、愿景|目标），分别放置在山脚/山腰/山脚右上位置；左上“核心原则”配三个绿色对勾 + 三条原则；底部居中一句引语“先让人看到问题，再让人看到希望，最后让人相信路径。”
- 巧思点：用“山”的隐喻把抽象的 Before-Bridge-After 变成视觉形状（路径=翻越的高度），文本框位置沿山形起伏。
- 配色：极浅灰绿山形填充，亮绿标签（Before/Bridge/After），灰色虚线框。
- 字体：绿色粗体英文标签（中等大小）；标题粗黑；正文灰小字。

### 06.jpg 用户画像案例：Peloton 的 Sarah

## 提炼出的设计规则
1. 同一内容做“两版”：Done = 内容正确且结构清晰的灰黑线稿版；Well Done = 在同一结构上加“一个视觉重点 + 一种隐喻/形状”。先保证 Done，再用巧思升级。
2. 全页只用一个强调色（本篇为绿色），再用同色深浅做层级；其余用灰/黑。强调色面积建议 ≤ 15%（Resolution 浅绿大块可作为例外，因为是浅色底）。
3. 一页只放一个视觉焦点：SCR 里 R、PREP 里 Example、漏斗里流失最严重的步骤；其余元素降级为灰色。
4. 让图形形状承载含义：漏斗用留存/流失并排 + 转化率标签；金字塔用逐层加深色 + 向下箭头表示“支撑”；SCR 用贯穿的箭头时间线；BAB 用“山形”表示翻越路径；PREP 用高低错落表示演讲节奏。
5. 把“理论依据”做成视觉锚点：如金字塔页将“7±2 chunks”做成绿色大号细体数字 + 加粗解释。
6. 抽象英文词（Point/Reason/Example、Before/Bridge/After、S/C/R）做成大号细体绿色字，中文说明用小号粗体 + 灰色正文，形成“大—中—小”三级对比（大小比约 5–8 倍，此为目测估计）。
7. 左右分栏的“问题 → 方案”对照：左侧灰色卡（痛点），右侧同色描边卡（方案），中间用箭头相连；绿色只给“方案/答案”侧。
8. 在顶部固定放一个圆角描边的“说明框”，写“术语（中文）- 一句话定位/适用场景”，其下用 1–3 行小字解释出处；让页面可独立阅读。
9. 页面标题写成“框架名 + 副标题（案例/适用场景）”；案例页要加一句加粗的结论（带黑圆点前缀）：“拒绝…通过…成功…”结构，即 “现象 + 行动 + 结果”。
10. 给量化数据加汇总条：漏斗底部用深灰色条汇总“整体转化率 8%，累计流失 92%”；每步用深绿小标签标转化率。
11. 对错/状态用红 ✗ / 绿 ✓ 标在步骤名旁，快速标识问题点与健康点。
12. 用剪影/插画（如跑步剪影）、超大数字（01/02/03）和阴影卡片（Example 卡）来制造层级，避免只靠文字大小。
13. 每页底部或角落留页码与署名（@ICEPPT + 三位数页码），统一风格。
14. 框架页底部用“核心原则/使用要点”三条短句收束，每条以“主语 + 必须/只讲…”的短结论句开头。

## 出现的思维模型/框架/方法论
- 金字塔原理（The Pyramid Principle，Barbara Minto）：核心结论→3个论据→数据/事实；结论先行、MECE 分组、逻辑递进；案例“进入东南亚市场”（印尼2.7亿人口、越南1亿人口、GDP增速、本地市场占有率<15%、企业所得税优惠）。附带理论“7±2 chunks”（人短期记忆容量有限）说明为何要分组。
- MECE：同层论据相互独立、完全穷尽。
- 漏斗图/转化漏斗分析：14天免费试用→付费，10,000→4,000→2,000→900→800，各步转化率40%/50%/45%/88.9%，总转化8%，累计流失92%；归因为 Friction（强制绑卡造成操作摩擦）与 Aha Moment 缺位（首次价值体验来得太晚）；解决方案“无需信用卡的逆向试用”“引入标准化模板与引导式交互”，“5分钟内无法感知核心价值则极易流失”。
- SCR（Situation-Complication-Resolution）：咨询汇报标准开头；先共识、再张力、最后答案；适合高管汇报。
- PREP（Point-Reason-Example-Point）：观点—原因—案例—重申；案例用 Slack 转向企业协作、Adobe 转订阅制（估值/市值增长600%）；适用电梯推销/危机公关/投资人路演/快速汇报/媒体采访。
- BAB（Before-After-Bridge）：先痛点、再愿景、后路径；用于向客户/老板要资源或预算；顺序“先让人看到问题，再让人看到希望，最后让人相信路径”。
- 用户画像（User Persona）+ Persona-to-Product Mapping：以 Peloton 的 Sarah（时间匮乏的高成就者）为例，把画像映射到硬件定位（Sleek Design）、软件与内容（Live Classes）、定价策略（Exclusion，舍弃的力量）。

## 正文金句与方法（来自 note.md）
- 标题：简单就是体现巧思的时候。
- “越基础的图形，越能看出设计者有没有认真理解内容。”
- ❶ 漏斗图：常规=几层梯形依次缩小；巧思=在流失最严重的一层拉开间距，制造视觉重点。
- ❷ 金字塔：常规=三角形分层，信息从上到下排列；巧思=表达观点与依据时，转成“顶部结论＋下方理由”。
- ❸ 信息屋：常规=屋顶、柱子、地基；巧思=分别变成目标栏、内容区和基础栏，让结构融入排版。
- ❹ 流程图：常规=一串方框加箭头；巧思=在需要强调的方框位置加深色色块，引导视觉。
- ❺ 四象限图：常规=田字格填文字；巧思=引入坐标系，可插入另一个维度信息，如“重要度/严重度”。
- ❻ 时间轴：常规=一条横线排日期和事件；巧思=在关键节点旁加入成果小图（草稿、初版、成品），沿时间看到发展变化。
