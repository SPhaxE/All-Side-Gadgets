# 汇报材料生出血肉中……（思维模型 + 真实案例 双页拼图合集，9 张）

## 本篇主旨
iceppt 把商业思维模型做成"上半页模型讲解 + 下半页真实企业案例"的成对幻灯片，每张图 = 同一编号（013/014/016/019/020/025/026/027/028）的两页。主张是"不只是模版，而是思维模型解析 + 案例分析，能看懂，更能用"，用同一套模块化版式把抽象框架落到数据与动作上。

## 逐页拆解
通用骨架（9 张全部一致）：上半=模型页，下半=CASE STUDY 页。左上英文大标题（粗黑无衬线），右上 "@ICEPPT"（衬线、字距拉开、深绿灰）+ 粗体大编号。整页是圆角描边大卡片；标题下一条圆角"定义胶囊"，内含"中文模型名（红色下划线）- 一句话价值"加一段 2-3 行小字说明；案例页的标题加"- CASE STUDY：企业名 - 一句话定位"，其下一行以黑色实心圆点开头的粗体"结论句"。

**01 Hook Model(028)**
- 上：左虚线点框=外部触发 vs 内部触发对比表（维度/外部/内部 4 行）+ 抖音、Instagram、拼多多三个案例行；右侧 STEP1-4 四张小卡错位排成循环（Trigger/Action/Variable Reward/Investment），每卡=英文步骤名+中文灰字+要点+"Insight/Goal"底栏；STEP3 卡放大、浅绿底、★★★ 与三个"?"图标，强调重点。
- 下：案例 TikTok。左"Perfect Addiction Score 25/25"超大数字+5 项评分表（每项★★★★★）；中间 STEP1-4 竖排卡，STEP3 绿底高亮并放"Dopamine HIT"大字；右侧手机样机 + 悬浮数据卡 "1.5B+ 月用户 / 95mins 日均时长 / 8x 日均打开次数"。
- 原文摘录："确定的奖励让人麻木，多变的奖励让人上瘾"；"B = M + A + T"；"Insight：降低行动门槛是关键"。

**02 CLV/LTV(027)**
- 上：顶部四个小标签卡（AOV/F/GM/LT 各带 Eg 示例）→ 下方大公式条 "LTV = (AOV x F x GM%) x LT = ($50x4x60%)x3 = $360"；左跷跷板图（LTV $360 vs CAC $120，3:1 Ratio, Healthy Growth）；右三档阶梯（LTV<CAC 灰 / >3xCAC 绿色高亮带勾 / >5xCAC 灰带警示）每档配"策略胶囊"；底部三个"Lever"杠杆卡（+30%/+50%/+67% LTV）。
- 下：Netflix。左 STEP1-3 竖向三卡（算 CAC→算 LTV→LTV:CAC=6:1，结果卡带勾）；右 "Strategy 1/2/3" 三个大数字卡（$17B / $9-$15 / 190+，数字用浅绿大号细体）+ 流失率横向条形图（Netflix 2.4% 浅棕条突出，Hulu 4.5%、Disney+ 5.2% 深灰条）+ 阴影注释框。
- 原文摘录："卖得越多，亏得越多 停止投放，优化产品"；"理想状态，每一分钱投入都在赚三倍回来"。

**03 3 Horizons(014)**
- 上：左侧"三层次增长曲线"——三段递升 S 曲线（H1 深绿实线带箭头、H2 灰、H3 更浅灰米色），曲线下方各挂要点列表；底部时间轴胶囊 "1-3年 / 2-5年 / 5年+" 与三列任务小卡；右侧"成熟企业常见误区"灰块 + "使用要点（绿勾）/常见局限（感叹号）"双栏。
- 下：某工业设备制造商。顶部深绿阴影"预测结果（3年后）"卡 + 4 个 KPI 前后对比卡（16.8%→19.2%、12%→28%、8%→22%、0→12，终值绿色加粗）；三栏："1.背景与挑战（含小表格）/ 2.三层次增长地图（3x3 矩阵，纵轴创新/转型/优化、横轴优化/转型/创新，圆点编号 1-9，对角三个 Horizon 区块）/ 3.各Horizon任务（虚线卡，任务灰条+①-⑨关键动作）"。

**04 RFM Model(026)**
- 上：左 RFM 3D 立方体线框（VIP 角点着色）；右"八大典型用户"2x4 卡网格（上行浅绿到浅灰，下行灰阶，随价值递减变灰）；底部 R/F/M 三张大卡：超大衬线斜体绿色首字母 + 中英文名 + 两条 High/Low 判断 + 深灰底栏"策略：…"。

**05 Marketing Funnel(025)**

**06 Blue Ocean Strategy(020)**

## 提炼出的设计规则
1. 模型页+案例页成对：上页回答"是什么/怎么用"（定义、要点、局限），下页回答"怎么落地"（背景→结构化拆解→数据→动作），同号同模板，便于系列化。
2. 页头固定三件套：英文大标题（约 28-32pt 量级，粗体）+ 品牌/编号右对齐 + 定义胶囊（含红色下划线的中文关键词）；案例页多加"● 结论句"（一句话量化结论，如"Top 20% 贡献 80% 营收"）。
3. 一页 3 栏或"2 行 x N 列"模块网格，栏间距统一、每栏有灰/绿块小标题（如 "RFM Metrics | 数据输入"）；栏数 3 为主（Hook、Ansoff、RFM、Moat 下页等）。
4. 重点用"绿色高亮"而非加字：同组卡片中只有 1 张用深绿描边/浅绿底/加阴影（Hook STEP3、LTV 3:1 档、RFM Monetary、Ansoff 市场开发象限），其余灰/米。
5. 数字即图形：关键 KPI 用 40-60pt 级细体大数字 + 8-10pt 灰色说明（$17B、190+、>80%、5B+、25/25）；前后对比用"旧值（灰）→ 新值（绿色加粗）"。
6. 图表按语义选型：对比用横条（流失率）、趋势用面积折线（曲线图 + 终点大圆点）、阈值/区间用仪表盘或阶梯卡、层级用金字塔/漏斗、关系用 2x2 或 3x3 矩阵、因果用箭头链、评分用★/圆点。
7. 层级视觉化隐喻：灰阶 = 价值递减（RFM 八宫格、金字塔），色块由绿渐浅；反面/旧模式一律灰，新模式一律绿（AIDMA vs AISAS、红海灰 vs 蓝海青绿）。
8. 每个要点列表不超过 3 条、每条 ≤ 14 字，辅助解释用更小更浅的灰字，英文原名 + 中文释义双语并列（英文做标签、中文做解释）。
9. 卡片统一圆角 + 轻阴影，浅灰/米色底（#F0F0EC 级）托住白色内卡；留白充足，大面积用浅底不用实心深色。
10. 使用要点/常见局限固定成对（绿勾 vs 感叹号）放在右侧栏，体现"能用、不滥用"。
11. 大字母/大数字做视觉锚点（AISAS 的巨大斜体字母、R F M 首字母、Year 1-5 大数字、E R R C 首字母）。
12. 底部放"Insight/判断/关键启示"一行总结，做到"图后有结论"。

## 出现的思维模型/框架
- Hook Model 上瘾模型（Trigger→Action→Variable Reward→Investment）：案例 TikTok，用 25 分上瘾评分。
- CLV/LTV：LTV=(AOV×F×GM%)×LT，LTV:CAC=3:1 基准；案例 Netflix（LTV:CAC=6:1，流失率<2.5%）。
- 3 Horizons 麦肯锡三层增长：H1 守成/H2 新兴/H3 探索；案例工业设备商（服务收入 12%→28%）。
- RFM 用户价值分层（R/F/M 八大用户）：案例丝芙兰 Beauty Insider 三级会员。
- Marketing Funnel AIDMA vs AISAS：案例完美日记（KOC 15,000+、>80% Top3 占有率、GMV 5B+）。
- Blue Ocean Strategy 蓝海战略 + ERRC：案例任天堂 Wii。
- Scenario Planning 情景规划（识别驱动因素→锁定关键不确定性→设计应对动作→建立预警信号）：案例特斯拉 2024-2028。
- Moat Analysis 护城河五来源（转换成本/成本优势/网络效应/无形资产/规模效应）：案例 Liquid Death。
- Ansoff Growth Matrix 安索夫增长矩阵（市场渗透/市场开发/产品开发/多元化，风险递增）：案例蜜雪冰城出海。
