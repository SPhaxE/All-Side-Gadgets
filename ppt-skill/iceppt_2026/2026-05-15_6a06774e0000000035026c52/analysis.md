## 提炼出的设计规则
1. 一页一个强调色：深酒红只给"最重要的 1 个数据/1 个节点/标题下划线"，其余全部灰；例如柱图 5 根只有最高柱红。
2. 统一骨架：面包屑(约 10pt 灰) + 粗黑标题(约 28-32pt) + 标题下 2-3pt 黑线；全套 27 页位置完全一致。
3. 小标题三种样式交替：灰块前缀 / 细灰下划线 / 深红粗下划线，用来分区而不是用色块框。
4. 大数字 KPI 公式：大数字(粗，约 28-32pt) + 增幅小字(粗，约 12pt) + 红细横线 + 灰色说明(约 12pt)；大数字可灰（弱化）或黑/红（强调）。
5. 图表去装饰：无边框、淡灰横网格线、数据直接标在柱顶/柱内，只保留 X 轴；柱宽约为间距 0.6-0.7。
6. 趋势用"黑色细箭头+椭圆增幅标签"（如 +223%）叠在柱间，不再画折线。
7. 时间序列用"灰柱 + 末 1-2 根换色(灰绿/深红)"区分历史 vs 预测/当期。
8. 瀑布图/漏斗/环形循环做逻辑关系；环形用灰、深红、灰绿三段，避免超过 3-4 色；词云/气泡用透明度表达强弱。
9. 分析文字三级字色：黑=小标题，深红=结论，灰=补充说明；段内关键词加粗而非加色。
10. 底板分层：白底 + 米灰(#F3F2F0)/淡灰绿块做分区，用色块代替边框；结论句放整宽淡灰条，深红粗体居中。
11. 圆角：外框与模块圆角约 8-16px，细灰线 1px；红色虚线/点划线表示"可选/长期/未定"。
12. 引线注释：深红细折线+红圆点连图与米灰注释块，注释标题深红粗体。
13. 图标一律灰色线条风，仅 1 个关键图标可染深红。
14. 序号：01-04 大号浅灰/深红数字 + 行间细分隔线；热点序号用粗黑大字。
15. 对比页：左右对称，左淡粉/右淡灰绿（如利润 vs 成本）。

## 配色（估算）
- 深酒红 #4F1215：强调柱/标题下划线/环形主段/KPI 数字
- 中红 #8B2A2A（引线、红点、箭头，近似）：注释线与链接
- 灰绿 #9AB5A5：预测/当期柱、环形次段、箭头与流程线
- 淡灰绿 #E8EFEA：底板、梯形区
- 浅灰 #D3D3D3 / 中灰 #8C8C8C：历史柱、序号、网格
- 米灰 #F3F2F0：面板底
- 粉灰 #E6DCDC：对比/次强调底
- 米黄 #D9D2C0：胶囊标签/气泡
- 近黑 #111：标题、标题线；白 #FFF：页底

## 字体与字号层级
- 字体：中文字体不确定；英文看起来是无衬线（类似 Source Han Sans/Microsoft YaHei UI 风格），斜体仅用于 Strategy/Short run 等行标签与大百分比。
- 层级（估算）：标题约 28-32pt Bold；小标题约 16-18pt Bold；大数字约 28-32pt；正文约 12-14pt；注释/轴标/面包屑约 9-10pt。字号层级拉开靠"粗细+颜色"而非多字体。

## 出现的思维模型/框架
- 3×3 矩阵（High/Low × Small/Large，高亮对角格）：做优先级/定位。
- 2.5D 层叠四象限 "When to compete"（Do more and better of same → Resegment → Create unique advantage → Exploit industrywide）：竞争战略。
- 循环流程（Goal Setting → Resource Allocation → Process Execution → Reporting Optimization）：复盘/工作流闭环。
- 漏斗（Large/Medium/Small size）：竞争格局分层。
- Harvey ball 矩阵：竞品多维评分。
- 短期/长期 × 策略/模型选择 2×3 表。
- 三圆维恩（Efficiency Up/Product Line/Market Share）：交集=核心。
- 利润与成本双栏、瀑布图（增量拆解）、Aspect 1-4 并列、Concept + Data 框架、"结论一句话标题"（Write one sentence conclusion here）。
