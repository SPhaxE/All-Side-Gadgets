# 做少一点 做好一点（2026-10-26）

## 本篇主旨
把功夫花在"能反复使用"的三件事上：一个无衬线字体、一个重点色+一个基础色、三种基础排版（左右/三分/上下）。图片用 Done（普通信息堆叠版）vs Well Done（同一内容重新设计后）的前后对比，示范同一个思维模型（护城河、SMART、麦肯锡7S）如何从"文字+表格"升级为"图解+结论句+单一绿色强调"的页面。

## 逐页拆解

- 版式与网格：左右两栏。左栏窄（约占 1/3），右栏宽（约占 2/3）；各栏内再用灰底小标题条分块（"核心问题""判断重点"/"1. 护城河的五大来源""2. 强护城河与弱护城河"）。
- 图表类型与画法：左栏为一个简单嵌套框示意（竞争者 ↓ 护城河/竞争壁垒 外框 → 企业核心业务 内白框），灰色线框；右栏上为 2 列表格（来源 | 作用，5 行）；右栏下为强/弱护城河两列项目符号清单，中间一条竖线分隔。

**下半 Well Done（改造后）**

- 图表类型与画法：左栏上方是大引号 + 灰色大字问句（"这家公司 / 凭什么**不能**被轻易取代？"，"不能"加粗加深以强调），下方是一个透视画的"护城河"线框图（水沟 + 墙），内部用绿色文字依次列出五个来源，每个配左右箭头，水池中央标 "Moat"（绿色较大字）。右栏上：绿色圆形数字徽标"1" + 小标题"护城河5大来源"，下面五行"绿色英文名 + 黑色中文名 ⇨ 灰色解释句"（左中右三列，中间一个空心箭头图标）；右栏下：绿色徽标"2" + "强护城河 vs 弱护城河"，两列带下划线的小标题（强护城河特征/弱护城河特征），下方浅灰底块里是灰色小号清单。

- 字体字号层级：编号数字（最大黑粗）→ 英文页标题（大粗体）→ 问句大字（浅灰、细体、最大号正文）→ 摘要标题（粗体小号）→ 区块小标题（粗体小号）→ 英文关键词（绿色、细体）→ 中文名（黑色、衬线感较轻的细体）→ 解释/清单（灰色小号）。英文用细体无衬线、中文用黑体系。
- 关键文字原文："Moat Analysis（护城河分析）- 巴菲特最核心的投资/战略判断工具""这家公司凭什么不能被轻易取代？""Switching Costs 转换成本 ⇨ 客户更换的成本高，导致粘性和留存""Cost Advantages 成本优势 ⇨ 更低的成本结构，带来更高的盈利优势""Network Effects 网络效应 ⇨ 客户越多，价值越大，形成正向循环""Intangible Assets 无形资产 ⇨ 品牌、专利、基数、数据等难以复制的资产""Efficient Scale 规模效应 ⇨ 规模扩大带来更低成本，或更强市场支配力""强护城河特征：高 ROIC、稳定利润率、定价权、客户黏性、竞争者难进入""弱护城河特征：同质化、比价严重、份额不稳、利润易被侵蚀、替代品多"。

**Done → Well Done 的变化要点**：标题从名词变成"带出处的结论定位句"；把抽象的"嵌套框"换成形象的护城河剖面图；表格变成"英文关键词+中文+箭头+解释"的行；两处重点用同一个绿色数字徽标统一序号；整页只一种强调色。

### 04.jpg：SMART 目标模型，编号 011
同样为上下拼接（Done / Well Done）。

**上半 Done**
- 页面角色：方法模型讲解页。
- 版式与网格：上部 5 等分横向列（S/M/A/R/T），每列一个灰底标签条（字母大号黑粗 + 英文）+ 中文名 + 说明 + "例："；下部左右两块：左"目标表达对比（示例）"（普通目标 vs SMART 目标 两行对比表），右"使用步骤"（1-4 编号清单）。
- 图表类型：5 栏卡片并列 + 对比表 + 步骤列表，全部灰白，用灰底块和细线分隔。
- 配色：纯黑白灰，无强调色。
- 字体层级：大标题粗体 → 加粗副标题（"把模糊方向转化为具体、可追踪、可验证的目标"）→ 灰色说明句 → 灰底条标题 → 中文名粗体 → 说明/例子小号。
- 关键文字原文："SMART 目标模型""把模糊方向转化为具体、可追踪、可验证的目标""用具体、可衡量、可实现、相关和有时限五个条件，检查一个目标是否清楚、可执行。""例：提升核心功能的用户留存。""例：30 日留存率从 28% 提升至 35%。""普通目标：提升产品表现。方向模糊，缺少量化标准和期限。""SMART 目标：在 2024 年第三季度内，将核心功能的 30 日留存率从 28% 提升至 35%。明确对象、指标和截止时间。""使用步骤：1 明确业务目标 2 按 SMART 拆解 3 设定口径与责任人 4 定期复盘与调整"。

**下半 Well Done**
- 页面角色：同模型重做版，编号 "011"、@ICEPPT。
- 版式与网格：页眉同 02（英文页标题 + 署名编号）；圆角摘要框（粗体结论式标题 "SMART Goal Model（SMART目标模型）- 有效建立目标，而不是愿望" + 约 3 行背景说明，提到乔治·杜兰 1981年《管理评论》）；主体上下两段，中间一条细虚线分隔。上段为 5 等分列，下段左为"普通目标 vs SMART目标"对比，右为"使用步骤"四个圆角小卡（2×2）。
- 图表类型与画法：上段每列为"彩色粗横条 + 圆形字母徽标（S/M/A/R/T）+ 向下的三角（倒梯形尖角）+ 大号英文单词（Specific/Measurable/…）+ 浅底色卡片（中文名括号、要点、白色圆角'例'小框）"。五列用同一色相的渐变深浅/或灰绿—灰—米色—浅绿表示依次变化：S 为饱和深绿，M 为灰，A 为很浅的灰近白，R 为米色/驼色，T 为淡绿。下段：对比用"红色 ×"与"绿色 ✓"图标，左列行首标签"普通目标/SMART目标"（粗体），右侧三条灰色"✕式"问题点（灰色圆点打叉）与三条绿色勾选结论；右侧"使用步骤"为 2×2 圆角描边卡，卡片内 "01 / 02 / 03 / 04" 绿色编号 + 粗体步骤名 + 灰色小字说明，卡片之间用浅灰双箭头 ">>" 连接。
- 配色：白底；深绿为主，辅以灰、米、淡绿的低饱和色阶；红色仅用于"×"反例标记；绿色用于 ✓。
- 字体字号层级：英文单词（大、细体、各列使用该列色）→ 页标题粗体 → 摘要标题粗体 → 中文名（括号内粗体小号）→ 要点（小号黑/灰）→ 例（更小，在白色圆角框内）。
- 关键文字原文："Specific（具体）目标必须明确，知道要做什么 例：提升新用户留存率""Measurable（可衡量）必须有量化标准 例：30日留存率提升至35%""Achievable（可实现）具有挑战，但资源可支撑 例：基于现有团队或预算可达成""Relevant（相关）与战略目标直接相关 例：服务于团队与收入提升""Time-bound（有时限）必须有明确截止时间 例：在Q3末完成""普通目标 提升产品表现（方向模糊，难以对齐；无法衡量，难以跟踪；缺乏时限，执行延迟）""SMART目标 在2024 Q3内，将核心功能30日留存率从28%提升到35%（具体明确，聚焦关键结果；量化可衡量，便于跟踪；明确时限，推动执行落地）""使用步骤 01 明确业务目标 02 拆解 SMART 表述 03 设定衡量指标口径与责任人 04 定期复盘与调整"。

**Done → Well Done 的变化要点**：五个字母从灰底小条变成"字母徽标+大号英文词"的纵向色阶卡，形成视觉节奏；对比表改成 ×/✓ 图标+颜色，一眼看出对错；步骤由列表改成 2×2 卡片+双箭头，体现顺序。

## 提炼出的设计规则
1. 前后对比改造的核心动作：文字表格 → 图解；灰色堆叠 → 单一强调色；名词标题 → 结论句。
2. 一个页面只用一种强调色（本篇为深绿），其余黑/白/灰；强调色用于编号徽标、英文关键词、关键图形（中心圆、对勾），面积控制在页面约 10%–15%（观察估计，不是原文数字）。
3. 色阶表达层级：同一色相的深/浅两档区分重要性（如 Hard S 深绿、Soft S 浅绿；SMART 五列从深绿到灰到米到淡绿渐变）。
4. 红色只做否定/警示（"×"、标题下划线），不与绿色争主色。
5. 系列页统一页眉：左上英文页标题（粗体）、右上"@署名 + 大号编号"；页面下方留白，不加页脚。
6. 标题下加一个圆角描边的"摘要框"：第一行为带红色下划线的结论式定位句（"A - 一句话结论"），第二至三行以极小字号写背景/出处/作者/年份，给出"为什么可信"。
7. 区块编号统一："1/2/3" 绿色圆徽标，或 "#1/#2/#3" 浅灰大数字+黑色小标题，全页不混用。
8. 抽象概念用比喻画：护城河画成真实水沟剖面；7S 画成环绕中心的辐射图；SMART 画成五列色阶卡。
9. 对比用符号+颜色：红×/灰点 vs 绿✓/绿点，比表格更快读出对错。
10. 流程用卡片+箭头：4 步使用方法做成 2×2 圆角卡，卡间 ">>" 浅灰箭头，编号用 01/02/03/04 绿色。
11. 英文关键词与中文名双语并列：英文为细体绿色、中文为黑色，两行紧贴，信息密度高但层次清楚。
12. 解释文字全部灰色小号；只有标题、结论、中文名为黑色，保证"眼睛先扫黑与绿，再读灰"。
13. 每个模型页固定四块信息：定义/要点、结构图、使用步骤、应用场景（或强弱对比），按"左（是什么）→ 中（长什么样）→ 右（怎么用）"排布。
14. 大段说明降级为极小字摘要框，不进入主体区；主体区只留短句（每条约 8–20 字）。
15. 拼图展示用"Done / Well Done"超大黑粗标题，上下各一张，形成直观前后对比（适合小红书封面/内页）。

## 出现的思维模型/框架/方法论
- 护城河分析（Moat Analysis，巴菲特）：用于判断企业能否长期不被取代。五个来源——转换成本、成本优势、网络效应、无形资产、规模效应；案例（页内背景说明）包括微信、ERP 系统（转换成本）、沃尔玛（成本优势）、可口可乐（无形资产）、亚马逊（规模）——文字很小，案例对应关系不完全确定。判断标准：强护城河（高ROIC、利润稳定、有定价权、客户黏性强、难进入）vs 弱护城河（同质化、价格战、份额不稳、利润易被侵蚀、替代品多）。
- SMART 目标模型（乔治·杜兰，1981，《管理评论》）：Specific / Measurable / Achievable / Relevant / Time-bound。案例：把"提升产品表现"改成"在2024 Q3内将核心功能30日留存率从28%提升到35%"。四步用法：明确业务目标→拆解 SMART 表述→设定口径与责任人→定期复盘。
- 麦肯锡 7S 模型（汤姆·彼得斯、罗伯特·沃特曼，1980年代初）：Strategy/Structure/Systems（硬性）+ Style/Staff/Skills/Shared Values（软性），共享价值观居中。四步用法：明确战略变化→检查七要素匹配→识别断点→联动调整。应用：战略转型、并购整合、组织诊断、增长变革。
- 拼图方法本身（Done vs Well Done）：同一内容的"信息堆叠版 vs 设计版"并置，可作为 skill 中"改造示例"的呈现格式。

## 正文金句与方法（来自 note.md）
- 标题：做少一点 做好一点。
- 核心句："把功夫花在能反复使用的地方。"
- Tip 1 字体：无特殊要求时，提前下载好一个无衬线字体（普惠体、思源黑体等），后续 PPT 不用再想，直接使用。
- Tip 2 颜色：商务色彩搭配基础公式（黑+白、绿+白、蓝+白）——一个重点色 + 一个基础色即可。
- Tip 3 排版：掌握最基本的排版即可——左右、三分、上下；所有设计小巧思都离不开基础排版。
