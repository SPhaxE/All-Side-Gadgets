# J人会喜欢的排版！（2026-09-09）

## 本篇主旨
这是一套"商业模型/图表类型速查卡"系列（编号 017/018/025/026/081/082）：每个模型占一张"定义卡"加一张"案例卡"，用统一的模块化网格把理论、拆解、案例、数据放在一页，信息密度极高、结构严格，所以叫"J人会喜欢的排版"。note.md 只有标题和标签（ppt、数据可视化ppt、storytelling、思维模型、工作汇报、汇报技巧、商赛），没有正文 tips。

## 逐页拆解

本篇需读的 3 张图（01/02/10）都是 3 张幻灯片竖向拼接（每张约 1080 宽，三页上下排列，浅灰蓝背景上放白色圆角大卡片）。以下按"图 + 上/中/下"分别描述。

### 共同的页面骨架（9 页都适用）
- 外层：浅青灰蓝背景（拼图底色），每页是白色圆角卡片，带细灰描边和轻微阴影。
- 顶部标题栏：左侧英文大标题（黑色粗体，约 28-30pt 视觉等级），案例页在英文名后追加 " - CASE STUDY：中文案例标题"（字号小一级，细体）；右侧是"@ICEPPT"（深绿，字距拉开的衬线风）+ 三位数页码（黑色粗体大号，如 017/018/081）。
- 定义页第二行是一个圆角白框"定义卡"：首行为"模型名（中文名）- 一句话主旨"，模型名加粗并带红色下划线，后面破折号接主旨；下面 2 行小号灰黑正文解释来历与用途。
- 案例页第二行是一条结论句：行首黑色实心圆点 + 粗体一句话，写"通过……，实现……"，即标题式结论（例如"通过识别……的真实任务，门店在早餐时段优化产品与陈列，实现早间销量提升7倍"）。
- 正文区用 2-3 栏模块化网格；栏标题用淡灰/淡绿底色条（如"1. 竞争定位图""2. 分析重点""3. 竞争商业价值定位图"）。
- 强调色统一为深绿/森林绿，其余几乎全是灰阶，点缀极少量红（下划线、红灯、下降箭头）。

- 字号层级：标题约 28pt 级；结论句约 12-13pt 粗体；栏标题与正文 8-10pt 级；大数字（70%/2.3x/180+）约 20pt 级、绿色。具体磅值不确定，仅为视觉估计。

### 图 01.jpg（中：018 Jobs To Be Done 定义页）
- 角色：定义/框架卡。标题"Jobs To Be Done（JTBD）"，右上"@ICEPPT 018"。
- 定义卡：加粗"Jobs To Be Done (JTBD) 任务驱动理论"红下划线 + "- 用户买的不是产品，而是雇它来完成一项任务"，下方一段小字：来自哈佛商学院教授克莱顿·克里斯坦森，2000 年代提出，核心洞察是奶昔案例。
- 版式：左 2/3 为 8 宫格框架，右 1/3 为说明栏。左侧用黑色实心圆内白色数字 1-8 编号，每格是"英文 / 中文"小标题 + 灰色要点：1 THE JOB/核心任务（"用一句话说明用户真正想完成什么进展"）；2 CONTEXT/情境（何时、何地、在什么约束下发生：通勤途中/时间紧张/无法做下来吃饭）；3 ACTORS/用户角色（谁在雇佣这个解决方案：忙碌上班族/学生/新手用户）；4 FUNCTIONAL/功能任务（快速解决问题/提高效率/节省时间）；5 SOCIAL JOB/社交任务（看起来专业/避免尴尬/在他人面前保持体面）；6 EMOTIONAL/情感任务（感觉安心/不焦虑/对自己更满意）；7 SUCCESS/成功标准（更快/更省力/更可控/更预约）；8 ALTERNATIVES/替代方案（竞品/不作为/人工流程）。整个 8 宫格外加一个细灰边框，格子间用灰色细线分隔。
- 右栏：大号黑字"Jobs to be done"（约 20pt 级）+ 一句解释；绿色药丸标签"经典案例：奶昔案例"+ 3 条编号灰字（用户在通勤途中需要打发时间并填饱肚子；奶昔被雇用来便携、耐喝、少打扰；竞争对手不是别的奶昔，而是香蕉、面包和"不买"）；"如何使用JTBD"小标题 + 4 条带灰色对勾的清单（挖掘真实进展需求/关注情境而非人群标签/比较所有替代方案/围绕任务设计解决方案）。
- 配色：几乎全灰黑，仅"@ICEPPT"和绿色药丸标签有绿色。

### 图 10.jpg（上：025 Marketing Funnel 定义页）
- 角色：定义/对比页。标题"Marketing Funnel"，定义卡"Marketing Funnel (营销漏斗 - AIDMA / AISAS) - 消费者从认知到购买的决策路径演变。"下方 2 行正文：AIDMA 是传统媒体时代的线性模型，AISAS 是互联网时代的互动模型（强调搜索 Search 与分享 Share），形成"购买即传播"的闭环。
- 版式：中间一条灰色竖线 + "VS"，左右对半。左：灰色圆形徽标"AIDMA"，5 个灰色药丸（Attention(注意)/Interest(兴趣)/Desire(欲望)/Memory(记忆)/Action(行动)），每个药丸左侧有一个特别大的斜体衬线首字母（A/I/D/M/A，浅灰半透明做装饰），右侧是由宽到窄逐层收窄的灰色描述条（通过电视/报纸广告引起注意 → 产生兴趣想要了解更多 → 产生购买欲望，情感驱动 → 记住品牌等待购买时机 → 最终购买）。右：深绿圆形徽标"AISAS"，5 层漏斗描述条逐层收窄（Attention/Interest/Search/Action/Share），首字母 A-I-S-A-S 用深绿加粗大斜体放在右侧；新增的 Search 和 Share 两层用浅绿底 + 绿色虚线边框 + 黑色三颗星★★★标记，作为"与 AIDMA 的差异"。
- 底部"Insight"：绿色衬线体标题 + 圆角阴影条小字："在 AISAS 模型中，搜索和分享是两个关键节点。营销的重点不再仅仅是"曝光"，而是"SEO/SEM"和"口碑管理(KOL/KOC)"。得搜索者得天下，得分享者得未来。"
- 配色手法：旧模型全灰（淡化）、新模型用绿色，强调"变化部分"；这是"灰色=旧/背景，绿色=新/重点"的对比。

## 提炼出的设计规则
1. 每个模型固定"两页制"：定义页（是什么+怎么用）+ 案例页（真实公司+数据），页码相同，用 "- CASE STUDY：" 在标题后明确区分。
2. 标题栏三要素固定位置：左为英文模型名、右为署名 + 三位页码；案例页标题后追加一句中文案例名。系列感靠位置不变而不是靠装饰。
3. 案例页第二行用"通过 X，实现 Y"的结论句（黑色实心圆点 + 粗体），先给结论再给证据，对应 storytelling 的"结论先行"。
4. 定义页第二行用"模型名（中文）- 一句话主旨"的定义卡，模型名加粗并加红色下划线，是整页唯一的红色装饰；后面追加 2 行以内的正文。
5. 正文区采用 2-3 栏模块化网格，栏标题用淡灰底色条 + 数字（1/2/3），卡片间留白一致，卡片用圆角、细灰边或浅灰底，不用粗描边。
6. 一页只用一个强调色（深绿）：图表中只把"要说明的那一根柱/一条线/一个数"着色，其余全部灰色（如 OLIPOP 一根柱用绿斜线填充，其他三根灰色；3/7/11 月绿色，其他灰色）。强调色面积看起来约占 10-15%。
7. 对比类内容用"灰 vs 绿"：旧模型/旧做法全灰，新模型/新增部分绿色并加虚线框或星标（AIDMA vs AISAS）。
8. 关键数字放大：每个模块配 1 个大号数字（衬线或粗体，深绿或深灰，如 15,000+、>80%、7.0x、70%/2.3x/180+），说明用 6-8pt 级灰色小字附在下面，形成"数字-说明"二级。
9. 图表直接标注而不是画图例：数字写在柱内/柱顶，折线终点用大圆点 + 数值（5B+），时间点只标关键节点；图表下方加 1-2 行"读图结论"。
10. 一个定义页要带"怎么用/设计原则/常见陷阱"类的清单（对勾列表、警示图标列表），并有"Insight / 如何使用 XXX"总结语。
11. 用编号徽标指导阅读顺序：黑色实心圆白字 1-8（JTBD 8 宫格）、绿色圆形字母 A/B/C、绿色圆形编号，避免读者不知从哪看起。
12. 英文小标题 + 中文并列（"THE JOB / 核心任务"），给框架格子做"术语对照"，增强专业感（nerdy 风）。
13. 装饰性大字母或衬线体用于"首字母框架"（A-I-D-M-A、R/F/M）：首字母放大为斜体衬线，用来帮助记忆缩写词。
14. 地图/矩阵类图表，用同色相明度渐变做色阶（5-7 级），图例放右下角；矩阵格用明度表达价值高低（RFM 八格）。
15. 用图标（线性、灰色、同风格）配指标，不用彩色图标；图标作为指标的前缀而非主视觉。
16. 页面信息量极大、最小字号约 6-8pt 级：只适合作为"速查卡/长图"阅读，不适合现场投屏，做汇报 PPT 时应只取其结构（结论句+3栏+大数字），字号提至 ≥12pt（此条为我的推断，不是图中明示）。

## 出现的思维模型/框架/方法论
- Competitive Positioning Map（竞争定位图，2x2 矩阵）：用 "专业性-大众化"x"低价值感-高价值感" 画四象限，案例 OLIPOP 占据"高端溢价区/大众差异化区"附近的差异化位置；再配搜索指数、渠道结构、价格带三图佐证。
- Jobs To Be Done (JTBD，克里斯坦森)：8 要素框架（核心任务/情境/用户角色/功能任务/社交任务/情感任务/成功标准/替代方案），案例为麦当劳早餐奶昔（通勤途中打发时间+填饱肚子+单手携带；竞争对手是香蕉/面包圈/能量棒/不买），结果早餐时段销量 1.0x → 7.0x。
- Dashboard UI（综合仪表盘）：金字塔原理分配版面（顶 20% 宏观概览 / 中 50% 战况剖析 / 边缘预警区）；12 栏或 3/4 栏网格；留白即边框；数据为主；五原则：信息层级、单屏叙事、视觉一致性、对比优先、高密度可扫描；四陷阱：信息过载、无视觉重点、图表逻辑不一、只有数据。
- Choropleth Map（热力地图）：数据归一化（人均/密度而非总量）、渐变图例分 5-7 级；按空间分布识别 Stronghold（根据地）/ Outpost（飞地）/ White space（留白）三类战略区。
- 营销漏斗 AIDMA vs AISAS：Attention-Interest-Desire-Memory-Action（线性）与 Attention-Interest-Search-Action-Share（闭环）对比；案例完美日记：种草（头部明星→腰部KOL→万名KOC）→ 搜索（SEO 关键词占位）→ 行动（DTC/私域）→ 分享（UGC 激励），GMV 2017-2020 曲线至 5B+，CAGR>300%。
- RFM 模型：Recency/Frequency/Monetary 三维，H/L 二分得 8 类用户（重要价值/唤醒/深耕/挽留 + 一般价值/发展/保持/挽留），每个维度配策略（唤醒/培养/优待）。
- 汇报通用方法（隐含）：结论先行（"通过X实现Y"）、定义+案例两页制、先整体后细节（总-分结构）。
