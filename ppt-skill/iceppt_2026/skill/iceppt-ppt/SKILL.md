# iceppt 风格 PPT

方法来自账号 iceppt（小红书号 94397528789）2026 年 61 篇幻灯片图笔记，由逐页读图分析后汇总。数据范围和剔除情况见 [references/sources.md](references/sources.md)。

**先读这条：** 所有 hex、字号、间距都是作者图片的目测估算，没有实测值；各章节里标了"分歧"和"推算"的地方不要当事实。

## 怎么用这个 skill

1. 动手前先确认场景和听众：汇报 / 述职 / 周会 / 面试 case / 商赛 / 单页改稿。
2. 按下面"工作顺序"走，需要细节时再读对应参考文件，不要一次全读。
3. 要产出 .pptx 文件时，同时加载 `pptx` skill，由它负责文件生成；本 skill 只提供设计与内容规则。色板直接用 [references/design-tokens.json](references/design-tokens.json)。
4. 做完对照"自检清单"逐条过一遍。

## 工作顺序（先结构后排版）

1. 先写三句话：发生了什么 / 为什么 / 接下来做什么。再问"对方要靠这几页判断什么"。
2. 先写全部页标题（每个都是结论句），再选框架装叙事，再填数据，最后调版式、图标、颜色。
3. 第 1 页放结论，最后一页写清"需要对方拍板的是什么"，行动卡不超过 3 张。
4. 每页只回答一个问题，只设一个视觉重点，其余降灰。
5. 先做出结构清晰的"Done"版（内容对、逻辑清），再升级成"Well Done"：名词标题改结论句、表格改图形、灰色堆叠改单一强调色、选定视线落点。

详细展开：[叙事与结构](references/03-story-structure.md)、[工作流](references/05-workflow-craft.md)。

## 核心规则（跨多篇稳定出现）

**视觉**（详见 [01-visual-system](references/01-visual-system.md)）
- 作者 2026 年有两套体系：06 月底起的**绿色 nerdy 体系**（下面规则的主体，样本最多），和 01–06 月的**酒红咨询体系**（面包屑导航、粗体标题、2–3pt 黑通栏线、酒红 + 鼠尾草绿 + 灰，正文 10–14pt 更适合投屏）。用户没指定时默认绿色体系；要酒红体系时读 [01-visual-system](references/01-visual-system.md) 第 9 节。
- 绿色体系下，全页只用黑、白、灰 + 一个绿色色相。深绿 `#0E7C66`（沉稳版 `#1F5C46`，整套只选一种）。实心绿面积 ≤10%，含浅绿底 ≤25%，灰与白 ≥75%。
- 一页只让 1 个对象拿最强强调（深绿描边或实心块），其余全部降灰。
- 红色只做否定或警示，面积 <2%，如定义框里框架名下的红下划线、✗、风险标记。推荐 `#D0312D`。
- 信息分三层灰度：主信息 `#1A1A1A`、次级 `#777777`、补充 `#AAAAAA`；层级靠字重、灰度、位置，不靠加字号或加颜色。
- 页头骨架全套固定：左上英文框架名粗体 22–28pt（案例页同行追加 " - CASE STUDY：…" 14–18pt），右上品牌小字 + 三位页码。
- 英文大标签用细体绿色 22–30pt，中文说明小号粗体或灰色叠在其下，形成"一大一小、一细一粗"的节奏。
- 大数字为正文的 3–5 倍，一张卡只放一个，下面一行灰色口径。
- 容器：圆角卡、线宽 ≤1pt、浅灰或浅绿底、默认无投影（只给 1 张重点卡加）。实线框表事实，虚线框表假设或待验证。
- 页面底用白色，不要铺青灰；拼图外底 `#BFD8D8` 只用于封面或预览。
- **两种页型**：高密度速查页可参考作者 7–10pt 正文；汇报现场页正文取 ≥10–12pt，只保留"结论句 + 3 栏 + 大数字"。这是作者自己多次提醒的，要投屏就用后者。

**标题与结论**
- 标题写结论句，不写名词：对象 + 动作 + 结果，尽量含数字，一到两行（约 25–70 字）。副标题式用"● 粗体结论句"，不要混用多种格式。
- 单个数字必须配基准（去年、目标、行业），变化写成"灰色旧值 → 强调色新值"。

**图表**（详见 [02-chart-craft](references/02-chart-craft.md)）
- "灰 + 一色"：非重点对象灰色，只把要讲的 1–2 个柱、线、气泡或格染深绿。去网格线、去图例，数值和名称直接标在图上。预测值用更浅色、斜纹或虚线。
- 先选图再排版，让形状承载结论：分档累计 → 阶梯图，两端点差距 → 哑铃图，两时间点变化 → 斜率图，多个同构对象 → 小多图；漏斗在流失最重一层拉开间距，金字塔改"顶部结论 + 下方依据"。
- 每图只放 2–3 个白底圆角注释气泡加细引线，每个不超过 3 行，图旁补一句 So-what。
- 基础图形可以拆分、展开、拉伸、重组，但必须保留层级、循环、交集等逻辑关系和数据比例。

**框架与页面结构**（详见 [03-story-structure](references/03-story-structure.md)、[04-thinking-models](references/04-thinking-models.md)）
- 每个思维模型做成两页成对："概念页"回答是什么、怎么用，"案例页"给真实场景和至少 2–3 个带基准的硬数字。只有概念页时要标明未经案例验证。
- 先选框架、填框、再找数据，不要按资料顺序平铺。竞品类汇报可套 3C；抽象方法必须配案例。
- 把"我做了什么分析"改写成"这页帮你判断什么"。

**可编辑性底线**（详见 [05-workflow-craft](references/05-workflow-craft.md)）
- 所有元素可选中；图表用原生图表、数据在内置 Excel；标题与坐标轴文字分开文本框；不用矩形拼假柱状图；字体不乱码。
- 一次定好三样复用资产：一个无衬线字体、一个强调色加一个基础色、三种基础版式（左右 / 三分 / 上下）。换内容不换骨架。

## 自检清单

- [ ] 每页标题都是结论句，且能单独读懂？
- [ ] 每页只有一个视觉重点？强调色面积 ≤10%？
- [ ] 红色只出现在否定或警示处？
- [ ] 数字有基准？大数字一卡一个？
- [ ] 图表去了图例和网格，标注直接上图？
- [ ] 用到的框架有"概念 + 案例"，案例有硬数字？
- [ ] 首页有结论、末页写了需要对方拍板的事？
- [ ] 要投屏的页，正文 ≥10pt？
- [ ] 元素可选中、图表可编辑？

## 不要做的事

- 不要编造"淡人感"之类笔记里没有定义的概念；61 篇里没有任何一篇定义它。
- 不要把拼图画布的边距当成幻灯片内边距。
- 不要因为同一页在多篇笔记里复用，就把它当成多条独立证据。
- 不要复刻作者的商品宣传页（封面卡、目录页、"附文件"引导）。
