# 结构卡（structure）

图库标签只说"这页是什么图"。结构卡说"这页由哪几块组成、各在哪、每块里有什么"。复刻时按结构卡一块一块对。

目前有 10 张，都是绿色体系的高分页，由主会话逐张对着原图写成。坐标是目测加刻度线读数，误差约 ±2%；字号由像素行高折算，误差约 ±1px。

## 怎么用

1. 在下表选一张和你要讲的内容关系最近的结构卡，Read 对应的 `../slides/<tid>.jpg` 原图。
2. 按卡里的版块表搭骨架：每个版块的位置、大小、底色、描边都照做。
3. 每个版块按"里面有什么"填内容：文字类型、条数、每条大概多长，都向原图看齐。内容换成你自己的，数量不要减。
4. 细节元素清单里的东西逐个做出来，这是"原帖感"的主要来源。
5. 截图后和原图上下拼在一起看，再跑 `node tools/layout-check.js`，留白和细节密度应落在原图范围内。

## 共用规格（绿色体系，1280×720 画布）

坐标写法：`x% y% w% h%`，相对整页宽高。字号是 1280 宽画布上的 px。

### 字号刻度

| 用途 | 字号 | 字重 / 颜色 |
|---|---|---|
| 框架名、页码 | 27–29 | 粗黑 |
| 英文大标签（Background、Strategic Threat） | 20–24 | 细体，绿或深灰 |
| 大数字 | 26–44 | 细体绿色；单位和货币符号小一号 |
| 结论句 | 14–15 | 粗黑 |
| 版块小标题 | 13–14 | 粗黑，常为"English \| 中文"双语 |
| 卡片标题、图上主标签 | 12.5–13 | 粗 |
| 正文 | 12–13 | 深灰 `#555`；段首引导词加粗 |
| 批注、坐标轴、图例 | 10–11 | 浅灰 `#888`–`#AAA` |

正文 12–13px 是原图的实际大小，对应约 9–10pt。原图密度就是靠这个字号撑起来的。

### 颜色（实测中位，JPEG 上偏浅）

- 深绿强调 `#1F7A66` 左右（实测中位 `#34816E`）；实心深绿只用在 1–3 个小块上。
- 浅绿底 `#D9EBE5`–`#E4F0EA`；浅灰底 `#F3F3F1`；灰条 `#EDEDEB`。
- 文字：`#1A1A1A` / `#555` / `#999` 三档。
- 第二色相只在需要区分两个角色时用：紫 `#7B3FA0`、橙 `#E0A060`、米色带 `#EFE9DC`。红 `#C0392B` 只做 ✗、▼ 和下划线。

### 细节元素词表

结构卡里用这些名字指代小元素。每页通常用到 6–10 种。

- **胶囊标签**：圆角全满的小标签，灰底或白底，12px，压在卡片上边线上（如 `Step 1：核心命题`、`Option A：内部自建`）。
- **英文标签块**：浅绿底 + 细体绿色英文 20px + 下方 2px 绿线（如 `Background`、`Actions`），旁边带 3 个竖排小圆点。
- **灰条行**：一行文字放在浅灰或浅色底的横条上，条高约 24px。
- **引导词**：段首 2–6 个字加粗，后面跟冒号或竖线，再接灰色正文（`背景 | …`、`核心任务：…`）。
- **批注框**：白底、1px 灰描边、圆角 8px、2–3 行 11px 灰字；用细线加小圆点连到数据点。
- **浮层卡**：白底、带投影、圆角 6px；粗体标题 + 灰色"核心数据："+ 3 行数值，数值加粗。
- **大序号**：`#1`、`01` 这类浅灰大字（22–40px）放在卡片左侧。
- **圈号**：绿色实心圆里放白色数字，直径 20–26px。
- **勾和叉**：绿色 ✓ 表示保留或要点，红色 ✗ 表示否定；细线条，不是实心图标。
- **色带**：图表里一条竖向的极淡色带，标出要讲的那一组数据，顶部用同色细体字写名字。
- **收口条**：页面底部通栏浅灰条，1–2 行，关键词加粗或加下划线。
- **VS**：两个方案或两个数字之间的粗体或细体大字。
- **投影卡**：圆角卡片，右下方向的柔和投影，只给重点卡。
