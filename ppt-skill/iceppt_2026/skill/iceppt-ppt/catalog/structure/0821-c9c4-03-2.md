# Executive Summary 099（案例页）

原图：[`../slides/0821-c9c4-03-2.jpg`](../slides/0821-c9c4-03-2.jpg)　约 330 个汉字，6 个版块，十来种小部件。图库里密度最高的一类，适合做第一页。

**读图顺序**：结论句 → 四栏从左到右（问题 → 结论 → 建议 → 行动）→ 底部影响带。
**强调落点**：四个绿色圈号把四栏串起来；第三栏小瀑布图的终点柱是绿色。

## 栏头（四栏相同）

绿色实心圈号（直径 26px，白色数字）；右边粗体标题 12.5px；标题下一行灰色问句 10.5px（"我们面临什么问题？"）。栏与栏之间一条细竖线。

## 各栏里的小部件

- 指标表（栏一）：4 行"指标名 … 数值"，行间细线，12px。
- 大序号结论（栏二）：绿色数字 18px + 一句 12px，每句含一个数字。
- 对比表（栏二）：表头灰底，列是"公司 / 行业 / 差距"，4 行，10.5px。
- 序号小卡（栏三）：浅灰底，左上角小方块里一个数字，粗体标题 11.5px，下面 2 条灰色圆点。
- 迷你瀑布（栏三）：4 级灰色台阶各带一个百分比标签，终点柱绿色，横轴 5 个标签。
- 迷你甘特（栏四）：表头 3 个阶段，4 行任务，每行一根灰条，位置错开。

## 细节元素

圈号 ×4、大序号 ×3、序号小卡 ×3、胶囊标签 ×1、下指箭头 ×1、圆角方形图标 ×4、人形图标 ×1、细竖线 ×3、绿色横线 ×1、表格 ×2、迷你图 ×2。
