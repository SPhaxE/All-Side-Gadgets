# SCR Framework 096（案例页）

原图：[`../slides/0821-c9c4-01-2.jpg`](../slides/0821-c9c4-01-2.jpg)　约 230 个汉字，6 个版块。适合"先给成绩、再讲问题、最后给动作"的页。

**读图顺序**：结论句 → 顶部三个大数字 → 左下两张小图和三个指标 → 右下三大举措。
**强调落点**：顶部三个细体绿色大数字；左下折线图里一段灰色阴影加一个粗体负值。

## B 每个 KPI

细体绿色大数字（40px，货币符号小一号）；下面一行标签（11px）；再下一行灰色同比（`↑15% YoY`，11px）。

## D 小图

- 左图：一条折线带数据点，后半段下方铺灰色阴影，旁边写粗体负值和一行说明。
- 右图：一条平滑下行曲线，每个点上标数值（粗 10px）。
- 纵横轴刻度 9px，没有网格。

## F 每一行

左格：浅灰底，绿色圈号 + 粗体标题 12.5px。右格：3 条圆点，12.5px，每条 8–15 字。

## 细节元素

圈号 ×3、灰条行 ×5、叉 ×3、右指三角 ×1、方括号线 ×1、细竖线 ×2、绿色分区线 ×1。
