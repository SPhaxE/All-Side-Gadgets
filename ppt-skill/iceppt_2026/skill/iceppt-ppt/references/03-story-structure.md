## 一、跨多篇稳定出现的规则

### 1. 叙事总原则

**R1. 结论先行，按听者要听的顺序讲，不按你做事的顺序讲。**
- 先结果后过程。作者的理由是"前 30 秒没抓到重点，对方就在看手机了"。依据：07-14、07-16、08-11。
- 汇报第一页（page1）直接放结论。依据：07-16。
- 先讲洞察再讲数据。反例：先说"完成 5 个项目、12 场活动"。正例：先说"用户增长停滞，不是活动少，而是一直在触达同一批人"，再接数据、原因、方案。依据：07-28。
- "结论放在前面，数据接住判断，整份 PPT 自然形成一条分析链。"依据：08-11。

**R2. 站在听众视角，把"我做了什么分析"改写成"这页帮你判断什么"。**
- 改写公式：分析名 → 听众的一个问题。作者给的示例（10-14）：
  - 市场分析 → 这个市场现在还值得进入吗？
  - 用户画像 → 下一阶段应优先服务谁？
  - 护城河分析 → 同样卖饮料，这个品牌凭什么被选择？
- 动笔前先确认决策者关心什么，再定结论和证据，最后才搭页面。依据：08-12、10-14。
- 面向 VP 或老板时，页面按"决策者要做的判断"组织，而不是按"资料收集顺序"。依据：07-16、07-14。

**R3. 每页只回答一个问题、只讲一个结论、只设一个视线落点。**
- 作者的三问自检："这页讲什么、用了什么数据、得出什么结论"。依据：03-24。
- 一页内最大字号、最深颜色、最大色块，只给最关键的信息，其余降为灰色小字。依据：10-12。
- 色重点和页面结构，就是汇报者思维的聚焦。依据：05-25。
- 述职模板一页只讲一个故事，结构为"左图 + 右图（或洞察卡）+ 底部结论"。依据：01-13、03-17。

**R4. 用现成框架装叙事，不要按资料顺序平铺。**
- 流水账 vs 思路：
  - 流水账："我做了 A、B、C"。
  - 思路："围绕降本这条主线，我从 X 和 Y 两个方向推进"。
  - 依据：07-14。
- 竞品动作汇报，不要按搜集顺序念，直接套 3C：市场在变什么、对手在做什么、我们的位置在哪。"分析的核心逻辑，就是把散装的资料装到框架里。"依据：07-16。
- 工作顺序：先选框架，把逻辑框填满，剩下只是找数据。依据：07-10、09-04。
- 框架不用自己发明。依据：07-14、07-31(meeting)、08-07(独生脑)。
- 被追问或被 cue 时，先快速判断四件事。依据：07-31(meeting)：
  1. 这是什么类型的问题。
  2. 用什么框架分析。
  3. 先讲结论还是先讲原因。
  4. 被追问时往哪里展开。

**R5. 先写"页标题序列"，再填内容和排版。**
- 推荐做页顺序（作者原话整理，依据 09-04）：先定框架 → 填数据 → 决定留哪些数据 → 写结论句 → 最后才调图标、间距、颜色。
- 急活：先写好每页大标题，再一张张往下搭。依据：08-12。
- 不知从何下手：先写第一页标题，再找能支撑它的数据。依据：08-28。
- 动笔前先写三句话：发生了什么？为什么会这样？接下来要做什么？写顺了再排版。依据：07-28。
- 推论（我的归纳，非原文）：把所有页标题单独抄成一列，只读这一列应能复述完整结论。01-13 的"读者只读标题即得结论"支持这一做法。

**R6. 末页给行动，说清"需要对方拍板什么"。**
- 作者原话："最后一页说清'需要您拍板的是什么'"。依据：07-16。
- 一页纸摘要的第四列是"下一步行动"，底部用一条线加 4 个"预期影响"数字收尾。依据：08-21。
- 树状拆解的叶子节点必须写成可分配的任务：动词开头 + 对象 + 范围。图底部放"根本原因 + 行动方案"。依据：08-28。
- 案例页的行动卡不超过 3 张，各带灰色大序号。依据：09-03。

### 2. 每页标题的写法（结论句公式）

**R7. 标题不写名词、不写"XX 分析 / XX 数据汇总"，写带判断的完整句。**
- 依据：10-12、10-14、10-26、10-29、11-05（作者明确对比过名词标题与结论句标题），另有 01-13、02-24、03-28、02-08（页面实例）。
- 通用公式：对象（主语）+ 动作或做法 + 结果（含数字）+ 必要时加判断。
- 各笔记里出现过的变体（均可直接套用）：

| 公式 | 例句 | 依据 |
|---|---|---|
| 做法 → 结果（含数字） | "……将吞吐量提升了 30%" | 07-09 |
| 通过 X，实现 Y | "服务收入占比可从 8% 跃升至 25%" | 09-09、08-20 |
| 现象 + 行动 + 结果 | "拒绝……通过……成功……" | 10-20 |
| 在 X 情境下，通过 Y，实现 Z | 含 40%、1.5 亿美元等量化结果 | 08-14 |
| 问题 + 原因 + 对策 | 一句话讲清，全页内容都是对它的论证 | 08-21 |
| 放弃什么 / 强化什么 | "战略性放弃 X，极致拉满 Y……" | 08-25 |
| 主语 + 对比 + 动作 | "必须卖出 40,000 件" | 08-13 |
| 方法 + 发现 + 结果 | 如 2 亿美元、12 周 | 08-31 |

**R8. 结论句的位置有两种稳定写法，按场景选一种，不要混用。**
- A. 副标题式（案例页、商赛、面试 case）。
  - 标题栏写"模型名 - CASE STUDY：案例名"，下一行放"黑色实心圆点 ● + 粗体一句结论"。
  - 这是 iceppt 案例页的固定结构，但它是同一模板系列的重复展示。
  - 概念页则是"框架名（中文）- 一句话定位"的定义框，框架名加红色下划线，其后 2-3 行小字。
- B. 行动标题式（述职、年终汇报，标题本身就是结论）。
  - 格式："2-4 字主题词：一句含数字的结论"，主题词加粗，结论常规字重。依据：01-13、03-17、02-08。
  - 示例：02-24 的 "market size will double in 2027"。
- 推论：现场汇报用 B。标题已是结论，不必再加副标题行。A 更适合作为阅读型资料或案例拆解页。

**R9. 结论句长度和字号区间（估，各篇不完全一致）。**
- 长度：1-2 行，约 25-60 字。
  - 各篇给出的数值：08-11 为 20-35 字，10-08 为 25-40 字，07-14 为 40-60 字，09-04 为每行 ≤60 字。
  - 10-29 给过 40-70 字，是上限值。
- 字号（估）：
  - A 式：结论句约为正文的 1.3 倍，粗体。依据：09-03。
  - B 式：主题词约 20-24pt 粗体，结论约 14-18pt 常规。
  - 三份 B 式依据：01-13 为 20-30pt，03-17 为 20pt/14-16pt，02-08 为 24pt/18pt。
- 这三篇（01-13、03-17、02-08）很可能出自同一述职模板系列，不是三个独立样本。
- 必须含具体数字或具体对象，不用"显著、明显、不错"。作者原话："效果不错"没人记得，"转化率从 3% 提到 4.3%"才是正解。依据：07-14。

**R10. 用基准让数字变成判断。**
- 单个数字必须配一个比较对象：去年、目标、均值、同行。示例：今年 115 万 / 去年 100 万 / 目标 120 万 → 同比增长但未达标。依据：10-29。
- 前后对比写成"旧值（灰）→ 新值（强调色加粗）"。示例：58%→76%、2%→18%。依据：07-09、07-31(meeting)、08-06、09-01。
- 指标表可用"公司 / 行业 / 差距"三列。示例：6.2% vs 11.2%，差 -510bps。依据：08-21。
- 图表标题写洞察，不写图名。依据：07-09。

### 3. 页面骨架、导航与定位

**R11. 全篇共用同一页面骨架，只换内容，不换结构和位置。**
- 依据：01-13、02-08、02-24、04-20、04-27、05-15（面包屑/章节导航系列）；09-04、10-19、08-31、09-09（CASE STUDY 系列）。
- 两套骨架（见下表，字号为估）：

| 骨架 | 自上而下 | 适用 |
|---|---|---|
| 咨询 / 述职风 | 导航（面包屑或章节条，约 8-11pt 灰字，当前项加粗）→ 主标题（24-32pt 粗黑）→ 2-3pt 黑色全宽线 → 内容区 → 底部结论条 → 页码 | 年度述职、周期汇报、提案 |
| 案例页风 | 标题栏（模型名 + CASE STUDY 案例名 + 右上编号）→ 黑圆点结论句 → 主体（左图右文）→ 底部 Insight 灰条 | 商赛、面试 case、框架拆解 |

**R12. 长汇报必须有页面导航，让听众随时知道自己在哪。**
- 章节导航条：顶部放 9 项左右，约 8-10pt 灰字，当前项黑色加粗 + 下划线，右上放页码。依据：01-13、02-08、03-17。
  - 作者原话："每页左上角的清晰导航+定位，让人跟着你的思路走"。依据：01-13。
- 简化版是三段面包屑 "Part 1 → **Part 2** → Part 3"，当前段加粗黑，其余浅灰，约 10-11pt。依据：02-24、04-20。
- 导航项数：9 项与 3 段都出现过。摘录里没有 9 项的具体章节名，不要编造；按你的汇报章节自行填。
- 此规则仅限长文档，短汇报（约 8 页以内，页数为我的建议，不是笔记数据）可省略导航，只用面包屑。

**R13. 版式固定为"左图右解读"，让阅读路径可预测。**
- 左主图占约 55-65%，右侧占 35-45%。依据：09-03、03-17、08-31、07-16、07-21。
- 数据多时用三栏等宽，栏头统一为"编号 + 粗体短句 + 细线"。依据：06-04、02-24。
- 图与文用编号一一对应（图中 1-4 对应右侧卡 1-4，或用 A/B/C 徽章），读者不用在图例和正文间来回找。依据：08-31、10-09、04-01。
- 一页最多 3-4 个编号小标题或模块。依据：03-28、06-15。

**R14. 每页底部放一条"So what"收口条。**
- 灰底或浅绿底通栏，1-2 行。内容是结论、启示、原则或风险水平，关键词加粗。
- 依据：07-09、11-05、09-15、08-06、09-04、03-28、01-13、02-08。
- 条数不超过 3 条。依据：09-15。
- 图下方配一句读图结论（"完全避开红海参数战……"）。依据：09-09、08-25。

### 4. "Done → Well Done" 升级方法

作者的定义（10-12）：信息平铺是 done，信息整合再展示是 well done。内容几乎不变，差别全在版式和叙事。

**R15. 升级路径：先保证 Done，再逐项升级。**
- Done 的标准：内容正确、结构清晰的灰黑版。依据：10-20。
- 升级动作清单，按优先级：
  1. 名词标题改为结论句。依据：10-26、11-05、10-12。
  2. 选定 1 个视线落点。可以是 SWOT 的大字母、"12x Faster"、"16.8% → 19.2%" 或一个流失最严重的步骤。依据：10-12、10-20。
  3. 把表格还原成内容本来的形状。2x2 画坐标，流程画箭头链，层级画金字塔。依据：10-12、10-14、10-26。
  4. 数字图形化。"5/5" 改为 5 个点，差距写成倍数标签，变化写成"灰前值 → 深色后值放大"。依据：10-12、11-04。
  5. 把页底的预期结果提到页面最上方做 KPI 卡。依据：10-12。
  6. 主次拉开：核心判断 > 分析维度 > 补充说明。依据：10-12。
     - 量化建议（10-12 的建议，非原图数据）：核心字号 ≥ 分析维度的 1.5 倍；补充说明用灰色（约 #9A9A9A）、更小、常规字重。
  7. 降权但不删减。次要内容退为灰色小字加图标。依据：10-12。
  8. 位置表达关系：相关的放近，并列的同高同宽对齐，从属的用分组框。同级标题的字体、字号、颜色统一。依据：10-12。
  9. 先决定重点，再决定版面。同一套四栏内容，不要四栏等宽，重点栏做最宽并给唯一粗边框。依据：11-04。
- 作者在 10-29 列出的"Done 反面教材"：全灰表格、簇状柱无重点、8 线叠图、文字比图多。出现这些就该改造。

**R16. 用颜色承载叙事，且含义要说清。**
- 颜色会被观众读成信息差异。颜色至少表达三件事：先看这里、这些属于同一件事、这里有差别或变化。依据：10-23。
- 同一含义的颜色跨页保持一致。例如前页蓝色代表海外业务，后页继续用。依据：10-23、10-12。
- 风险：三个平级方案用越来越深的蓝，会被误读为有等级。依据：10-23。
- 强调色面积一般 ≤10-15%，只给一个对象。依据：10-12、10-26、10-20、10-19 等，数值为目测估计。
  - 10-29 的 8:2 法则允许到 ≤20%。

### 5. 汇报框架与叙事结构（框架当作页面骨架）

以下框架出现在 08-21、08-20、11-04、10-19、10-20 等篇。同一页被多篇复用，只算一份证据。

| 框架 | 叙事用法 | 页面结构要点 | 依据 |
|---|---|---|---|
| SCR | 背景—冲突—解决 | S 只讲必要背景；C 必须尖锐（"没有冲突就没有关注"）；R 必须回应 C。R 区用浅绿整块底色 | 08-21、10-20 |
| BAB | 现状—桥梁—目标 | 引语"先让人看到问题，再让人看到希望，最后让人相信路径"；三个虚线卡片按山形高度错落；Bridge 栏浅绿底 | 08-21、08-20 |
| Burning Platform | 提案推动变革 | 最终目标是"不改变的代价 > 改变的成本"；"维持现状本身才是最大的风险" | 08-21、11-04 |
| Executive Summary | 给高层的一页纸 | 四列：背景与核心问题 → 关键结论 → 战略建议 → 下一步行动。必须假设"老板只看这一页" | 08-21 |
| PREP / Answer First | 电梯汇报、口头表达 | "永远把结论放在第一句话"。PREP 可画成 0s/30s/60s/90s 时间轴，Example 卡放大加描边 | 08-20、11-04、10-20 |
| STAR / Why-How-What / SCQA | 经历复盘、价值观与动机、提问式开场 | STAR 的"行动"栏最宽加粗框；其余等宽等重会失去重点 | 11-04、10-19 |
| 3C | 竞品与市场汇报 | 三框一填、逻辑齐了，剩下只是找数据 | 07-10、07-16 |
| 假设树 / 议题树 | 把大问题拆成可验证的小问题 | 从左到右分层；被排除分支变灰加红叉并写明原因；保留分支加绿勾；叶子是任务 | 08-28 |

- 框架本身就是页面骨架：先画框架结构，再往结构里填字。依据：07-09、11-04。
- 不要把框架名放在四个等宽文本栏的列头上，要用框架的逻辑形态做版式。依据：11-04。
- 框架可以变形，但支撑、层级、循环、交集的关系必须讲清，涉及数据比例处要准确。依据：10-09。

### 6. 章节故事线（跨页组织）

- 概念页 + 案例页成对。概念页回答"是什么、怎么用"，案例页回答"真实场景里长什么样"。
  - 依据：07-16、07-14、08-04、08-06、08-11 等。案例页的版式延续概念页，图形可复用（10-09、08-04）。
  - 推论：现场汇报通常不需要概念页。这是教学或商赛的结构，汇报只取案例页的"结论句 + 证据 + 行动"。
- 案例页内部的稳定顺序：
  - 背景 → 困境 → 分析 → 行动（#1 #2 #3，不超过 3 张）。依据：09-03。
  - 或 Step 1 核心命题 → Step 2 拆解逻辑 → Step 3 战略行动。依据：09-15、10-29。
- 同一章内用同类图重复，不换图形。依据：06-15（蝴蝶图两组、折线图两张）。
- 框架之间交代关系，做成系列。例如 PEST 是 SWOT 外部分析的输入，输出填入 O/T 象限，形成逻辑闭环。依据：10-08。
- 设置一个叙事钩子：用设问或引号概念（"谁又完成了底层逆袭？""Retail Apocalypse"）。依据：09-01。
  - 这一条主要是单篇出现，见下文特例。
- 观众为什么要继续听下一页，是 storytelling 真正要解决的问题。依据：07-28。

## 二、各场景的页面清单

说明：每个场景的页面顺序由笔记的原话和页面实例拼合，其中标"推论"的部分是我的归纳。笔记没有提供标准页数，也没有给出每页讲多长时间。

### A. 向 VP / 老板做汇报（实习生、日常）

依据：07-16、07-14、08-12、08-21。

1. **P1 结论页**：一句话结论 + 2-3 个支撑数字。如能放下，可直接用一页纸摘要（背景与核心问题 → 关键结论 → 战略建议 → 下一步行动）。
2. **框架页（正文）**：用 3C 或对应框架装叙事。每页标题是结论句，每页只回答一个问题。
3. **数据页**：一页一个主图加 2-3 个说明模块，图旁用批注直指答案，并带基准（去年、目标、行业）。
4. **风险与取舍页**（推论）：写明被排除的方案及原因，比如红叉加原因。依据 08-28 的树状图做法。
5. **末页拍板页**：写清"需要您拍板的是什么"，附下一步行动与预期影响数字。

### B. 年终述职 / 年度汇报

依据：01-13、03-17、02-08、03-24、04-20、02-24。

1. **封面 / 总览**：一页纸摘要，放全年最重要的 3 个数字。
2. **章节导航条贯穿全篇**：9 项左右，当前项加粗下划线，右上角放页码。
3. **每章 1-3 页，每页一个故事**：
   - 标题用"主题词：含数字的结论"。
   - 左图右洞察卡，底部放 Insight 或 Key Takeaway 卡，左侧加 2-4pt 深色竖条。
   - 03-17 给出了图表选型：达成用雷达；增长归因、预算、单位经济用瀑布；趋势拐点用折线加基准线；留存用热力三角表；组合分布用矩阵或气泡；稳定性用 Pareto 加前后对比柱。
4. **KPI 页**：4 张等宽卡并排，每张"大数字 + 双语标签 + YoY 或目标"三层。依据：01-13、02-08。
5. **目标与基准线页**：目标线用红色虚线，并配小字标签。依据：02-08。
6. **下一年计划与所需支持页**（推论）：写成可分配的行动和"需要拍板或资源"。
- 摘录没有给出章节具体名称，也没有给出推荐页数。01-13 的卖点说法是"50 个完整故事，适当增减"，这是模板规模，不是推荐篇幅。

### C. 周会 / meeting 被突然 cue

依据：07-31(meeting)、08-12。
- 没有固定页面清单，核心是一个"现场判断"流程，见 R4 的四件事。
- 急活三步：先确认决策者关心什么 → 再确定结论和证据 → 每页先写好大标题再往下搭。
- 页面最小集（推论）：结论页 + 1 个框架页 + 1 个数据页。

### D. 面试 case

依据：08-11。
1. 先识别问题类型，再套模型，给出清晰逻辑。
2. 模型页：定义加来源的引言框（约 2 行小字），再放结构图，最后放"常见误区 / 使用步骤"。
3. 案例页：结论句（20-35 字）+ 3-5 列等宽卡片拆解（VRIO 4 列、SMART 5 列、Hook 4 步，每列同构：标题 / 问句 / 内容 / 结论）。
4. 数据接住判断，整份形成一条分析链。
- 作者原话：面试官想看到的是，你能接住一个模糊问题，并把它变成可执行的答案。

### E. 商赛 / 框架拆解

依据：07-17、07-31(眼睛)、09-09、09-15、08-06。
- 结构：模型页（定义 + 结构图）+ 案例页（真实公司、结论句、数据、动作）成对出现。
- 这些页是"阅读型 / 海报式 / 商赛附录型"，正文约 6-10pt，作者的材料本身多处注明不适合现场投屏。
- 现场使用时的建议值：只取结构（结论句 + 3 栏 + 大数字），正文提到 ≥10-12pt。依据：10-12、09-09、08-21、10-08。
- 摘录里商赛叙事（路演顺序、评委视角）几乎没有文字说明，标签里的"商赛"只说明用途。该场景叙事需另行调研，不能由本章推出。

### F. 提案 / 推动变革

依据：08-21、08-20。
- 说服型叙事用 SCR 或 BAB 或 Burning Platform，必要时先讲问题和冲突，再给方案。
- 这与"结论先行"有张力，见第四节"分歧"。

## 四、分歧与不确定处

1. **结论放哪里：标题 / 副标题 / 底部，笔记里三种都有。**
   - 案例页系列：标题栏 + 黑圆点副标题。
   - 咨询风系列：行动标题 + 底部 "So what"。
   - 04-20 等酒红系列还有"底部总结句"。
   - 本章建议见 R8，但这是我的归纳，不是作者明说。
2. **结论先行与"先问题后希望"的张力。**
   - 对上汇报强调 page1 放结论（07-16、07-14）。
   - SCR / BAB / Burning Platform 把"问题—冲突"放前面，BAB 引语是"先让人看到问题，再让人看到希望，最后让人相信路径"（08-21）。
   - 07-31(meeting) 把"先讲结论还是先讲原因"作为要现场判断的问题。
   - 作者没有给出统一裁决。推断：汇报结果给上级 → 结论先行；争取资源或推动变革 → 可用 SCR/BAB，但摘要页仍放在前面。
3. **导航形式不统一：** 面包屑（3 段，约 10pt）与章节条（9 项，约 8-10pt）两种并存，没有哪篇说明应该选几项。
4. **字号区间不确定：** 作者的版式正文常低至 6-10pt，同时多篇自己提示"不适合现场投屏"。建议字号 ≥10-12pt 只有 10-12 这一篇明确提出（并标注"此为建议，非原图数据"）。
5. **强调色面积：** 5-10%（08-31、09-15）、10%（多数）、10-15%（多数）、≤20%（10-29）并存。本章取"≤10-15%"作稳妥区间。
6. **页数、时长、每页字数：** 笔记没有可靠数据。未发现"汇报应该几页""每页讲几分钟"的依据，本章不给数字。
7. **02-08、01-13、03-17 三篇可能是同一述职模板的重复展示。** 以三条独立证据计会夸大。
8. **07-14 的三技巧与图片案例的对应是摘录者的推断，笔记并未逐点说明。**
9. **10-14 备注：** "问题导向"原则与配图的版式重构是两条线，对应关系为推断。
10. **商赛叙事：** 如上，缺少文字依据。

## 五、可直接执行的检查清单（来自上文稳定规则）

1. 第一页是否直接给出结论？（R1）
2. 每页标题能否去掉所有名词性短语，只剩"主语 + 动作 + 数字结果"？（R7）
3. 把所有标题抄成一列，只读标题能否复述完整结论？（R5 推论）
4. 每页能否用一个听众问题概括？（R2、R3）
5. 每个数字是否有基准（去年 / 目标 / 行业）？（R10）
6. 每页是否只有一个视线落点？其余是否降为灰色小字？（R3、R15）
7. 长汇报是否有章节导航，当前章是否加粗？（R12）
8. 每页底部是否有 So what 收口条？（R14）
9. 末页是否写清"需要对方拍板 / 支持什么"？（R6）
10. 颜色含义是否跨页一致且已交代？（R16）
11. 走一圈回来看一眼，能否第一眼看到重点？（03-24）
