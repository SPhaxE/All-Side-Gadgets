# 视觉系统：配色、字体字号层级、版式网格、留白、nerdy 绿体系

> 依据：digest 中 61 篇笔记全部读完（日期均为 2026 年，下文用 MM-DD 标注）。
> 所有 hex、字号、间距都是作者逐页拆解里的目测估算，没有取色器读数，下文给的是综合区间，不是实测值。
> 复用说明：同一页幻灯片被反复贴进多篇笔记，例如 Amazon 斜率图、Jardine/Smith 箱线图、AIDMA vs AISAS、Zara 12x Faster、DMAIC、RCA 冰山、Moat/7S/SMART、3 Horizons。
> 因此"出现在 N 篇"只说明这套模板体系的一致性，不等于 N 个独立样本。下文把独立证据按"体系"计：绿色 nerdy 体系（06 月底至 11 月）、酒红咨询体系（01 至 06 月）、单篇特例。

## 0. 先分清两套体系和一个口径

1. 绿色 nerdy 体系：约 06-23 起，07 至 11 月笔记占绝大多数。特征是浅青灰拼图底、白卡、墨绿单强调色、"框架页 + CASE STUDY 案例页"成对出现、信息密度极高。这是本章主体。
2. 酒红咨询体系：01-13、02-24、03-28、04-01、04-20、04-27、05-15、06-04、06-15。特征是面包屑、粗体标题、2-3pt 黑通栏线、酒红 + 鼠尾草绿 + 灰。它的字号是真正可投屏的（正文 10-14pt），放在第 9 节单列。
3. 关于"高智感 / 呼吸感 / 淡人感 / 干净但不空"：
   - "高智感"：03-24 的定义是"清醒 + 克制"，即低调配色加不做花哨转场。04-01 和 04-14 没有文字，08-06 靠"统一墨绿 + 固定版式"实现。
   - "呼吸感"：07-21 和 05-15。
   - "干净但不空"：08-31。
   - "淡人感"：61 篇里没有任何一篇出现这个词或对它的定义。最接近的是 07-24"淡淡的精英感"和 03-24 的"克制"。下文不替它编造定义。
4. 信息密度与呼吸感并存，不要混淆。许多笔记自己承认"留白少、字小、不适合投屏"（10-19、07-16、09-09、10-08、07-21）。真正以呼吸感为主题的只有 07-21（BCG/Ansoff 页）和 05-15（酒红体系）。所以 skill 里应分两种页型：
   - 高密度速查页：按作者原参数，正文 7-10pt。
   - 汇报现场页：正文 ≥10-12pt，只取结构（结论句 + 3 栏 + 大数字）。这个建议来自 08-11、10-08、09-09、07-16、09-15 的自我提醒，是笔记的推断，不是原图数据。

## 1. 跨多篇稳定的规则（绿色体系，按重要性排序）

### 1.1 一个强调色相 + 灰阶，强调色面积 ≤10%（几乎所有绿色笔记）
- 依据：07-09、11-05、10-26、10-20、10-12、10-09、09-20、09-15、09-07、09-03、08-31、08-21、10-14。
- 全页只有"黑 + 白 + 灰 + 一个绿色色相（深浅可变）"。其他色相只在两种情况出现：红色做否定/警示，以及"必须区分两个对象"时的紫/橙对照（见 2.1）。
- 作者原话里"≤10%"只有部分笔记明说，多数是观察者估算。各篇估值是 5-10%（08-31、09-15）、10%（07-09、08-21、10-09）、10-15%（10-26、10-19、09-07、09-03、07-24）、≤20%（10-29、09-20）。
- 综合建议：实心深绿 + 中绿 ≤10%，加上浅绿底总计 ≤25%，灰与白 ≥75%。这个预算是综合推算，不是原文数字。
- 一页只让 1 个对象拿到最强强调（深绿 2px 描边 + 轻投影 + 白底，或实心深绿块）。依据：07-09、10-26、10-12、10-20、08-31、07-28、07-17、07-14。07-23 放宽到"最多 2-3 处"，10-04 类页（11-04）为 1-2 个。取 1 个为默认，2 个为上限。

### 1.2 灰 + 一色的图表规则
- 依据：07-09、10-29、09-01、09-04、08-31、10-09、09-09、08-20。
- 对比对象全部灰色（#D9D9D9 到 #9A9A9A），只把要讲的 1-2 个对象上深绿，如一根柱、一条线、一个气泡、一格。
- 直接标注取代图例，去网格线（或只留极淡网格）。数值写在点、柱顶或柱内。图例改成"着色文字"。
- 预测或估计值用更浅色、斜纹或虚线表示（10-29 的 2027 条形、10-08 的 2024E 竖纹柱）。
- 涨跌：▲ 用绿或深灰，▼ 用深红（#8B1A1A 到 #A02828）。依据 07-09、09-01、09-04、10-08。

### 1.3 红色只做"否定/警示"，面积极小
- 依据：07-09、11-05、10-12、10-14、10-26、09-09、08-21、08-06、07-23、07-16。
- 用途：定义框里框架名下的一条红下划线（最稳定的用法）、✗、危机竖线或虚线。
- 估色一致落在 #C0392B 到 #E03030，推荐 #D0312D。
- 红色下划线是整套里唯一固定出现的红色装饰。

### 1.4 灰度分层信息：黑 > 中灰 > 浅灰，字重辅助
- 依据：07-09 #15、10-26 #12、09-07 #13、10-19、07-24、08-13。
- 主信息（标题、结论句、中文名）：黑色粗体 #1A1A1A。
- 次级说明：#666 到 #888，推荐 #777。
- 三级补充（触点、例子、来源）：#999 到 #AAA。
- 层级主要靠"字重 + 灰度 + 位置"，而不是靠加更多字号或更多颜色。每页字号只用 4-5 档（09-04、04-20）。
- 作者的阅读路径是"眼睛先扫黑与绿，再读灰"（10-26）。

### 1.5 页头骨架固定，系列页位置完全不变
- 依据：几乎全部绿色笔记，最完整的是 07-09、10-12、10-19、09-09、07-24。
- 左上：英文框架名，粗体 22-28pt。案例页同一行追加" - CASE STUDY：中文案例名"，常规字重，约为标题的 60%。
- 右上：品牌标记（带字距的衬线小字，绿色）+ 三位页码（粗黑 24-28pt，与标题同级）。
- 标题下：
  - 概念页放"圆角描边定义框"：首行是"框架名（中文名）- 一句话定位"，粗体，框架名带红下划线；其后 2-3 行灰色小字。
  - 案例页放一行"● + 粗体结论句"，含"做法 → 数字结果"。
- 变体：10-19、10-29、10-09 的标题是"圆角描边胶囊条"；其余是无框纯文字标题。两种都稳定，二选一并在全套保持一致。

### 1.6 结论句 / 洞察条
- 依据：07-09、10-12、10-29、09-03、08-31、08-14，几乎全部。
- 结论句 11-14pt 粗体，黑色实心圆点开头，1-2 行，约 20-60 字。
- 底部可加一条灰底或浅绿底"Insight / 启示"横条。灰条色估值 #EEF0EE 到 #F2F2F2。

### 1.7 大字号对比靠"大 vs 小、粗 vs 细"
- 依据：10-14、10-09、09-20、09-15、08-20、07-14、07-17、08-06、07-21。
- 英文大标签（Core Idea、Why/How/What、Definition、Point/Reason/Example、Insight）用细体（Light）无衬线，绿色，22-30pt。
- 对应的中文说明用小号粗体黑或灰，叠在其下，形成"一大一小、一细一粗"。
- 英文放前，中文放后，语气像咨询文档，这就是 nerdy 感的主要来源。
- 大数字（KPI）为正文的 3-5 倍（09-20 为 4-5×、07-14 为 4-5×、07-07 为 4-6×、08-04 为 3-4×、07-21 为 4×以上）。
- 一张 KPI 卡只放 1 个大数字，下面一行 8-10pt 灰色口径。

### 1.8 容器语言统一：圆角卡 + 细边/浅底，投影极少
- 依据：07-09、10-19、10-12、10-09、07-23、08-12。
- 圆角矩形，线宽 ≤1pt，浅灰底或浅绿底，不用渐变。
- 投影只给"重点卡"或警示卡（07-09、08-04、10-09、07-17、07-31b）。10-19 明说"避免阴影与渐变"。
- 此处有分歧：07-07、07-23、08-14 把"轻阴影"写成卡片通用做法。取交集：默认无投影，只给 1 张重点卡加。
- 实线框表示事实/定义/主体，虚线框表示假设、待验证、结果区、补充。依据：07-16、07-31b、08-07b、08-12、10-09。

### 1.9 编号样式一页内统一
- 依据：10-26、07-09 #11、10-12、08-21。
- 三选一，不混用：
  - 绿色圆徽标 1/2/3。
  - 大号浅灰 #1/#2/01/02 + 黑色粗体小标题。
  - 黑色实心圆白字 1-8（用于宫格）。
- 背景水印数字（01-04）用 #E4E4E4 到 #D9D9D9，或透明度 5-10%（07-10、07-17）。

### 1.10 图标：细线、单色、从属
- 依据：09-09 #15、08-20 #11、11-04 #12、09-07 #12，酒红体系 04-27、06-04 也同样。
- 线性图标，统一线宽，灰或绿单色，常放在浅绿圆底里或作为指标前缀。
- 不用彩色图标、不用插画。唯一例外是品牌 Logo（07-31 的可口可乐红）。

## 3. 字体与字号层级

### 3.1 字体（全部不确定，只有族别稳定）
- 中文：无衬线黑体族（观感像思源黑体 / 微软雅黑 / 苹方），全部笔记一致。具体字体名无法确认。
- 英文标题与页码：粗体无衬线。各篇猜测有 Arial / Helvetica / Segoe UI / Inter / Montserrat，没有定论。
- 英文大标签：同一无衬线的细体（Light）。
- 衬线斜体粗体：用于首字母框架的巨型字母（DMAIC、AISAS、RFM、SCP、S/C/P）。依据 07-09、09-15、09-09、07-28、07-23、07-31b。这一条相对稳定。
- 品牌署名：带字距的衬线或等宽小字，绿色。
- 大数字有两派，不能统一说成"衬线"：
  - 衬线粗体或斜体：07-09、09-09、09-04、08-12、07-31b。
  - 细体无衬线：09-20、07-14、07-21、08-21。
  - 建议一套内只选一种。
- 落地字体映射（这是工程建议，不是证据）：
  - 中文 "Microsoft YaHei"，Mac 回退 "PingFang SC"。
  - 英文粗体 "Arial" 或 "Segoe UI Semibold"。
  - 细体 "Segoe UI Light"（无则回退 Calibri Light）。
  - 衬线斜体 "Georgia" Bold Italic。

### 3.2 字号（以 13.333in × 7.5in 幻灯片的 pt 计）
- 换算：各篇多以 1080px 宽拼图估算，1px 约 0.89pt，估值直接按 pt 看即可。
- 页码（三位）：24-28pt 粗黑。
- 英文框架名（页标题）：22-28pt 粗体黑，默认 24pt。依据 07-09、10-19、09-15、08-31、10-14。
- "- CASE STUDY：…"：14-18pt 常规字重。
- 英文大标签（细体，绿）：22-30pt。
- 结论句 / 定义首行：11-14pt 粗体，默认 12pt。
- 栏头 / 模块标题：10-14pt 粗体。
- 卡片标题：10-12pt 粗体。
- 正文要点：参考密度 7-10pt；汇报安全值 10-12pt。
- 图内标注、轴标签：6-9pt 灰色。
- 脚注、来源：6-8pt 浅灰。
- KPI 大数字：30-48pt，默认 36pt。
- 巨型首字母或装饰序号：60-80pt（07-09、10-08）；背景灰数字 50-70pt，色 #E4E4E4 到 #D9D9D9。
- Tesla 年份数字约 70px，是单页里最大的字（08-12）。

### 3.3 字号比例（比绝对值更稳）
- 标题 : 正文 ≈ 3 : 1（10-19、09-15、08-14、07-16）。
- 结论句 : 正文 ≈ 1.3-1.5×（09-03、10-12 的"核心 ≥ 分析维度 1.5 倍"）。
- 大数字 : 正文 ≈ 3-5×。
- 最大 : 最小 ≈ 5-6×（09-01）。

### 3.4 单篇特例或分歧
- 07-09 的实测像素反推：标题 26、结论句 11-12、正文 9-10、图内标注 8-9，可作"参考密度"档。
- 11-04 的 pt 换算：页码 24-28、页头 18-20、摘要句 9-10、正文 7-9、脚注 6-7。比 07-09 更小，且作者标注"若投屏需放大"。
- 09-09、08-06、07-16 直接指出正文 6-8pt 不适合投屏。
- 03-17 的酒红体系页标题 20pt + 结论 14-16pt，属于另一体系的数值，见第 9 节。

## 4. 版式网格、边距、间距

> 本节多数是比例估算，作者没有给出具体 px。推荐值是综合换算的，标明"推算"。

### 4.1 页面分区（比例有证据，坐标是推算）
- 页面外边距 3-5%（11-04、10-29 左右边距约 5%）。
- 注意：07-24 的"卡片外边距 30-40px"、09-04 的"8-12% 外圈留白"、08-12 的"灰青底边距约 40px"都是拼图画布到页面卡片的距离，不是幻灯片内边距，不要照搬到页内。
- 竖向分区：
  - 标题行。
  - 定义框约占页高 10-12%（09-04）。
  - 主图解占 50% 以上页高（07-09 理论页）。
  - 底部收束条 1-2 行。
- 概念页三段式：上定义框、中大图解、下要点或启示灰条（07-09 #10）。
- 案例页：标题 → 结论句 → 图 + 右栏卡 → 底部 Insight。

### 4.2 栏结构
- 3 栏等宽最常见：10-12、09-04、07-07、10-26。
- 3-5 列等宽卡每列同构（08-11：VRIO 4 列、SMART 5 列）。数量取 3/4/5/8（07-23）。
- 2 栏比例（左图右文）：

## 5. 留白与"高智感 / 呼吸感 / 干净但不空"的具体手法

只列笔记里有明确做法的：

1. 浅色大色块代替边框（07-21、10-12、04-27）。分区用 #EEF1EC 之类的浅灰绿或浅灰底，不画粗框；描边保持 ≤1pt。
2. 卡片分离而不是连成表格（11-05）。矩阵格子之间留 6-10px，用细描边 + 低饱和底，等级用边框色区分，不靠大面积底色。
3. 一大一小的节奏（11-04）。英文大标签用细体放大、中文说明缩小；文字块之间留出整行空白。
4. 一页一个视线落点（10-12）。全页最大字号、最深色、最大色块只属于一个元素，其余统一降为灰色小字。
5. 降权不删减（10-12 #10）。次要内容改灰色 + 小字 + 图标，保留但退到边缘，而不是删。
6. 去装饰（10-29、08-31、10-19）。无网格、无渐变、无粗框；表格去竖线，只留表头下和行间细灰线（07-21）。
7. 弱化区用深一档的灰，而不是加新色（08-31）。如"放弃 / 长尾"区域。
8. 稀疏分布也是信息（10-14 #10）。03 页卡片沿对角线分布，空位保留，让"关注点随时间迁移"可见。
9. 背景装饰极淡（07-09、08-12、11-05）。超大灰数字、半透明灰剪影、灰度低对比照片，只作氛围；照片要去饱和并盖白或浅绿蒙层。
10. "干净但不空"的本质（08-31）：浅底白卡、细线框、单一绿、灰度做背景层；留白 ≠ 信息少，靠分区与层级让密度可读。
11. 密度控制：卡内每条要点 ≤1 行，单格 2-3 条（10-14），列表不超过 3 条，每条 ≤14 字（07-07）。
