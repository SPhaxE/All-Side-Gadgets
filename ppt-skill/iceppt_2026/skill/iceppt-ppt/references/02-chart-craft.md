# 数据可视化与图表画法：把基础图形变得不基础

> 口径说明（先读）
> - 证据来自 61 篇笔记的逐篇分析。这个作者大量**复用同一页幻灯片**（如 083 斜率图、074 箱线图、072 气泡图、086 阶梯图、各编号的 BAB/SCR/RCA 页反复出现在多篇拼图里），所以"多篇出现"≠"多个独立样本"。下文"依据"栏列的是笔记日期，同一页被多篇复用时只算一条证据，并标"同页复用"。
> - 作者有两套相对独立的视觉体系：**2026-01 至 06 的咨询风（酒红+灰绿+灰，面包屑+2-3pt 黑线标题）**，与 **2026-07 至 11 的 nerdy 绿（深绿+灰，圆角卡+黑圆点结论句）**。图表层面的原则（灰+一色、直接标注、结论标题）两套完全一致；只有强调色和页头骨架不同。本章以"强调色"泛指，具体色见第五节。
> - 所有 hex、pt、px 均为作者图的**目测估算**，给的是区间，不是源文件数值。
> - 本章不涉及模板售卖/下载引导等内容。

## 一、跨多篇稳定的核心规则（优先级最高）

### S1. 一页一个视线落点，强调色做"减法"
- 全页只设 **1 个**主角：1 根柱 / 1 条线 / 1 个象限格 / 1 个气泡 / 1 个大数字；其余统一降为灰色。强调色面积 **≈5-15%**（作者自述 8:2 配色法，上限 ≤20%；多篇目测为 10-15%，气泡图、斜率图实测更低，≈5-10%）。
- 例：气泡图 15 个气泡只让 1 个（目标象限）变绿；斜率图只有 Amazon 1 条彩色粗线；折线图 5 条线只 1 条酒红；柱图 5 根只有最高/当前/最后一年 1 根上色。
- 允许"主角+1 个次强调"的情形见 S8（两个对立角色）；除此之外，同页第二种强调色只给警示，且面积极小（≤1 处）。
- 依据：10-29（8/2 原话）、10-12、10-23（"一页数字全灰，只有退货率 14% 用强调色"）、08-31、09-07、03-28、04-20；稳定、跨两套配色。

### S2. 灰=背景/基准/旧，强调色=重点/新/答案，且含义全套固定
- 同一含义同一颜色，并跨页延续（前一页蓝色代表海外业务，后一页继续用）。
- 对比页常用语义：**灰=旧/弃/问题，绿=新/选中/方案**（AIDMA 灰 vs AISAS 绿；传统主机灰线 vs Wii 绿线；红海灰/红 vs 蓝海绿）。
- 红色只表示否定/风险/下降/警示（✗、▼、基准阈值线），不与主色竞争；每页 ≤1 处，面积极小。
- 色相不要无意中编码层级：三个平级方案用越来越深的蓝，读者会误以为有高低。
- 依据：10-23（颜色是信息）、09-07、10-12、07-14、08-13、08-25；稳定。

### S3. 图表去装饰：直接标注代替图例、网格、坐标轴
- 数值直接写在柱顶/柱内/线端点；系列名用**着色文字**写在图旁或图顶（Male 紫 / Female 绿），省去图例框。
- 网格线：删除，或改极浅灰（见 S9 灰阶数）；只保留一侧刻度（y 轴或 x 轴其一）；轴刻度字号最小最淡（约 6-8pt 感）。
- 曲线图只标关键点（起点、拐点、终点，如 Start / 180M+ / 3B+ / 5B+），不标全部点。
- 数据标签**只标重点项**，或阶梯图"只标价格不标全部数值"。
- 依据：10-29、09-15、09-04、08-25、06-04、05-15、03-28、02-24；稳定，且是**两套配色共有**的唯一硬规则。

### S4. 标题写结论句；注释写成"含后果的完整句子"
- 标题栏下固定一行 **黑色实心圆点 ● + 粗体结论**，结构"对象 + 做法/发现 + 结果（含数字）"，一行到两行（约 25-70 字；多数案例 40-60 字）。例：「核心并非单一单价压价，而是锁定 250K 件最优承诺量」。
- 咨询风版本：标题本身就是结论（"market size will double in 2027"、「主题词：一句带数字的结论」，标签加粗约 20-24pt + 结论常规字重约 14-18pt）。
- 图表自己的标题仍可用"英文细体大字 + 中文小字副标（含单位/时间范围）"，如 Market Capitalization Shift / 千亿美元财富的转移 | (2010 vs. 2022)；但页面主结论必须有。
- 每页的"问题"导向：标题回答"这页帮听众判断什么"，不写"我做了 XX 分析"。
- 依据：10-29、10-14、10-12、10-08、09-04、08-21、07-14、03-17、02-24、02-08；约 25+ 篇出现，是全库最稳定规则。

### S5. 数字必须配基准，变化用"旧→新"写法
- 单数字不成立：补**去年 / 目标 / 均值 / 行业**之一。例：今年 115 万 / 去年 100 万 / 目标 120 万 ⇒ "同比增长但未达标"。
- 行业对标三列法："公司 / 行业 / 差距"（6.2% vs 11.2% → -510bps）。
- 前后值：旧值**灰**（可斜体、小一档）→ 新值**强调色粗体**（可大 1.5 倍）：58% → 76%、12% → 28%、2% → 18%。
- 倍数/差距做成标签：12x Faster、15 vs 90 天、7.0x。
- 阈值线/基线统一用虚线并带小字标签（咨询风用红色虚线：100% Baseline、Industry Benchmark、SLA 目标线用绿色虚线）。
- 依据：10-29、10-12、10-08、08-21、08-13、09-07、02-08；稳定。

### S6. 大数字 KPI：字号倍数拉开，单位退后
- 公式："标签（小灰字）→ 大数字 → 涨跌小标（▲/▼ + 百分比或 YoY）→ 灰色对比基线"，每卡**1 个**大数字（≤2 个）。
- 字号比：大数字 ≈ 说明文字的 **3-5 倍**（各篇给 2-3 倍、3-4 倍、4-5 倍、"约 40-60pt vs 10-12pt"；作者页内最常见的是 3-5 倍）。字重/字体不统一：细体、衬线斜体、粗体都出现，**同一套内保持一种**。
- 横排 3-4 张等宽卡（4 张最常见），交替浅灰/浅绿底或细竖线分隔；数字用强调色或深灰，旧值/弱化值可用灰。
- 涨跌：▲ 绿/主色，▼ 深红或深灰（深灰避免大面积红）。
- 依据：09-04、09-20、08-21、07-17、07-14、06-04、05-15、02-08、01-13；稳定（部分页面同页复用）。

### S7. 注释气泡：数量少、贴数据点、结构固定
- 每图 **2-3 个**（一页最多 3 个），白底或浅灰底圆角 + 细描边/轻阴影，细线或虚线引线指到数据点；文字 ≤3 行（或 ≤15 字 + 1 组数字）。
- 卡片结构："粗体名称 → 灰字小标题 → 2-3 行核心数据（关键数字用强调色）"（阶梯图三张卡：保守采购陷阱 / 最优承诺量 / 极限规模效应）。
- 虚线垂线标"事件时点/交付日/今日"，终点用菱形里程碑。
- 注释写原因+后果，不写名词。
- 图下或图旁再加 **1 句 So-what**（圆角灰条、虚线框、"Key insights" 2 条以内）。
- 依据：10-29、09-07、09-04、09-01、08-31、08-13、06-15、03-28、02-24；稳定。

### S8. "灰+一色"的例外：两个对立角色用两个色相，并用色带+同色文字绑定
- 仅当必须表达"两种角色"时引入第二色相：Male 紫 / Female 绿（哑铃图）、Jardine 橙带"High Variance" vs Smith 紫蓝带"Consistency Engine"（箱线图）、去年米 vs 今年绿、历史灰 vs 预测绿。
- 做法：图顶或图旁用同色文字标角色；背景用极淡竖向色带（透明度约 10-20%）；右侧解读小标题染同色。其余数据仍灰。
- 依据：10-29（哑铃）、09-07、09-04、09-01、07-10、06-04；稳定但"几乎全是同两三页的复用"。

### S9. 灰阶、字号、色带的量化底线
- 灰阶 ≤3 档（柱/表格），网格线用极浅灰；重要性靠"粗体黑 > 常规深灰 > 浅灰（约 #9A9A9A）"三档，不靠多色。
- 层级字号刻度（估算，页内相对关系更可靠）：页码/英文图名 ≈ 28-32pt 感 → 结论句 12-14pt 粗体 → 图内主标签/台阶价格 10-12pt → 卡片正文 8-10pt 灰 → 轴刻度/图例/脚注 6-8pt。
- **可读性冲突（明说）**：作者图的正文普遍 6-9pt 级，笔记自己多处评价为"阅读型/收藏型长图"，不适合现场投屏；本 skill 用于现场汇报时，**图内最小字建议 ≥10-12pt**，并减少注释条数（这是分析者的建议，非作者做法）。
- 依据：10-29、10-12、09-20、09-09、08-21、07-17、07-10、09-15。

## 二、Excel → 图形的转换原则（跨 10-29 / 10-12 / 10-14 / 09-04）

1. **数字→图形**：12 个月 GMV 表只能看数值，看不出走势和关系 → 折线图展示大小、趋势、构成（10-29 note）。表格仅在需要精确数值时保留（10-14）。
2. **有图→好读**：数据一多，普通簇状柱会"顺序杂乱、标签难找" → 两色柱，a:b≈8:2，标签只放重点柱旁（10-29）。
3. **数值→判断**：单列柱"销售额 115 万"无意义 → 加去年 100 万、目标 120 万（10-29）。
4. **按数据关系选图**（不要所有数据都用柱）：
   - 分档/累计 → 阶梯图；两端点差距 → 哑铃图；两时间点变化/排名反转 → 斜率图；多个同构对象趋势 → 小多图；叙事节奏 → 剧情曲线（10-29）。
5. **把表格还原成"形状本来的样子"**：2x2 画坐标矩阵、流程画带箭头卡片链（含回路）、层级画金字塔/房子、同心画圆、递进画 3x3 对角线地图；"高/中/低"文字表 → 点线价值曲线；时间×主题表 → 年份×阶段矩阵；8 维度表 → 带序号宫格；评分"5/5" → 5 个圆点（10-14、10-12、08-14、07-31）。
6. **同步删文字**：Done 页的典型毛病是"全灰表格 / 簇状柱无重点 / 8 线叠图 / 文字比图多 / 10 多条圆点"；改造时右侧叙事压成 **3 步卡片或 3 条对勾**（Step 1 核心命题 → Step 2 拆解逻辑 → Step 3 战略行动），每卡 1-3 句（10-29）。
7. **图表按主张重画**：想强调"差距与目标"就把折线改成柱（柱浅灰、去网格、数值标柱顶、只留一侧刻度）；占比用最简单的水平条（92% vs 8% 两根灰条，不用饼图）（11-04）。
8. **模块化与原生性**：图表用原生内嵌 Excel 可双击编辑；标题与坐标轴文字不得混在同一文本框；不用矩形拼假柱状图（02-08、10-19）。这是实现层原则，对"可修改"很重要。

## 三、各类图的"常规画法 vs 巧思画法"

每类给：何时用 / 常规 / 巧思怎么画 / 怎么标注 / 依据。凡标"同页复用"的，实际独立样本更少。

### 3.1 折线图
- **何时用**：趋势、拐点、新旧曲线交叉。
- **常规**：多条等权重线 + 网格 + 图例。
- **巧思**：
  - 同页折线**≤3 条**（深绿/浅绿/灰；07-14 的 OKR 页 ≤3 条+图例置底+图下 3 条解读）；多于 3 条就拆小多图（见 3.7）。
  - "一条线点亮，其余变灰"：主角深色实线 1.5-2px，对照项浅灰**虚线**（旧/基线）；终点用大圆点+数值（5B+）。
  - 去网格、y 轴只留极小刻度、x 轴留类别；折线下可用浅色面积填充。
  - 事件点：圆点 + 竖直虚线 + 气泡说明（一图只标 1 个关键节点）。
  - 趋势拐点加基准线；历史/预测用竖虚线分隔，预测段更浅或虚线。
- **标注**：线旁直接写名称，不要图例；终点数值；1-2 个气泡。
- **依据**：09-04（曲线只标 Start/180M+/3B+/5B+）、08-25、08-28（只标一个关键节点）、07-14、04-20（5 线仅 1 条酒红）、03-17；稳定。

### 3.2 柱状图（含时间序列柱、双轴组合）
- **何时用**：大小比较、构成、历史 vs 预测。
- **常规**：全灰两色簇状柱，网格+图例+纵轴齐全。
- **巧思**：
  - 8/2 两色：一根（最高/当前/目标）强调色，其余浅灰；柱顶标数值；柱宽约为柱间距的 0.6-0.7（05-15）。
  - 时间序列：历史灰、预测/新增换另一色（咨询风：灰柱 + 末 1-2 根换灰绿/深红；预测柱用斜纹/竖纹/空心，08-... 10-08 的 2024E 竖纹）。
  - 趋势箭头：不画折线，在柱间叠"黑色细箭头 + 椭圆增幅标签（+223%、+19%）"，每图 1-2 处（05-15、04-20）。
  - 加基准：同柱组并列去年 + 目标（见 S5）。
  - 双轴组合图（柱=规模、折线=比率）是最常用型，两轴不要同色（02-08；单篇主张）。
  - 少量柱（2 根）直接用水平条+数值，不画轴；占比用水平条，不用饼图（11-04、07-23）。
- **标注**：只给重点柱标数值/气泡；"读图结论"1-2 行放图下。
- **依据**：10-29、11-04、10-08、09-09、06-04、05-15、04-20、03-28；稳定。

### 3.3 阶梯图 / 成本曲线（Step Chart）
- **何时用**：分档报价、累计资金、规模效应、决定"锁定哪一档"。
- **常规**：两张并排表格（分档报价 + 方案测算），所有数字等权重。
- **巧思怎么画**：
  - 横轴承诺量、纵轴累计总额；每档一级台阶，**台阶顶部用绿色横线+绿色价格标签**，档位名与区间灰字写进台阶内。
  - 全部台阶浅灰/浅绿渐变，**只深色填 2 个关键台阶**（陷阱档、最优档）；台阶内可堆叠成本构成。
  - 三张浮层卡片：陷阱 / 最优（带对勾）/ 极限，虚线垂直引线连台阶；卡片内"粗体名称→灰字→三行数据"。
  - 标题结论句：先给决策（"锁定 250K 件最优承诺量"），再给理由。
  - 只标价格，不标所有数值。
- **依据**：10-29（单页，086）、09-15（"阶梯成本曲线"，同页复用）、08-13（只深填 Tier 5 与 Tier 10）。独立证据：1 页，**单篇特例倾向**；规则本身（只高亮 2 档+浮层卡）可用。

### 3.4 哑铃图（Dumbbell / Gap Chart）
- **何时用**：同一对象在两端点（男/女、目标/实际、前/后）的差距；年份多时纵向逐行。
- **常规**：男女两色簇状柱，右侧 10 多条圆点文字。
- **巧思怎么画**：
  - 纵轴年份/类别逐行，每行**两端点圆点 + 浅灰连线**（连线长度即差距）；每行右侧小字标 Δ 差值。
  - 两端点一紫一绿（S8），**图顶用同色文字标 Male/Female，取代图例**；两条竖参考线指均值，背后铺极淡同色带。
  - 排序：按差距或年份排，保证"剪刀差"可读。
  - 右侧只放 3 步卡片（Step 1/2/3），不再堆圆点。
- **标注**：Δ 数值、均值线；结论句用"剪刀差""停滞 vs 狂飙"这类判断词。
- **依据**：10-29（075 页）、09-15、07-10（同页复用）；独立样本 ≈1 页。

### 3.5 斜率图（Slope Chart）
- **何时用**：**只有两个时间点**时，看变化与排名反转（2010 vs 2022 市值）。
- **常规**：6 公司×2 年的簇状柱，眼睛来回对照。
- **巧思怎么画**：
  - 两条竖轴，每家公司一条连线，左右端点标"公司名 + 数值同一行"（Amazon $80B → $500B），**无图例**。
  - 主角 1 条**深绿粗线**，其余**灰色细线**；上升 ▲ 绿、下降 ▼ 深红；Costco 与 Target 交叉区可填极淡紫/淡色块标反转。
  - 右侧每条线后跟一个圆角灰框原因胶囊（≤约 20 字，与数据点同高）。
  - 左栏 3 条对勾叙事 + 一句设问（"谁被清算，谁完成了逆袭？"）+ 引号大字收束（"Retail Apocalypse"）。
  - 值太小或缺口用 "<$5B" 之类的标注处理。
- **依据**：10-29、09-01、09-04、10-08、07-16、08-31（**多篇出现但几乎都是同一页 083**，按单页计）。

### 3.6 小多图（Small Multiples）
- **何时用**：8 条以上同构序列、多区域/多渠道对比，一个洞察一张图。
- **常规**："意大利面"——8 条线灰度深浅+线型叠在一张图。
- **巧思怎么画**：
  - 同一小卡模板复制 N 次（如 2×4），**统一尺寸、统一刻度、统一结构**；按大区分组头（北美/欧洲/亚太/拉美，每组 2 个）。
  - 每卡：国名 → "年份 vs 年份" → 两根水平条（灰=旧，绿=新；下滑的新条改**深灰而非红**）→ 数字行（$70.8M / $65.0M / +8.9%）→ 迷你折线（仅标起点与终点）。
  - 异常项用卡片右上角小胶囊标签（"增长引擎"绿框 / "急需干预"红框）。
  - 页面左侧放总览大数字：5↑ 增长市场（62.5%）/ 3↓ 下降市场（37.5%）。
- **依据**：10-29（085 页）、08-13（热力图/箱线/哑铃/小多图一组，卡片复制 8 次）。独立样本 1-2 页；"统一刻度+胶囊标异常"为稳定意图。

### 3.7 热力表 / 同期群（Cohort）/ 敏感性矩阵
- **何时用**：留存随时间衰减、两变量敏感性（AOV×CAC）、RFM 八格价值。
- **常规**：数字表格全等权重。
- **巧思怎么画**：
  - **单色相明度渐变**（浅→深 5-7 级；深青绿 100% → 近白 10%），图例放右下角；同期群为**阶梯三角形**，未发生数据留空白。
  - 只圈一个读点：整列（Month 3）或基准格；基准格白底描边/蓝框，危险格浅红/米色，其余不动。
  - 配"横向读取（生命周期衰减）/纵向读取（策略干预前后）"读图指南，并带例子（Eg）。
  - 格内同时写百分比+短标签（Safe / Base / Risk / Danger），色盲友好。
- **标注**：把干预事件（如"6 月上线自助化模块"）与 M3 留存抬升（约 18% → 30%）并排写进结论句。
- **依据**：08-13（Cohort 080 页，单页）、03-17、01-13（同一套 SaaS 述职模板内同类页）、09-09（RFM 八格明度）；稳定意图，独立样本 2-3 页。

### 3.8 瀑布图（Waterfall）
- **何时用**：增长归因、预算、单位经济（UE：AOV → COGS → 毛利 → 履约 → CAC → 边际贡献）、背景-原因-行动叙事。
- **画法**：
  - 起止柱大、中间增减柱小；增量用主色/浅描边，**扣减项用灰柱或深色实心**（10-08 的"增加=浅绿描边，减少=深绿实心，汇总=灰白"；03-17 的"蓝=正，灰柱+黄描边=扣减"；01-13 下降项红框浅粉）。**分歧**：减少项到底用深色、灰色还是红色，三套风格不一致；统一原则是"整图内同一含义同一种样式，且不用大面积红"。
  - 顶部用折线括号标总增幅（+25%、+15%）。
  - 小计柱置灰，只有 1 根关键柱上主色。
  - 背景（Background）→ 带原因批注的图 → 行动（Actions #1/#2/#3）；行动卡数量与图中"负向柱"数量对应（3 个失血点对应 3 个行动）。
- **依据**：10-08、03-17、01-13、09-03、02-08；稳定（SaaS 述职页与 Marimekko/BAB 页是多个页面）。

### 3.9 帕累托 / 箱线图 / 蝴蝶图 / 气泡图（"图表模板"类）
- **帕累托**：柱子退为极浅灰，累积折线深绿，80% 点用异色圆点 + 气泡"杠杆点"，两个虚线框直接写结论（关键少数 20% → 80%）；读者不看轴就懂。依据：09-20、09-04、03-17、07-10。
- **箱线图**：只给 2 个对象加竖向色带（橙 = High Variance，紫蓝 = Consistency Engine）；语音气泡指向中位数 / IQR / 异常点；右栏"误读 vs 真相"。依据：09-01、09-04、08-13（同页 074 复用）。
- **蝴蝶图**：按数值**降序**排，两翼呈漏斗；中轴深色细竖线；类别标签居中（英文灰小字在上，中文黑粗字在下）；**左翼数据输入负数**；仅被强调的条上绿，其余浅灰。依据：08-20、06-15（咨询风蝴蝶图两组同结构，仅换底色）、02-08。
- **气泡图（BCG 式）**：**面积（不是半径）正比于数据**；无网格，虚线十字划四象限并给每象限命名；一颗气泡+一个象限框变绿，其余浅灰半透明；象限编号用大号浅灰数字置于角落，并与右侧卡片 1-4 一一对应；放弃/长尾区用更深一档灰底。依据：10-09（bubble 072）、08-31、08-20、02-08（同页复用）。
- **Marimekko / BAB 柱 / 瀑布小计**：非重点全部置灰，只有一块高亮并配 "80%" "75%" 大号绿色数字。依据：09-03。
- **百分比条/进度条**：深绿填充+浅灰轨+右侧百分比，不用饼图（07-31 OKR 页、11-04）。

### 3.10 漏斗图
- **何时用**：转化流程，关键是**找到流失最严重的一步**。
- **常规**：几层梯形依次缩小。
- **巧思**（作者原话）：**在流失最严重的一层拉开间距**制造视觉重点；或侧向展开——保留逐级收窄的轮廓，每个阶段向右展开，留出转化率、流失原因的展示空间（10-20、10-09）。
- **怎么画/标注**：
  - 留存与流失并排；每步用深绿小标签标转化率；底部深灰汇总条"整体转化率 8%，累计流失 92%"。
  - 红 ✗ / 绿 ✓ 标在步骤名旁，标识问题点与健康点。
  - 步骤型"漏斗"可简化为**逐行向内缩进**（AISAS 右栏）或阶梯条+颜色区分新旧（AIDMA 灰 vs AISAS 绿；10-14）。
  - Marketing Funnel 底部用 Insight 行收束（09-04）。
- **依据**：10-20（漏斗页实测，Done vs Well Done）、10-09（caption）、10-14、09-04；漏斗实例页可信。**漏斗侧向展开只在 10-09 caption 描述**，作者图中未见成品。

### 3.11 金字塔
- **何时用**：观点 + 依据（结论先行）；层级递进；价值递减。
- **常规**：三角形分层，信息从上到下排列。
- **巧思**：
  - 观点与依据 → "**顶部结论 + 下方理由**"；保留半边金字塔，把每层分界线向右延伸接标题和解释，让层级成为排版的一部分（10-20、10-09）。
  - 实测页：逐层加深色 + 向下箭头表示"支撑"；把"7±2 chunks"做成绿色大号细体数字作视觉锚点；概念注释（结论先行 / MECE 分组 / 逻辑递进）用细线引出，不在塔内堆字（09-20）。
  - 层级用灰阶（价值递减，RFM 八格、金字塔）或同色相明度（07-07）。
- **依据**：10-20、10-09、09-20、07-07。caption 与实测一致。

### 3.12 四象限 / 2×2 矩阵（含 BCG、Ansoff、Impact-Effort、风险矩阵）
- **何时用**：二维定位，需导出"战略动作"；风险矩阵（概率×影响）。
- **常规**：田字格，每格填文字。
- **巧思**：
  - **引入真实坐标系**，可插入第三维度（"重要度/严重度"），保留分界线，内容变项目标签、说明引出图外，还可加迁移箭头（10-20、10-09）。
  - 画法（单页稳定版）：浅绿圆角底 + 十字分隔线 + **轴标签用深绿胶囊**；轴上标 High / Low 文字；象限名用白胶囊；每格"图标 + 英文名 + 中文名 + 策略句 + 3 要点 + 例子标签"；核心象限加深绿描边 + 浅绿底，其余极淡底色。
  - 风险矩阵（波音 787）：格与格之间留白 6-10px，**"连块表格 → 分离的方块"**，格子细描边+低饱和底，用**边框颜色**区分等级，只有最危险的 1 格用红（11-05）。
  - 框架页底部用不等式一行压缩风险水平（市场渗透 < 市场开发 ≈ 产品开发 < 多元化；07-21）。
  - 图-文用编号一一对应（图中 1-4 ↔ 右侧卡 1-4），不画连线。
- **依据**：10-20、10-09、11-05、07-21、07-28、09-07、08-06、08-31；稳定，但**多数是 Done/Well Done 同页或同系列页**。

### 3.13 信息屋 / 循环图 / 韦恩图 / 鱼骨图（"拆分、展开、拉伸、重组"）
- **范围**：作者 10-09、10-20 的 caption 列出了处理方式，但分析显示 10-20 的 6 张图里**没有信息屋、四象限、时间轴成品**，10-09 也只读到 2 张且不含这些（"可能在被跳过的图中，不确定"）。以下规则来自 **caption，非实测图**：
  - 信息屋：屋顶 → 目标区，柱子 → 并列信息栏，地基 → 共享基础层，保留上下支撑关系。
  - 循环图：圆环拉成跑道形或横向流程，回流线接起点，保留循环方向。
  - 韦恩图：圆换椭圆/圆角矩形，保留相交关系，放大关键交集并引出说明。
  - 鱼骨图：展开成"问题 — 原因类别 — 具体原因"的水平原因树；叶子写成可分配任务（动词 + 对象 + 范围，08-28）。
  - 时间轴：关键节点旁加成果小图（草稿 → 初版 → 成品）；PREP 用 0s/30s/60s/90s 圆点时间轴（11-04）。
  - 总准则：**形态可以变，但支撑、层级、循环、交集关系必须讲清楚；涉及数据比例的必须保持准确。**
- **沙漏**：61 篇笔记摘录与 caption 中**未发现**"沙漏"图，不编造画法。
- **依据**：10-09、10-20（均为 caption 级）；08-28（树状图实测）。

### 3.14 流程图 / 时间轴 / 甘特图
- **流程图**：在要强调的方框加**深色色块**引导视线，其余方框降灰；箭头用浅灰/浅绿粗箭头，不用默认黑色细箭头（10-20、11-04）。chevron 串联表顺序，虚线箭头表反馈，空心大箭头表因果（07-31）。
- **甘特图**：只用细横分隔线，阶段/工作流分组行整行深灰底；关键路径条用主色，缓冲/浮动区灰；一条贯穿的竖虚线标"交付日/今日"，终点用菱形里程碑；批注气泡写成含后果的完整句（08-31）。
- **剧情/张力曲线**（三幕式）：一条绿色粗曲线 + 幕间黑色竖线 + 三个淡色背景（米/淡绿/淡紫）+ 节点上悬挂白色小标签（脱离稳态 / 中点反转 / 危机关头）（10-29）。
- **依据**：10-20、11-04、08-31、07-31、10-29、04-20（流程节点分层着色：根/终点酒红底白字，中间浅灰；单篇）。

## 四、视线落点、强调与注释的"怎么做"清单（可直接执行）

1. **选落点**：先问"观众看完这页应记住哪一个数/哪一根柱"；该元素用**全页最大字号、最深色、最大色块**之一；其余统一灰色小字。核心判断字号 ≥ 分析维度的 **1.5 倍**，补充说明用约 #9A9A9A、更小、regular（10-12）。
2. **强调手段（每页最多 2-3 处，作者各自排序）**：深色粗描边（常配浅底）/ 大号数字 / 虚线圈 + 星标或对勾 / 手绘红圈（咨询风，2pt，一页 ≤2-3 个，**同页只用一种圈示方式**，03-28）/ 整列色带（热力图圈整列）。
3. **虚线与实线含义固定**：虚线框 = 假设 / 待验证 / 重点区 / 辅助；实线框 = 主体 / 事实 / 定义。全套不混用（08-12、08-07、06-15、07-31）。
4. **编号与图文对应**：图中节点/象限 1-4（或 A/B/C 字母徽章）与右侧卡片编号一致，免连线（10-09、08-31、09-09、04-01）。
5. **被排除项**：整体变灰 + 淡化文字 + 红色小叉/斜线 + 红字原因（"已砍掉，资金不足"）；保留项 ✓ + 绿描边/虚线框（08-28、08-14、09-15）。
6. **状态符号**：✓/✗ 放在卡片右上角，用绿/红区分处置方向；评分用 **5 点圆点**（实心绿/空心灰），不用数字或百分比（08-14、07-31、08-06）。
7. **图-文比例**：图占 55-65%，右侧解读 35-45%（若图为主，也可 65/30；左文右图时左 30-40%）。所有"右侧"文字为 3 步卡片或 3 条对勾。
8. **标注的"So-what"收口**：图下一条圆角灰条（或浅米黄 / 浅绿条）写 1 句，如"关键洞察：CAGR>30%…"；底部总结带可带向下小三角收束三卡（09-15、10-08、11-05）。
