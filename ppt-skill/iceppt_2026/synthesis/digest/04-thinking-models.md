# [2026-07-09] ✍🏻power point重要的是point
## power point重要的是point：商业思维模型 PPT 合集（第2批，编号013-083）


## 本篇主旨
展示一套“每个思维模型 = 1页理论页 + 1页案例解析页”的信息密集型商业分析 PPT 模板体系（Moat、NPS、Kano、DMAIC、SIPOC、3 Horizons、3C、SCP、Slope Chart、Pareto、RCA、TOWS、Persona、CJM 等）。caption 总结方法论：“言之有物，数据详尽，最后再加一点审美”，即先有内容与数据，再用统一的绿色系视觉去美化。

## 出现的思维模型/框架/方法论
- **Moat Analysis（护城河分析）**：5 大来源（转换成本、成本优势、网络效应、无形资产、规模效应）× 强度打分；案例 Liquid Death（极端品牌文化 + 社区）。
- **Competitive Positioning Map（竞争定位图）**：选 2 个维度做 2×2，找空白象限；4 条 Key Insights（维度决定结论 / 拥挤是信号 / 空白不等于机会 / 定位会漂移）。
- **NPS**：0-6 贬损者 / 7-8 被动者 / 9-10 推荐者；NPS=推荐者%−贬损者%；基准 >0 / >30 / >70；案例 Costco（NPS 79，会员续费 ~90%）。
- **Kano Model（卡诺模型）**：基本型 / 期望型 / 兴奋型 / 无差异 / 反向，对应战略动作 Threshold / Compete / Differentiate / Avoid / Remove。
- **Six Sigma DMAIC**：Define-Measure-Analyze-Improve-Control；案例 Sweetgreen 排队问题（帕累托 + 箱线图），吞吐量 +30%。
- **SIPOC**：Supplier-Input-Process-Output-Customer，建议用 COPIS 反向构建；示例咖啡店。
- **Ansoff Growth Matrix**：市场渗透/市场开发/产品开发/多元化；案例蜜雪冰城走“市场开发”。
- **3 Horizons（麦肯锡三层增长）**：H1 核心、H2 新兴、H3 未来期权（1-3年/2-5年/5年+）；误区“99% 资源放 H1”；案例工业设备商 AI 预测维护。
- **3C's Model（大前研一战略三角）**：Customer / Corporation / Competitor，交集=战略甜蜜点；案例西南航空（15 分钟 vs 60 分钟过站）。
- **SCP Paradigm（结构-行为-绩效）**：结构决定行为、行为决定绩效，另有反向作用。
- **Choropleth Map（分级设色地图）**：案例跨国零售商网络错配诊断。
- **Slope Chart（坡度图）**：两个时点对比；案例 4G 覆盖率、北美零售市值（Amazon / Costco 逆袭）。
- **Pareto Principle 80/20**：关键少数；案例 F2P 游戏 99/1 “鲸鱼经济学”。
- **RCA（根本原因分析）**：冰山模型（表面症状/直接原因/根本原因）+ 5 Whys + 数据帕累托；案例硬件垫圈退货（采购省 2 美分）。
- **TOWS Matrix**：S/O、W/O、S/T、W/T 四类战略；案例 Crumbl Cookies。
- **User Persona（用户画像）**：Demographics + Psychographics + 画像到产品映射；案例 Peloton 的 Sarah。
- **CJM（用户旅程地图）**：5 阶段 × 行为/触点/情绪曲线/对策；案例 IKEA（峰终定律、宜家效应、强制动线）。
- 其他出现的名词：COPIS、Peak-End Rule（峰终定律）、IKEA Effect。

# [2026-11-04] 🫆 手搓ppt独有的感觉
## 手搓ppt独有的感觉：用五个汇报框架做 Done / Well Done 对比


## 本篇主旨
PPT 的"人感"来自取舍：每页都在表达"我怎么看这些内容、希望你怎么理解"。用 STAR、Burning Platform、BAB、PREP、Why-How-What 五个框架，各做一组"Done（四栏平铺的文字模板）"与"Well Done（按内容重新设计的版面）"对比，说明三件事：结构里有主张、画面里有节奏、细节里有照顾。

## 出现的思维模型/框架/方法论
- **STAR（背景-任务-行动-结果）**：用于复盘一次事件，把事件拆成 S/T/A/R 四栏；案例是某大厂产品经理复盘一次失败的推荐功能迭代（GMV 下滑 12%，9 天修复，目标 14 天），附"可复用方法论"（数据分层分析、小流量 A/B、灰度发布）。
- **Burning Platform 燃烧的平台（Daryl Conner）**：用于变革沟通，让客户意识到"不改变的代价＞改变的成本"；三个关键要素（紧迫性、相关性、真实性）、三个常见误区（泛泛而谈、只讲危机不给出希望、夸大其词）、四步构建（揭示现状真实代价 / 外部趋势加速压力 / 未来状态对比冲击 / 出发行动的临界点）。
- **BAB 框架（图中标注为 BAB Framework）**：用于说服类汇报，现状（服务拖累增长）→ 目标状态（2028 服务业成为第二增长曲线）→ 转型路径（智能化 IoT 设备监控、服务产品化维保套餐订阅、数据变现预测性维护）；案例是工业设备制造商的售后服务转型，服务收入占比 8%→25%，服务收入 1.2→5.4 亿元。具体 Before / After / Bridge 的对应关系为按版面推断。
- **PREP（观点-原因-案例-重申观点）**：用于 90 秒电梯汇报，按 0s / 30s / 60s / 90s 分配每一步；案例是电商退货率从 15% 升到 28%，原因是尺码标准缺失（43.6%）与商品描述失真（31.2%），建议建立商品质量分级体系，目标 Q3 退货率降至 18%。
- **Why-How-What 黄金圈叙事（Golden Circle）**：用于品牌、领导力沟通、产品营销、投资路演、个人品牌；先说信念再说方法再说产品；案例对比"普通公司"（What→How→Why，结果：价格竞争）与"伟大公司"（Why→How→What，结果：品牌忠诚），以 Apple 与 Dell 的差别说明（Think Different）。
- **Done vs Well Done 对比法**：同一内容做"朴素版"与"设计版"的前后对比，用作教学和展示。

## 正文金句与方法
（来自 note.md）
- "PPT 的"人感"，来自取舍。也是一种变相的表达："我怎么看待这些内容，以及我希望你怎样理解它。""

- ❷ **画面里有节奏——呼吸感**：紧凑配合舒展，留白是信息的缓冲带。
- ❸ **细节里有照顾——强调**：间距、对齐、备注和说明，都在让阅读更顺畅。

# [2026-10-29] 📠 图表可视化的意义be like
## 本篇主旨
图表的意义是"让数据里的关系变得可见，减少观众查找、比较和推算的负担"。五张图用"Done（表格/灰色默认图）→ Well Done（结论先行、重点上色、标注直达答案）"的前后对比，示范如何按数据关系选对图形（阶梯图、哑铃图、斜率图、小多图、剧情曲线）。note.md 里另给了三条小技巧：数字→图形、有图→好读（8/2 双色）、数值→判断（加对比基准）。

## 出现的思维模型/框架/方法论
- **三幕式结构（3-Act Structure）**：Act 1 建立世界（现状与背景、钩子、激励事件）→ Act 2 制造冲突（矛盾、阻碍、中点转折、危机升级）→ Act 3 解决危机（高潮、答案与出路、结束）。用法：大型演讲/发布会/融资 Pitch/商业提案，甚至一封邮件，把"传递信息"升级为"制造体验"。顺序口诀：现状与背景 → 矛盾与转折 → 答案与行动。使用注意：开场只给必要背景；第二幕要有明确冲突；第三幕答案要回应开场的问题；最后留下清晰结论与行动方向。
- **结论先行 + 一句话洞察**（Well Done 页的统一结构）：标题栏下一行加粗结论句。
- **Step 1 核心命题 → Step 2 拆解逻辑 → Step 3 战略行动**：用于把数据洞察变成行动，案例为哑铃图页（表面现象 → 停滞的左端点/强升的右端点 → 破除单一营销惯性、重构服务基础设施、长期风险对冲）。
- **8/2 双色法**：普通数据用 a 色，重点用 b 色（a/b=8/2）。
- **加比较基准**：当前值 + 去年值 + 目标值 → 判断（案例：销售额 115 万 vs 去年 100 万 vs 目标 120 万）。
- **图表选型表（本篇隐含）**：阶梯图/成本曲线（阶梯报价与累计资金）、哑铃图/Gap Chart（两极端点与剪刀差）、斜率图（两时间点排名与变化）、小多图（多区域同构对比）、剧情张力曲线（叙事节奏）。
- **叙事三段对勾栏**（斜率图页左栏）：用 3 个对勾点概括"崛起—催化—陨落"，最后抛出提问并用引号大字收束（"Retail Apocalypse"）。
- 案例素材：OEM 阶梯报价（最优承诺量 250K 件、$16.00/件、累计 $5.43M）、社区大学男女入学人数 1990–2015、北美零售 2010 vs 2022 市值（Amazon $80B→$500B）、A公司 8 国营收矩阵（5 增 3 降）。

## 正文金句与方法（来自 note.md）
- 开篇定义："让数据里的关系变得可见，减少观众查找、比较和推算的负担。"
- ❶ 从数字到图形：✗ Excel 能看到 12 个月的 GMV 具体数字，但没办法判断走势和关系；✓ 折线图展示数字的大小、趋势、构成。

# [2026-10-23] 🎧◞˚♩颜色也是信息
## 本篇主旨
《颜色也是信息》：颜色会给内容附加一层“没写出来的说明”，观众看到颜色差异，往往会把它理解为信息差异。因此 PPT 配色应当是有意识的表达，而不是装饰。

## 正文金句与方法
- 「颜色会给内容加上一层‘没写出来的说明’。观众看到颜色区别，往往也会理解成信息上的区别。」
- 颜色在 PPT 里至少表达三件事：
  1. 【这里，值得先看】：整页数字用灰色，只给“退货率 14%”用强调色，等于提前告诉观众先看哪里。颜色体现你对重要性的判断；全部鲜艳则判断模糊。
  2. 【这些内容属于同一件事】：图表中的蓝色曲线与旁边解释的蓝色关键词呼应；颜色对应可跨页延续（如前页蓝色=海外业务，后页继续用），观众无需重建对应关系。
  3. 【这里存在差别或发生了变化】：不同色区分类别；由浅到深表示数值增加；预设颜色表示完成/进行中/待处理。

# [2026-01-13] 在犯困的述职中让人眼前一亮
## 本篇主旨
展示一套"年度述职/年终汇报"数据可视化PPT模板（宣称50个完整故事）：每页顶部导航定位、每页独立故事、低饱和墨绿+酒红+灰的配色，用"结论式标题+多图表+要点卡"把复杂业务数据讲清楚。

## 出现的思维模型/框架
- BCG 增长份额矩阵：电商=金牛、SaaS=明星、AI=问号、传统广告=瘦狗；同一框架在渠道效率矩阵中复用于渠道（Google Search/LinkedIn/Display/TikTok）。
- 红绿灯复盘 Key Wins / Key Loss + Solution：赢的3项、亏的2项，每个亏项配对策。
- 增长归因瀑布：6.8亿到8.5亿，按季度或驱动因素拆解，再深挖ToB（Depth）/ToC（Breadth）。
- UE（单位经济）模型：AOV-COGS-履约-CAC=边际贡献，配AOV x CAC敏感性矩阵。
- 同期群分析 + RFM策略（复购）。
- AARRR 海盗模型（A/B测试5个实验：获客/激活/留存/变现/推荐）。
- 增长公式：Revenue = Traffic x Conversion x ARPU；病毒系数 K = i x c（K>1为指数增长）。
- 流量"黄金交叉点"：免费流量超过付费流量的拐点。
- Blended CAC = 总营销花费 / 总新客数；回本周期对比。
