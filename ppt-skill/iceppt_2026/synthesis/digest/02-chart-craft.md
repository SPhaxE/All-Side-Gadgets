# [2026-07-09] ✍🏻power point重要的是point
## 本篇主旨
展示一套“每个思维模型 = 1页理论页 + 1页案例解析页”的信息密集型商业分析 PPT 模板体系（Moat、NPS、Kano、DMAIC、SIPOC、3 Horizons、3C、SCP、Slope Chart、Pareto、RCA、TOWS、Persona、CJM 等）。caption 总结方法论：“言之有物，数据详尽，最后再加一点审美”，即先有内容与数据，再用统一的绿色系视觉去美化。

## 提炼出的设计规则
1. **每个思维模型固定两页**：页1“理论页”（定义 + 图解 + 使用要点/局限），页2“案例页”（真实公司 + 结论句 + 数据/图表 + 启示）。
2. **统一页头结构**：左上 大号粗黑标题（框架英文名），右上 “@ICEPPT + 3位编号”（编号用粗黑加宽字体，ICEPPT 用绿色加大字距）；案例页标题改为“框架名 - CASE STUDY：公司 + 结论短语”，且编号可省略 @ICEPPT。
3. **定义框模板**：圆角描边框；第一行 = 框架英文名（中文名）+ 破折号 + 一句话定位（粗体）；框架名下加 1 条红色下划线（唯一的红色强调）；第二段为 2-3 行 8pt 级灰黑小字背景说明。
4. **案例页必有“结论句”**：标题下一行，以黑色实心圆点 ● 开头，整句加粗，写成“做法 → 结果（含数字）”，如“……将吞吐量提升了 30%”。
5. **强调色面积≤10%**：整套仅用一个绿色色系（深绿描边/文字 + 浅绿底），灰色铺大面积；重点元素 = 深绿描边 + 轻投影 + 白底，其余元素 = 无描边灰底。每页只让1个格/1条线/1张卡获得强调（如 S/O 格、Process 列、Analyze 行、Amazon 线、Why 5）。
6. **“灰 + 一色”图表规则**：坡度图/折线/柱图中，对比对象全部灰色，只把要讲的那一个/两个对象用深绿粗线+绿标签；上升加 ▲、下降加 ▼ 并用深灰。
7. **图表标题写洞察，不写名词**：如 “90% of people in the world live in range of a 4G network”、“Market Capitalization Shift”，而非“折线图”。
8. **图表直接标注取代图例和网格**：数值直接写在点/柱旁，去除多余坐标轴、网格线；关键点用虚线圆角气泡 + 一句解释。
9. **大数字 KPI 卡**：数字用 3-5 倍于说明文字的字号，绿色斜体衬线或粗体，下方灰色小标签说明；前后对比用 “灰色旧值 → 绿色新值”（如 12% → 28%）。
10. **“理论页”三段式布局**：上=定义框，中=大图解（占 50%+ 高度），下=要点/启示灰条；三列或五列卡片等宽，列间距统一。
11. **大序号 + 小标题 模块化**：01/02/03 或 #1-#4 使用大号浅灰（装饰）序号 + 绿色或黑色粗体标题 + 灰色说明；同一页内序号样式统一。
12. **巨大首字母装饰**：DMAIC / SCP 用特大斜体衬线粗体深绿字母作为列头（占列宽 1/3），配小号阶段说明，形成强视觉锚点。
13. **背景装饰弱化**：背景使用半透明灰色剪影/照片/超大淡灰数字（01-05、Retail Apocalypse、RCA Iceberg 文字），透明度极低，不干扰正文；正文放在白色或浅色块上。
14. **底部“战略启示 / Insight”灰条**：每页收尾一条灰底（≈#EEF0EE）横条，写 1-2 行总结（如 “人类的天性是遇到问题就立刻跳到解决方案……”）。
15. **信息分层用灰度**：主信息 黑色粗体；次级说明 中灰；三级补充（触点、例子）浅灰；链接信息的箭头/连线用中灰或绿色。
16. **框架图直接就是页面骨架**：3C 用三角排布、Ansoff/竞争定位图用 2×2、CJM 用矩阵、Kano 用坐标曲线——先画框架结构，再往结构里填字。
17. **用“前→后/左→右”表达因果**：箭头（⇨、▶、大三角）固定表示“痛点→策略”“来源→解释”；虚线箭头表示反馈/反向作用。
18. **内容密度高、字号小**：正文 8-10pt（相对 1080px 宽图约 9-11px 字高），靠留白+边框+灰度分层避免拥挤；文字都放在圆角框里，间距统一（约 8-12px）。
19. **圆角矩形、投影轻**：所有卡片圆角约 6-10px，重点卡才有投影（模糊半径小、透明度低）。

# [2026-10-29] 📠 图表可视化的意义be like
## 本篇主旨
图表的意义是"让数据里的关系变得可见，减少观众查找、比较和推算的负担"。五张图用"Done（表格/灰色默认图）→ Well Done（结论先行、重点上色、标注直达答案）"的前后对比，示范如何按数据关系选对图形（阶梯图、哑铃图、斜率图、小多图、剧情曲线）。note.md 里另给了三条小技巧：数字→图形、有图→好读（8/2 双色）、数值→判断（加对比基准）。

## 提炼出的设计规则
1. **先选图再排版**：按数据关系选图形——分档/累计关系用阶梯图；两端点对比与差距用哑铃图；两个时间点的变化与排名反转用斜率图；多个同构对象的趋势用小多图；叙事节奏用剧情曲线。不要所有数据都用柱状图。
2. **标题写结论句**：每页标题栏下加一行"黑圆点+加粗结论句"（约 40–70 字，含主语、动作、判断，如"核心并非单一单价压价，而是锁定 250K 件最优承诺量"），不写"XX 数据汇总"。
3. **8/2 配色法**：普通数据用颜色 a（灰/淡色），重点用颜色 b（强调色），a:b 面积约 8:2；强调色面积控制在 ≤20%，一页只保留 1 个主强调色（本组为深绿），涨/跌分别用绿▲/红▼点缀。
4. **标签直达重点**：数据标签只标重点项，直接放在重点数据旁，不要让观众对照图例+坐标轴；图例改为着色文字或直接标注（如 Male/Female 用紫/绿直接着色）。
5. **加基准做判断**：单个数字必须配比较对象（去年、目标、均值、同类），如"今年 115 万 / 去年 100 万 / 目标 120 万 → 同比增长但未达标"。
6. **一个洞察一张图**：不要把 8 条线叠在同一图（意大利面图），拆成小多图，每个小图结构一致、同坐标逻辑，再用标签（"增长引擎""急需干预"）标出异常项。
7. **图旁叙事结构化**：右侧或左侧用 3 步卡片（Step 1 核心命题 → Step 2 拆解逻辑 → Step 3 战略行动）或 3 条对勾叙事栏承载文字，每张卡片只放 1–3 句，不再堆 10 多条圆点。
8. **浮层卡片做注释**：关键台阶/节点用白底圆角+细阴影的卡片标注，固定结构"粗体名称 → 灰字小标题 → 2–3 行核心数据"，用虚线引线连到图上位置。
9. **用淡底色带划分区域**：以极淡的色带（透明度约 10–20%）分隔阶段/群体（男/女区、Act One/Two/Three），并用同色胶囊标签呼应。
10. **去掉装饰性强调**：无渐变光效、无粗框；表格和柱状图的灰色全部降到 ≤ 3 个灰阶，网格线用极浅灰。
11. **整套页面保持统一模板**：顶部标题栏（圆角描边，英文图表名+中文案例名+页码）、结论句、图区、右侧/下方卡片，同一套间距（左右约 5% 边距）与同一主色。
12. **Done 页的反面教材清单**：全灰表格、簇状柱无重点、8 线叠图、文字比图多——凡有这些就应改造。

9. 对比用符号+颜色：红×/灰点 vs 绿✓/绿点，比表格更快读出对错。
10. 流程用卡片+箭头：4 步使用方法做成 2×2 圆角卡，卡间 ">>" 浅灰箭头，编号用 01/02/03/04 绿色。

## 本篇主旨
展示一套"思维模型/框架名 + CASE STUDY 案例"的整页信息图式 PPT 模板（STAR、Kano、Why-How-What、SCQA、MECE Tree、Brand Identity Prism、Ghost Deck 共7页）。卖点不是内容而是工程质量：全部元素原生可选中、整齐无乱码、图表数据双击即用 PPT 内置 Excel 编辑（"手搓"而非贴图）。

> 版面说明：本篇7张图全部是"上下拼图"，但**上半 = 干净成品页，下半 = 同一页在 PPT 编辑态下全选后的样子**（满屏选择框/控制点，部分页面弹出内置 Excel 数据表），并不是 Done/Well Done 式的内容前后对比。下半的作用是"证明每个元素都是可编辑的原生对象"。

## 提炼出的设计规则
1. **统一页面骨架**：每页固定"圆角胶囊标题栏（框架名 + CASE STUDY 案例名 + 右侧大号编号）+ 黑点结论摘要句 + 主体模块"。系列页只换内容不换骨架，翻页零学习成本。
2. **标题 = 框架名 + 案例名，摘要 = 结论句**：摘要句必须同时包含"用了什么方法 + 得出什么结果/数字"（如"牺牲短期GMV以换取核心模型重构的战略级止损"），而不是话题名。迷你页标题同理写成结论（"高价值会员贡献过半"而非"用户分层"）。
3. **单一强调色**：全页仅用一种主绿（深绿 #0B7A5E 左右）+ 灰阶。强调色面积控制在约 10-15%，且只落在"最关键的一个模块"上（如 STAR 的"行动"列深绿粗框、Prism 的 Culture 格深绿胶囊、Kano 的 Switch 曲线）。
4. **警示色只用来表达语义且每页≤1处**：红色=负面/危机（"急转直下"竖线、收入仅+3%、"投入核心创意资源"批注）；橙色仅出现在 MECE 的"根因诊断"标题。其余一律不用。
5. **"主角深色 / 对照浅灰"做图表**：突出系列用深绿实线/深灰条，对照系列用浅灰虚线或浅灰条（Kano 曲线、SCQA 条形图）；直接在线/条旁标注系列名，省略图例。
6. **图表必须原生，数据可双击编辑**：折线、条形、瀑布、直方、帕累托、环形全部用 PPT 内置图表（数据在内置 Excel），不贴图；文字、色块、箭头、图标、表格全部为独立对象，不合并成图片、不出乱码。
7. **每个图表配一句结论**：图下方用圆角灰框/描边框写1句"So what"（"完全避开红海参数战，开辟蓝海价值曲线。""帕累托图分析：价格+可及性=70%流失原因"），或在图内用黑色圆角批注框标出关键数字（"53家门店亏损占比42%"）。
8. **数字分级**：KPI 用"大号黑色数字 + 小灰标签 + 绿色↑涨幅 + 灰色行业对比"四件套；前后对比用"旧值→新值"箭头写法（2%→18%）；关键转折数用大号字单独拎出（"2022 Q2 急转直下"）。
9. **叙事结构用形状编码**：顺序=chevron/箭头串联（STAR、转型路线图）；并列=等宽卡片网格（KPI 3×3、Insight 3卡、Ghost Deck 2×3）；层级=树状图；对立=强弱对比表；排除=✗药丸；验证=✓+绿点虚线框。
10. **模块分组靠底色而非边框堆叠**：灰条表头 / 浅灰绿底面板 / 细描边圆角框三种容器，圆角统一、线宽≤1pt；避免阴影与渐变。
11. **图片只当氛围背景**：照片需去饱和并盖白色/浅绿蒙层（Patagonia 森林），保证文字对比度。
12. **信息密度高但层级清楚**：正文可低至约 7-9pt，靠"粗体小标题 + 灰色正文 + 关键数字加粗"三档拉层级；留白少，但靠栏间距、淡分隔线和统一对齐保证"整齐"。
13. **用"灰色问号/大引号/大箭头"做大号装饰字符**，以浅灰色放大，充当视觉锚点而不抢内容（SCQA 的"?"、Kano 的引号、Patagonia 的下行箭头）。
14. **加入"思考/诊断/验证"侧栏**：每个框架页附一个小模块（Thinking、棱镜诊断、MECE验证、可复用方法论、Ghost Deck 筛选），把"如何用这个模型"也呈现出来，使页面既是案例又是教程。

这是一组"经典分析框架 + 咨询风案例页"的模板合集。每个框架先给一页"概念页"（定义 + 四象限结构），再给一页"案例页"（用真实感数据把框架跑一遍）。笔记 note.md 只有标题"一点灵感slides"和 10 个标签，没有文字 tips，全部方法需从图中提炼。

## 提炼出的设计规则
1. 页面框架固定：每页 = 顶部标题栏（框架名粗体 + "- CASE STUDY：案例标题" 常规字重）+ 右上页码/署名 + 一行带黑色实心圆点的"结论句"（约 25-40 字，粗体 13px 级），再进入主体。结论句同时点出"方法 + 数字 + 结果"。
2. 标题用"框架名 + 案例"双层：框架名粗体，案例标题字重变细，用 "- CASE STUDY：" 分隔，让读者一眼看出"这页是哪个方法的哪个例子"。
3. 概念页和案例页成对出现：概念页讲"是什么、每个象限问什么"（带定义框 + 引导问句）；案例页用同一象限结构填入真实数据——同一框架的两页版式应延续（SWOT 的 S/O/W/T 大字母在两页都出现）。
4. 配色克制：灰色做数据底色、绿色（单一色相）做强调。强调色面积控制在整页约 10-15% 以内，只用于关键数字、关键柱/线、字母装饰、标签条。
5. 同色相的明度梯度表达语义：增加 = 浅绿描边，减少 = 深绿实心，汇总 = 灰白；不必用红绿对立，色盲友好。仅在"下跌"这类需要警示的小标记（▼）上用深红，且面积极小。
6. 图表只保留必要元素：无网格线或仅极淡刻度、数值直接标在柱顶/点旁、省略图例（必要时才用三色块图例）、预测值用"竖纹/斜纹填充"与实际值区分（如 2024E 柱）。
7. 图表旁必须有"一句话洞察"：柱图下方用浅米黄色圆角条写 "关键洞察：CAGR>30%…"；斜率图/瀑布图用批注气泡写原因，而不是让读者自己解读。
8. 瀑布图叙事结构：背景（Background）→ 图表（带原因批注）→ 行动（Actions #1/#2/#3），三段用绿色小标签分隔，行动卡数量与图中"负向柱"对应（3 个行动对应 3 个主要失血点）。
9. 斜率图只有两个时间点，重点公司用彩色粗线 + ▲/▼ 标记，其余用灰色细线；用淡色半透明区块填充重点区间；每条线旁标 "公司名 $数值"，右侧放一句原因胶囊。
10. BAB 三栏叙事：左 Before（现状指标，阶梯式胶囊 + 灰色条形图）→ 中 After（目标对比表 + 预测柱图）→ 右 Bridge（转型动作卡）。栏间用大号浅灰 chevron 表示流向，Bridge 栏用浅绿整块底板突出"怎么做"。
11. 动作卡内：图标 + 粗体动作名 + 灰色说明 + 一个绿色大号结果数字（▼35%、▲18pct、▲2.3x），结果数字字号约为正文 2 倍。
12. 引导问题标签：每个维度配一句反问句（"[我们的产品是否符合未来的人心所向？]"），用带阴影的圆角小标签压在内容条顶边，降低理解成本。
13. 英文小标题 + 中文并置（如 "Strengths 核心优势"），中英双语标签提升"nerdy / 咨询风"质感，英文可用等宽或衬线感字体做点缀（@ICEPPT 水印即此类）。
14. 圆角矩形 + 细灰描边 + 轻投影（卡片）是统一容器语言；整页外层大圆角白卡片，外部背景为淡青灰色（#BFD7D8 左右），多页拼接时留约 20-30px 间距。
15. 字号层级刻度大致为：大字母装饰 80px+ → 标题 24-26px → 结论句/栏标题 13-14px → 正文 10-12px → 注释/脚注 8-9px。注意：本组页面的正文偏小（8-10px），在手机上阅读吃力，复用时建议把最小字号提到 ≥10px（或按 PPT 实际 12pt 以上）。
16. 引用权威来源增加可信度：概念页定义框中引用提出者（如"哈佛商学院肯尼斯·安德鲁斯"）、书名，案例中用具体数字（"毛利率>55%""15% 提升至 25%"）而不是形容词。
17. 框架之间要交代关系：PEST 页明确说明"是 SWOT 外部分析的输入，输出填入 O/T 象限，形成逻辑闭环"，便于做系列页。
