**04-下｜026 RFM Model**
- 页面角色：框架介绍页（RFM 用户价值分层）。
- 版式与网格：标题栏 + 定义框 → 中部"左立体 + 右 8 格矩阵"：左约 30% 画 3D 立方体（X: Recency, Y: Frequency, Z: Monetary，立方体里一个绿色点标 VIP），右约 70% 是 "八大典型用户" 的 2x4 矩阵（上排四格浅绿、下排四格灰色渐深），每格含小标签（如 H-R, H-F, H-M）+ 类型名（重要价值客户/重要唤醒客户/重要深耕客户/重要挽留客户/一般价值客户/一般发展客户/一般保持客户/一般挽留客户）+ 灰字说明。→ 底部三列等宽卡片 R / F / M：每列有大号衬线斜体字母（深绿，半透明灰影）、图标、"Recency（最近一次消费）" 等名称、问题句、两条圆点解读（"越近(High R)，复购概率越大 / 越远(Low R)，流失风险越高"），最底下是深灰色横条写策略（"策略：唤醒 (Re-engage) 沉睡用户" / "培养 (Nurture) 习惯，提升频次" / "优待 (VIP Treatment) 高净值用户"）。
- 配色：矩阵用"绿到灰"的明度梯度表达价值高低（价值高=绿，价值低=灰）；VIP 格使用稍深的绿色。
- 关键文字摘录：“基于购买行为数据，识别高价值客户的黄金法则。”；“‘大水漫灌’转向‘精准滴灌’”；“重要价值客户”。

## 提炼出的设计规则
1. **页面骨架固定为"标题栏 → 结论句/定义框 → 图表主体 → 案例/应用"**：每页顶部一行 [英文框架名 粗体] + [- CASE STUDY：中文案例名 细体] + 右上角 3 位页码（如 020、056）。便于做成套模板。
2. **框架介绍页与案例页成对**：同一框架做两页，一页"定义 + 示例图 + 应用场景"，一页"CASE STUDY 真实公司/数据 + 解读"。（Marketing Funnel 025 两页、Box and Whisker 074 两页、Blue Ocean 020 案例页）。
3. **结论句写成一行带黑色实心圆点的粗体句**，放在标题栏下方，且要含"对象 + 动作 + 结果"（如"不与…正面竞争，而是…把‘游戏机’重构为…"）。长度约 1-2 行、每行 ≤ 60 字。
4. **定义框**：圆角细描边，里面第一行"框架名（中文名）- 一句话定义"（框架名粗体+下划线），其后 2-3 行小字解释；总高度约占页面 10-12%。
5. **强调色用量克制**：整页仅一种主强调色（深绿 #1F6E5A 左右），主角元素（如 Amazon 线、Wii 线、AISAS 右栏）用绿色，其余全部用灰；强调色面积大致 ≤ 10-15%。
6. **用"灰 vs 绿"表达新旧/好坏对比**（AIDMA 灰 vs AISAS 绿；传统主机灰 vs Wii 绿；红海 × 红色 vs 蓝海绿色）。
7. **需要两个不同角色的对比时，引入第二、第三个颜色，并且用淡色纵向色带 + 同色文字标注**（箱线图中 Jardine=橙色带 "High Variance"，Smith=蓝紫色带 "Consistency Engine"）；其余数据保持同一中性色。
8. **图表直接标注而不是靠图例**：斜率图在端点写"公司名 + 数值"；帕累托图用虚线圆角框 + 气泡标注"关键少数 20% 贡献 80% 营收"；箱线图用语音气泡指向中位数/IQR/异常点。
9. **图表只在关键点标数值**：曲线图仅标 Start、180M+、3B+、5B+；无网格线或仅极淡网格。
10. **图表标题用"英文细体大字 + 中文小字副标题（含单位/时间范围）"**，如 "Market Capitalization Shift / 千亿美元财富的转移 | (2010 vs. 2022)"。
11. **文字卡片用"浅灰/浅绿底 + 无边框或极细边框 + 小号灰字"，层级由字号、粗细、灰度三者共同区分**；标题 > 子标题（粗体黑）> 正文（灰）> 注释（更浅更小）。
12. **每个模块一个"可回答的问题"或一个"动作策略"收尾**：RFM 每列以深灰横条写"策略：…"；Pareto 每个应用以"战略动作："收尾；RCA 每层以"常见误区/终极对策"收尾；Marketing Funnel 底部 "Insight"。
13. **字母/首字母做视觉锚点**：用大号细体或衬线斜体字母（E/R/R/C、A/I/D/M/A、R/F/M）作装饰，半透明，不抢正文。
14. **大数字 KPI 用衬线粗体 + 小号灰字单位**（15,000+ 活跃KOCs；>80% Top3占有率），右对齐在卡片右侧。
15. **用 "三宫格 / 四宫格 / 八宫格" 做信息分层**，宫格间距一致，标题条用同色实心条（ERRC 的 4 个深绿条）；价值高低用明度梯度（绿 → 灰）。
16. **隐喻型插图用于概念页**（RCA 冰山 + "Sea Level" 水平虚线，三层标签 1 浅层/2 中层/3 根层），图形放在页面一侧，文字放在另一侧。
17. **步骤性内容用逐级缩进/变窄表达漏斗**（AISAS 右栏每行向内缩进）。
18. **每页保留 8-12% 的外圈留白**（卡片外框到画布边缘），卡片内部留白均匀。

## 字体与字号层级
- 英文标题：粗体无衬线（类似 Source Sans/思源黑体 Bold 或 Segoe UI Bold），不确定具体字体。
- 中文：黑体系（类似思源黑体/苹方），不确定具体字体。
- 装饰字母 / KPI 大数字 / "Insight" / "CAGR>300%"：衬线斜体或衬线粗体（类似 Georgia/Times 风格），不确定具体字体。
- "Core Idea"、"RCA Iceberg"、图表标题（Market Capitalization Shift）：细体（Light）大号无衬线，绿色或灰色。
- 层级（相对页面高度估算，非真实 pt）：页标题 + 页码（最大，约占页面高度 3.5-4%）> 图表标题 / 区块标题（约 2.2%）> 结论句 / 小标题 粗体（约 1.5%）> 正文 / 要点（约 1.2%）> 注释 / 轴标签（约 1%）。真实 pt 数值不确定。
- 每页字号只用 4-5 档；强调靠"粗细 + 颜色（黑/灰/绿）"而不是继续加大字号。

## 出现的思维模型/框架/方法论
- **Blue Ocean Strategy / ERRC 四步法**（页 020）：Eliminate 剔除 / Reduce 减少 / Raise 提升 / Create 创造；用 2x2 四宫格 + 价值曲线（Strategy Canvas）。案例：任天堂 Wii 不在性能红海对打，把"游戏机"重构为"全家体感娱乐设备"。
- **Pareto Principle 80/20 / 帕累托分析**（页 056）：柱状 + 累计折线 + 双轴；"关键少数 vs 无用多数"；应用：产品组合优化、客户关系管理、质量控制与流程优化。
- **Root Cause Analysis (RCA) 根本原因分析**（页 057）：冰山模型（表面症状/直接原因/根本原因）；三大心法：对事不对人、5个"为什么"、用数据说话；"重复犯错的代价"收尾。
- **Slope Chart 斜率图**（页 083）：两个时点对比，线条斜率表示变化；案例：北美零售 Amazon / Walmart / Costco / Target / J.C. / Sears 2010 vs 2022 市值。
- **Box and Whisker Plot 箱线图 / 五数概括法**（页 074）：最小值/Q1/中位数/Q3/最大值 + 1.5×IQR 异常点；案例：销售审计，识别 "虚假的高产出（高方差）" 与 "真正的产能引擎（稳定）"；提醒"幸存者偏差"。
- **Marketing Funnel：AIDMA vs AISAS 营销漏斗**（页 025）：AIDMA（Attention/Interest/Desire/Memory/Action）vs AISAS（Attention/Interest/Search/Action/Share）；案例：完美日记"公域种草 + 私域收割"，KOL 金字塔（头部明星/腰部垂类 KOL/尾部万名 KOC）。
- **RFM Model 用户价值分层**（页 026）：Recency/Frequency/Monetary 三维，高低二分得 8 类用户，对应策略（唤醒、培养、优待）。
- **Storytelling 方法**（隐含，见 tags）：每页以"结论句"开头，案例页用"高亮 + 解读栏"讲故事。

## 正文金句与方法
- 以前做 PPT 喜欢从空白页开始：找图标、调间距、纠结两个颜色，页面顺眼了脑子也没电了，"这页到底要说什么"反而放到最后。
- 现在先找一个能用的框架：结构有了，图表也有个起点；剩下的精力用来判断**哪些数据该留，结论应该落在哪里**。
- 能复用的就直接复用，能参考的也别硬想。
- 🗞️"脑力其实很贵。尽量花在那些没有标准答案的地方。"
- 可执行化：做页面顺序 = 先定框架 → 填数据 → 决定留哪些数据 → 写结论句 → 最后才调图标/间距/颜色。
