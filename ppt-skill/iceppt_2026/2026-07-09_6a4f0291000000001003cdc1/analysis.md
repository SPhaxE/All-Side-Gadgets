# power point重要的是point：商业思维模型 PPT 合集（第2批，编号013-083）

## 本篇主旨
展示一套“每个思维模型 = 1页理论页 + 1页案例解析页”的信息密集型商业分析 PPT 模板体系（Moat、NPS、Kano、DMAIC、SIPOC、3 Horizons、3C、SCP、Slope Chart、Pareto、RCA、TOWS、Persona、CJM 等）。caption 总结方法论：“言之有物，数据详尽，最后再加一点审美”，即先有内容与数据，再用统一的绿色系视觉去美化。

## 逐页拆解

通用说明：所有幻灯片是 3 张竖向拼成 1 张图（不是 2 张）。每张幻灯片都是白底圆角描边的“卡片”，整图背景是淡青灰色（约 #BDD7D6）。以下统一称 上 / 中 / 下。

### 02.jpg（NPS 034 / NPS 案例 034 / Kano 035）
**上：NPS (Net Promoter Score) 理论页**
- 版式：定义框 → 带引号的大问句 “您有多大可能向朋友或同事推荐我们的产品/服务？” 置于带投影的白色条上 → 1-10 数字圆圈刻度（7、8、9 绿色圆，其余灰圈，强调“被动者/推荐者”区间）→ 三张圆角阴影卡片（0-6 Detractors / 7-8 Passives / 9-10 Promoters，每张含 “用户画像 / 行为特征 / 战略动作” 三个灰色小标签）→ 右侧绿色虚线框 “The NPS Formula 计算公式”。
- 大数字：“0-6 /10”“7-8 /10”“9-10 /10” 大号粗体黑 + 小号 “/10” + 星级；公式 “NPS = (推荐者%) - (贬损者%)”；基准 “>0 合格 / >30 优秀 / >70 卓越” 用斜体衬线绿字突出。
- 战略动作用英文关键词：Damage Control(止损) / Nurture(培育) / Leverage(放大)。

**中：NPS - CASE STUDY：Costco（开市客）靠口碑（NPS）驱动增长**

- 版式：左右两栏，中间虚线分隔，两栏各有小标题 “The NPS Advantage / NPS与财务的强关联”。

- 右：01 克制的毛利率 / 02 寻宝体验 / 03 无理由退货，大号灰色序号 + 右侧 “策略” 灰条 + 带绿色对勾的白色圆角说明条。
- 底部：一行圆角胶囊 “战略启示：…”。
- 图表类型：KPI 大数字对比卡（无坐标轴）。

## 提炼出的设计规则
1. **每个思维模型固定两页**：页1“理论页”（定义 + 图解 + 使用要点/局限），页2“案例页”（真实公司 + 结论句 + 数据/图表 + 启示）。
2. **统一页头结构**：左上 大号粗黑标题（框架英文名），右上 “@ICEPPT + 3位编号”（编号用粗黑加宽字体，ICEPPT 用绿色加大字距）；案例页标题改为“框架名 - CASE STUDY：公司 + 结论短语”，且编号可省略 @ICEPPT。
3. **定义框模板**：圆角描边框；第一行 = 框架英文名（中文名）+ 破折号 + 一句话定位（粗体）；框架名下加 1 条红色下划线（唯一的红色强调）；第二段为 2-3 行 8pt 级灰黑小字背景说明。
4. **案例页必有“结论句”**：标题下一行，以黑色实心圆点 ● 开头，整句加粗，写成“做法 → 结果（含数字）”，如“……将吞吐量提升了 30%”。
5. **强调色面积≤10%**：整套仅用一个绿色色系（深绿描边/文字 + 浅绿底），灰色铺大面积；重点元素 = 深绿描边 + 轻投影 + 白底，其余元素 = 无描边灰底。每页只让1个格/1条线/1张卡获得强调（如 S/O 格、Process 列、Analyze 行、Amazon 线、Why 5）。
6. **“灰 + 一色”图表规则**：坡度图/折线/柱图中，对比对象全部灰色，只把要讲的那一个/两个对象用深绿粗线+绿标签；上升加 ▲、下降加 ▼ 并用深灰。
7. **图表标题写洞察，不写名词**：如 “90% of people in the world live in range of a 4G network”、“Market Capitalization Shift”，而非“折线图”。
8. **图表直接标注取代图例和网格**：数值直接写在点/柱旁，去除多余坐标轴、网格线；关键点用虚线圆角气泡 + 一句解释。
9. **大数字 KPI 卡**：数字用 3-5 倍于说明文字的字号，绿色斜体衬线或粗体，下方灰色小标签说明；前后对比用 “灰色旧值 → 绿色新值”（如 12% → 28%）。
10. **“理论页”三段式布局**：上=定义框，中=大图解（占 50%+ 高度），下=要点/启示灰条；三列或五列卡片等宽，列间距统一。
11. **大序号 + 小标题 模块化**：01/02/03 或 #1-#4 使用大号浅灰（装饰）序号 + 绿色或黑色粗体标题 + 灰色说明；同一页内序号样式统一。
12. **巨大首字母装饰**：DMAIC / SCP 用特大斜体衬线粗体深绿字母作为列头（占列宽 1/3），配小号阶段说明，形成强视觉锚点。
13. **背景装饰弱化**：背景使用半透明灰色剪影/照片/超大淡灰数字（01-05、Retail Apocalypse、RCA Iceberg 文字），透明度极低，不干扰正文；正文放在白色或浅色块上。
14. **底部“战略启示 / Insight”灰条**：每页收尾一条灰底（≈#EEF0EE）横条，写 1-2 行总结（如 “人类的天性是遇到问题就立刻跳到解决方案……”）。
15. **信息分层用灰度**：主信息 黑色粗体；次级说明 中灰；三级补充（触点、例子）浅灰；链接信息的箭头/连线用中灰或绿色。
16. **框架图直接就是页面骨架**：3C 用三角排布、Ansoff/竞争定位图用 2×2、CJM 用矩阵、Kano 用坐标曲线——先画框架结构，再往结构里填字。
17. **用“前→后/左→右”表达因果**：箭头（⇨、▶、大三角）固定表示“痛点→策略”“来源→解释”；虚线箭头表示反馈/反向作用。
18. **内容密度高、字号小**：正文 8-10pt（相对 1080px 宽图约 9-11px 字高），靠留白+边框+灰度分层避免拥挤；文字都放在圆角框里，间距统一（约 8-12px）。
19. **圆角矩形、投影轻**：所有卡片圆角约 6-10px，重点卡才有投影（模糊半径小、透明度低）。

## 出现的思维模型/框架/方法论
- **Moat Analysis（护城河分析）**：5 大来源（转换成本、成本优势、网络效应、无形资产、规模效应）× 强度打分；案例 Liquid Death（极端品牌文化 + 社区）。
- **Competitive Positioning Map（竞争定位图）**：选 2 个维度做 2×2，找空白象限；4 条 Key Insights（维度决定结论 / 拥挤是信号 / 空白不等于机会 / 定位会漂移）。
- **NPS**：0-6 贬损者 / 7-8 被动者 / 9-10 推荐者；NPS=推荐者%−贬损者%；基准 >0 / >30 / >70；案例 Costco（NPS 79，会员续费 ~90%）。
- **Kano Model（卡诺模型）**：基本型 / 期望型 / 兴奋型 / 无差异 / 反向，对应战略动作 Threshold / Compete / Differentiate / Avoid / Remove。
- **Six Sigma DMAIC**：Define-Measure-Analyze-Improve-Control；案例 Sweetgreen 排队问题（帕累托 + 箱线图），吞吐量 +30%。
- **SIPOC**：Supplier-Input-Process-Output-Customer，建议用 COPIS 反向构建；示例咖啡店。
- **Ansoff Growth Matrix**：市场渗透/市场开发/产品开发/多元化；案例蜜雪冰城走“市场开发”。
- **3 Horizons（麦肯锡三层增长）**：H1 核心、H2 新兴、H3 未来期权（1-3年/2-5年/5年+）；误区“99% 资源放 H1”；案例工业设备商 AI 预测维护。
- **3C's Model（大前研一战略三角）**：Customer / Corporation / Competitor，交集=战略甜蜜点；案例西南航空（15 分钟 vs 60 分钟过站）。
- **SCP Paradigm（结构-行为-绩效）**：结构决定行为、行为决定绩效，另有反向作用。
- **Choropleth Map（分级设色地图）**：案例跨国零售商网络错配诊断。
- **Slope Chart（坡度图）**：两个时点对比；案例 4G 覆盖率、北美零售市值（Amazon / Costco 逆袭）。
- **Pareto Principle 80/20**：关键少数；案例 F2P 游戏 99/1 “鲸鱼经济学”。
- **RCA（根本原因分析）**：冰山模型（表面症状/直接原因/根本原因）+ 5 Whys + 数据帕累托；案例硬件垫圈退货（采购省 2 美分）。
- **TOWS Matrix**：S/O、W/O、S/T、W/T 四类战略；案例 Crumbl Cookies。
- **User Persona（用户画像）**：Demographics + Psychographics + 画像到产品映射；案例 Peloton 的 Sarah。
- **CJM（用户旅程地图）**：5 阶段 × 行为/触点/情绪曲线/对策；案例 IKEA（峰终定律、宜家效应、强制动线）。
- 其他出现的名词：COPIS、Peak-End Rule（峰终定律）、IKEA Effect。
