# 项目复盘：暖橙水滴 IP → 动态桌宠

从一张 8 步 IP 绘制教程图出发，逐步复刻成 SVG，再按 pet-forge 的 SVG 路线做成可交互桌宠，最后发散出同系列角色、做成分享页，并把流程归档为技能 `.claude/skills/ip-to-desktop-pet/`。本文按迭代顺序记录每一轮的反馈与优化，然后汇总踩过的坑。

交付物：`index.html`（完整验收页）、`share.html`（手机优先分享页）、`ref/`（原图逐步裁切）、`README.md`（参数与取舍）。

## 二、踩坑汇总

每条按「现象 → 原因 → 怎么发现 → 怎么修」记录。

### 复刻

1. **复刻的 ω 嘴变细、臂顶变尖**
   - 原因：描边阈值偏白把形状量细；再加「内缩校正光晕」进一步变细；18 个锚点均匀分布，贴不住半径 2.7 的圆头。
   - 发现：原分辨率放大并排对照。
   - 修：用半强度阈值只量尺寸，按量到的几何（描边宽、三臂中心、半椭圆 U 洞、中缝为两外弧交点）解析重建，曲率加权拟合。
2. **身体底部被斜着切掉一块**
   - 原因：生成器里一段弧线的 x、y 都写成了 `sin`，变成直线。
   - 发现：叠图对照。
   - 修：每个生成器先单独画出来再接入。
3. **把等效参数写成「换算值」**
   - 原因：原画板尺寸未知，SVG 滤镜值其实是对照原图调出来的。
   - 修：页面同时写教程原值和「对照原图调出的 SVG 等效值」。

### 曲线与形状

4. **休息态看起来像被拉伸**
   - 原因：睡姿就是把静止形压扁。
   - 修：睡姿设计成另一个姿势（小橙侧身倒下，噼啪收角斜靠）。
5. **小橙轮廓不连续、角旁边有凹坑**
   - 原因：直线接圆弧只有 G1，拟合后留下拐点；改用「变指数超椭圆」做角又会在旁边内凹。
   - 发现：画曲率梳、统计曲率变号次数。
   - 修：用曲率半径随法向角的分布 ρ(θ) 定义形状。ρ>0 且光滑 ⇒ 外凸且 G2；去掉一阶谐波 ⇒ 精确闭合。
6. **锚点太少，拟合长直边时振铃出拐点**
   - 修：加二阶差分正则；网格搜索「无拐点前提下 K 最少」的组合（小橙 K=16、c=4、λ=0.02）；外凸角色再加凸性守护。依据是均匀 B 样条的变差缩减性：控制多边形凸 ⇒ 曲线凸。
7. **姿态变化时锚点滑走**
   - 原因：锚点的参数取自静止形的弧长，角一移动锚点就不在角上了。
   - 修：参数跟着特征走（小橙以角方向为中心，噼啪 θ 随尖角旋转 / 弯折）。
8. **关键形线性相加会叠出尖角、让脸跑出身体**
   - 修：改为参数化生成器每帧生成；每个状态都跑「五官在体内」检查。
9. **逐锚点交替的果冻抖动让轮廓起皱**
   - 修：改为 2 瓣、3 瓣两个平滑模态。
10. **细线形（闭眼、眨眼）锚点太少，被守护压成尖点**
    - 修：半宽 ≥ 2.3，眼睛用 12 个锚点。

### 动画

11. **「转一圈」没有发生**
    - 原因：状态每帧重设目标，把旋转目标覆盖了。
    - 发现：逐帧打印 `rot`，一直是 0。
    - 修：整圈旋转单独累加，转完与目标一起减去整圈，无缝归零。
12. **登场动画快到看不清**
    - 原因：被急性子的时间系数缩短了。
    - 修：表演给人看的动画用固定节奏。
13. **模拟 Agent 事件时身体抽动**
    - 原因：圆角 / 凸性守护是开关式修正，形状在阈值附近每帧一会儿修一会儿不修；默认姿态又正好贴着阈值；贴地用离散采样的最大值，换脚着地时硬跳；发抖用方波。
    - 发现：逐帧算锚点二阶差分，按管线分段（拟合 / 圆角守护 / 凸性守护 / 贴地）比较，定位到守护把 2～3 放大到 11～15。
    - 修：身体守护改为固定遍数、强度从下限 × 1.25 处平滑升起的连续修正；凸性守护按违例量比例修正；五官 / 特效保留硬守护（静态目标形，很少触发）；贴地用亚采样抛物线精化 + 快速临界阻尼跟随；发抖改为平滑振荡 × 平滑包络；打字时两条腿不动。
    - 走过的弯路：第一次把所有守护都改「软」并提前结束迭代，五官半径掉到 0、噼啪出错态抖得更厉害。软守护必须固定遍数；五官继续用硬守护。
14. **生气要「更尖」与「永无尖角」的冲突**
    - 修：圆角下限用弹簧在 6 / 3.4 / 2.6 之间平滑切换，尖锐度参数做上限，永远是圆角、不出现尖点。

### 页面与验收

15. **QA 只断言状态名，漏掉「落地没有动画」**
    - 修：抛落逐帧采样高度和压扁权重，断言有中间高度、回弹、压扁、站稳。
16. **同页多个内联 SVG 的 id 冲突、滤镜被切边**
    - 修：id 按实例加前缀；滤镜区域显式设大。
17. **分享页走了两个极端**
    - 先是说明文字太多，后来又一个字都不放。
    - 「让布局说话」指的是用层次组织信息：大字名字 → 性格 → 实时心情 → 舞台 → 角色切换 → 模拟 Agent → 一行手势提示。
18. **同一引擎跑两个页面**
    - 修：引擎取元素统一用 `$()`，缺失时返回游离占位；分享页由脚本从验收页生成。
19. **面板切分脚本数错画板**
    - 原因：按白色连续段找边界，被画面内容打断（数出 14 块）。
    - 修：改为识别画板之间的深灰底色。
20. **`-x ** 2` 是语法错误**
    - 整个脚本不执行，页面空白。
    - 修：写成 `-(x ** 2)`。

## 三、可复用的东西

- **技能**：`.claude/skills/ip-to-desktop-pet/`。`SKILL.md` 是流程和 14 条硬性规则；`references/` 下有复刻方法、引擎设计、验收清单；`scripts/` 下有 `split_panels.py`、`trace_outline.py`、`qa_pet.js`、`build_share.py`。

- **验收**：`node .claude/skills/ip-to-desktop-pet/scripts/qa_pet.js ip-pet/index.html`。

## 四、已知取舍

- Part 1 教程复刻保留教程原本的圆角矩形和圆弧拼接（G1），与原图一致；桌宠形态全部是 G2。
- 小橙静止时角半径约 10.3（教程是 9），这是保证无拐点时的最少锚点数（16）下能做到的值。
- ω 嘴中缝原本是两段圆弧的交点（尖角），按「永无尖角」倒圆，与原图量取几何最大偏差约 0.5 单位。
- 噼啪登场时尖角升起的过程中会短暂多出拐点（凸起正在长出来），其余时刻恒为 10。
