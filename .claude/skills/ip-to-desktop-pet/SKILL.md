# IP 绘制 → 动态桌宠

这套流程来自 `ip-pet/` 项目（暖橙水滴 + 糯糯 + 噼啪）。参考实现就是仓库里的 `ip-pet/index.html`：开工时先读它，新角色、新项目优先在它的引擎上改，而不是从头写。

## 交付物

| 文件 | 作用 |
|---|---|
| `index.html` | 验收页：Part 1 逐步复刻 + 原图对照，Part 2 pet-forge 流程，Part 3 舞台 + 控制台（切状态、模拟 Agent 事件、显示锚点），附迪士尼法则表和状态表 |
| `share.html` | 分享页：手机优先，整屏就是舞台，角色切换只用地面上的缩略图，界面不放文字（让布局说话）；由 `scripts/build_share.py` 从 index.html 生成，引擎只有一份 |
| `ref/stepN.jpg` | 原图逐步裁切，供对照 |
| `README.md` | 参数、取舍、与原图的差异说明 |

页面写成 Artifact 规范的 HTML（无 doctype，`<title>` + `<style>` 开头，颜色令牌 + 深色模式），发布后给用户链接，同时提交到仓库。

## 流程

### 1. 复刻教程图（详见 `references/replication.md`）

1. 原图放进独立空目录；`scripts/split_panels.py` 找画板边界并逐步裁切。
2. 读图里的参数对话框（内发光、高斯模糊等）：按原分辨率裁切放大后再看，不要猜。
3. 取色、量几何：用画板像素 ↔ SVG 单位的固定比例换算，所有数值写进代码注释。
4. 细小特征（嘴、眼）用 `scripts/trace_outline.py` 以**半强度阈值**描轮廓量尺寸；再按量到的几何**解析重建**（圆弧、半椭圆、交点），不要直接用像素描边拟合——描边噪声会被拟合放大。
5. 每一步渲染后与原图做「并排 + 50% 混合」对照，读图迭代，直到眼睛、嘴、轮廓重合。
6. Illustrator 效果在 SVG 里只有等效值（内发光、模糊半径和画板尺寸相关）：页面上同时写教程原值和「对照原图调出的 SVG 等效值」，不要声称是换算值。

### 2. 角色设计与发散

- 先做拓扑清点：只有身体和脸就只做这两样。**不要头顶装饰、腮红、眼睛高光、四肢**，差异只来自外形、面部、填色、性格。
- 同系列角色的剪影必须一眼可分：把静止形纯黑填充、48px 并排看。本项目用了水滴 / 云朵软糕（平底 + 三鼓包）/ 软五角星。
- 面部统一参考图的语言：白色纯色简单形、无阴影无高光、足够大。
- 性格落到参数上：时间系数 T、夸张系数、弹簧刚度/阻尼、入睡时间，以及同一输入的不同反应（被戳、被拎起、开心）。

### 3. 引擎（详见 `references/engine.md`）

硬性规则，全部来自用户验收反馈，任何角色都适用：

1. **曲线 G2**：所有轮廓是闭合均匀三次 B 样条（C2 ⇒ G2）。
2. **任何时刻都没有尖角**：每帧做圆角守护（身体曲率半径 ≥ 6、五官 ≥ 1.5、特效 ≥ 1 单位）；目标形拟合前先沿弧长高斯平滑。
3. **形状变化只靠锚点**：身体画 7 个关键形（静止/压扁/拉长/左倾/右倾/融化/鼓起），全部在生成器里画出、用同一组生成器参数拟合以保证锚点一一对应；运行时只做加权混合。**禁止**运行时缩放、拉伸、剪切、旋转——倾斜也要在生成器里画（底部不动、上部弯过去），不能用剪切生成。
4. **表情是锚点插值**：同一部件所有表情点数相同、起点相同、绕向相同；切换只改弹簧目标，绝不直接写姿态，打断时从当前形续接。
5. **眼睛以下眼睑为基准**：拟合后把最低点钉回基线；整张脸作为刚体随身体平移，眼—嘴三角区不变形。
6. **锚点尽量少**：拟合参数按「弧长 ×（1 + 2·曲率）」分配，锚点自动集中到急弯；报告每个形状的拟合误差。
7. **填色要回应互动**：指针光斑、点击色波、拖拽晃荡、落地下压、情绪变色，不能只是自己循环流动。
8. **特效有滞后**：画在舞台独立图层，锚点用弹簧滞后跟随；粒子生成后独立运动；出现/消失是从同点数小圆点过渡。
9. **拉起落地要有物理**：抛物线、按冲击速度压扁、回弹、站稳。
10. **动效遵循迪士尼 12 法则**，并在页面上写一张「法则 → 具体做法 → 在哪里看」的对照表，表述要诚实。
11. 抗锯齿用 `<mask>` 而不是 `clipPath`；`shape-rendering: geometricPrecision`。

### 4. pet-forge 对接

沿用 pet-forge 的约定：`viewBox 0 0 200 200`、`<g id="pet">`、`--breath-period` / `--blink-min-gap` 等变量名、state-map 的 14 个状态名与 A（循环）/ B（一次性回原姿态）/ C（过渡链接）语义、Agent 事件映射（`UserPromptSubmit→thinking`、`PreToolUse→working-typing`、`PostToolUseFailure→error`、`PermissionRequest→notification`、`Stop→happy`、长时间无事件→睡眠链）。宿主负责位移，SVG 只负责表演。手写 SVG 时如实说明没有跑 png2svg / vtracer。

### 5. 验收（详见 `references/qa.md`）

不要只断言状态名——上一轮「落地没有动画」就是这样漏掉的。用 `scripts/qa_pet.js` 跑：

- 控制台零报错；375px 无横向滚动；深浅色都看一遍。
- G2：每个拼接点切向角差、曲率差 ≈ 0。
- 圆角：遍历全部状态 + 拖拽 + 抛落，身体最小曲率半径 ≥ 6、五官 ≥ 1.5。
- 眼睛基线偏差 ≈ 0；任意状态下五官都在身体轮廓内。
- 抛落逐帧采样：有中间高度、至少一次回弹、落地压扁、最终 y = 0。
- 性能：4× CPU 降速下 rAF 中位数 ≤ ~22ms。
- 截图读图：原图对照、表情过渡胶片、交互前后（填色）、剪影并排。

### 6. 收尾

1. `python3 .claude/skills/ip-to-desktop-pet/scripts/build_share.py <index.html> <share.html>` 生成分享页，按 390×844 手机尺寸（深浅色）和桌面各截一张检查。引擎里取元素统一用 `$()`（缺失时返回游离占位），分享页里没有的控件不会报错。
2. 更新 README（参数、取舍、诚实的差异说明）。
3. 提交、推送到指定分支；发布/更新 Artifact，回复里按用户反馈逐条说明改动和查看方式。

## 常见坑（都踩过）

- 宽图直接看会糊：按画板裁切、原分辨率看对话框。
- 同页多个内联 SVG 的 `id` 会冲突：渐变、滤镜、遮罩 id 都按实例加前缀。
- 滤镜默认区域只扩 10%：模糊会被切边，显式设 `x/y/width/height`。
- 生成器里弧线写成两个 `sin` 会变直线：每个新生成器先单独画出来看。
- `-x ** 2` 是语法错误，要写 `-(x ** 2)`。
- 关键形相加会叠出尖角或让脸跑出身体：圆角守护 + 「五官在体内」检查必须在全部状态下跑。
- 薄条形（闭眼、眨眼）锚点太少会被守护压成尖点：加粗到半宽 ≥ 2.3、眼睛用 12 个锚点。
- 描边阈值偏白会让形状变细；描边 + 内缩更会失真：用半强度阈值，并以解析重建为准。
