## 3. 小橙几何

- **身体（教程原形）**：圆 r = 60 + 右上角 r = 9 + 上边、右边各长 51（`M86 30H137A9 9 0 0 1 146 39V90A60 60 0 0 1 86 150A60 60 0 0 1 26 90A60 60 0 0 1 86 30Z`，教程坐标）。
- **身体（桌宠，G2）**：ρ(θ) 分布，圆部分 60、角部 rc、两条边是宽 5° 的高斯长度脉冲 51·m·(1 ± d)，窗口过渡宽 6°，去一阶谐波闭合；角对面圆弧的圆心 = (100, 100)。见 `scripts/rho_shape.py`。
  - 参数范围：rc 6…20，m 0…1.25，d −0.4…0.4；超出会让 ρ 接近 0。
  - 常用姿态：静止 rc 9；生气 / 被戳 rc 7.5；通知 rc 6.5、m 1.25、d −0.38；出错 rc 16、m 0.75、d 0.4；睡 rot −62°、rc 13、m 0.85、d 0.2。
- **眼睛**：胶囊 15 × 25.2（半强度阈值量取），下眼睑中点 (69.2, 101.6)、(95.4, 101.6)。
- **ω 嘴**：中心 (83.2, 119.3)，宽 27。描边宽 5.3；三臂中心 x = 72.3 / 83.15 / 94.15，臂顶圆心 y = 115.15；U 洞为半椭圆 rx 2.78、ry 4.9；外底为两段圆弧（圆心 y = 117.3，半径 = 半臂距 + 2.65），中缝为两弧交点（倒圆）。20 锚点曲率加权拟合，最大偏差约 0.5。
- **配色**：渐变 #FF413B → #FCD685；色团 #FF1F4B、#FFE9A6；内发光 #FDE3A7；阴影 #FF6A4A；强调 #F0533A。

## 4. 噼啪几何

- 身体：θ(p) = −90° + 360°·p + rot + Σ bend_i·cos²(πd/0.2)（|d| < 0.1），r(p) = core + Σ ext_i·0.44·exp(−(d / (0.046/sharp))²)，半径 58；尖角 i 在 p = i/5。
- 静止 core 0.78、ext 1、sharp 1；生气 sharp 1.55、ext 1.3、core 0.74；睡 ext 0.45、droop 0.28、rot 20°。
- 脸：胶囊眼 14 × 21，下眼睑 (86.5, 111)、(113.5, 111)；咧嘴宽 26，中心 (100, 123)。
- 配色：#A86BFF → #FF7FB0；色团 #5B8CFF、#FFD1F0；内发光 #FFD9F7；强调 #7A3DF0。

## 8. 验收基准值

G2 偏差 ~1e-14；下眼睑偏差 ~1e-16；小橙所有状态曲率变号 0、噼啪恒为 10；身体最小曲率半径约 3.2（噼啪生气）、五官约 1.37；稳定状态锚点逐帧二阶差分 ≤ ~4；4× 降速 rAF 中位约 18–20 ms。
