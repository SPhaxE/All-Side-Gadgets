# 教程图复刻方法

目标：每一步的 SVG 画板与原图逐张对照时，轮廓、眼睛、嘴重合，配色和光感接近。

## 1. 拆图

- 上传的压缩包 / 图片解压到独立空目录，脚本放在别的目录，Python 用 `-I` 运行。
- `scripts/split_panels.py <图片> <输出目录>`：取中间一行的亮度变化找白色画板边界，按画板裁出 `stepN.jpg`（同时输出画板坐标）。本项目原图 9940×1522，8 个画板各宽 1200px。
- 给页面用的对照图：每块画板裁掉标题区，缩到 400×360，存进 `ref/`。

## 2. 读参数

- 对话框（内发光、高斯模糊）在缩略图里看不清：按原分辨率裁出对话框区域，放大 2～3 倍再读。
- 本项目读到：内发光「滤色 · #FDE3A7 · 60% · 模糊 100px · 边缘」，高斯模糊「半径 129.1178 px」。
- 取色用 PIL 在原图上直接采样（纯色步骤取画板中心；渐变取四角附近）。

## 3. 量几何

- 定一个换算：某一步的纯色外形外接框（如水滴 692px）↔ SVG 单位（120）。之后所有量取都过这个换算。
- 圆角半径：沿外接框边逐行扫描非白像素的最右点，看在哪一行收敛。
- 眼、嘴：`scripts/trace_outline.py` 用**半强度阈值**（白与背景色的中间值）提取最大连通块并追踪边界，给出外接框和轮廓点。阈值偏白会把形状量细。

## 4. 解析重建

像素描边带有 JPEG 光晕和台阶，直接拟合会把噪声带进形状（本项目第一次的 ω 嘴就因此变细、臂顶变尖）。正确做法：

1. 用描边结果量出几个关键尺寸（ω 嘴：描边宽 5.3、三臂中心 x、臂顶 y、洞底 y、外底 y、中缝 y）。
2. 用几何原语重建：臂顶 = 半圆，洞 = 半椭圆 U，外底 = 两段大圆弧，中缝 = 两弧交点。
3. 稠密采样后按曲率加权拟合到最少锚点（ω 用 20 个），报告最大偏差。
4. 中缝这类交点是尖角，按「永无尖角」规则倒圆，偏差如实写进说明。

## 5. 效果映射（Illustrator → SVG）

| 教程效果 | SVG 做法 | 备注 |
|---|---|---|
| 线性渐变 | `linearGradient`，端点用 objectBoundingBox 或随身体锚点移动的 userSpace 坐标 | 量色带位置调 stop offset |
| 内发光（边缘） | 反相 alpha → 高斯模糊 → `in` 原形 → 颜色 flood → `feBlend mode=screen` | AI 与 SVG 算法不同，不透明度、模糊值对照原图调出 |
| 高斯模糊 | `feGaussianBlur`；移动中的形状改用径向渐变填充代替模糊，省性能 | 原画板尺寸未知时不要声称「换算」 |
| 投影 | 偏移椭圆 + 模糊；桌宠里改成舞台地面上的独立阴影 | |

滤镜区域默认只扩 10%，模糊会被切边，显式设大。

## 6. 对照

每改一次就渲染「原图 | 复刻 | 50% 混合」三联图读图；嘴、眼单独按原分辨率放大对照。复刻页提供「复刻 / 原图」切换和悬停看原图。
