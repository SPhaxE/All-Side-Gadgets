## 1. 曲线与拟合

- 所有闭合形状 = 均匀三次 B 样条控制点（`bspline`），C2 连续 ⇒ G2。
- 拟合（`fitClosed`）：给定稠密样本和每个样本的参数 u ∈ [0, K)，解 K×K 法方程，得到 K 个控制点。
- 参数分配（`curvU`）：按「弧长 ×（1 + c·曲率）」累积，c = 2。锚点自动集中到急弯，所以少量锚点就能贴住圆头、小 U。
- 面部 / 特效形状（`fitShape`）：统一绕向（`normLoop`）→ 等弧长重采样 → 沿弧长高斯平滑（`smoothLoop`，σ = 0.8）→ 拟合 → 设计期圆角守护。
- 起点规则保证锚点对应：眼睛从底部中点起（`bottomCenter`），嘴和特效从最左点起（`leftmost`）。

## 2. 圆角守护（`roundGuard`）

在每段的 t = 0 / .25 / .5 / .75 用 `bsR` 算曲率半径；小于下限就把相关锚点向「左右邻点中点」松弛，迭代至满足。下限：身体 `R_BODY = 6`、五官 `R_FACE = 1.5`、特效 `R_FX = 1`。设计期跑 60～80 遍，运行期每帧 14 遍以内。

## 3. 角色定义与参数化身体

`CHARS.<key>` 关键字段：`K`（锚点数）、`genAll(params)`（返回 `PS` 上的稠密样本）、`params`（默认姿态参数，数组参数如 `ext`/`bend` 每个元素一根弹簧）、`curvC` / `lambda`（拟合的曲率权重与二阶差分正则）、`convex`（是否加凸性守护）、`rmin`（默认最小曲率半径），以及填色、脸、性格字段（同前）。

生成器：

- **小橙 `dropAll`**：按法向角 θ 给出曲率半径 ρ(θ)：圆部分 60，角部 `rc`（默认 9），上边 / 右边是宽 5° 的高斯「长度脉冲」（默认 51，`d` 控制两边长差 → 耷拉 / 翘起，`m` 控制角的量，`m=0` 为圆）。去掉 ρ 的一阶谐波保证闭合，再沿 θ 积分得到轮廓；角对面那段圆弧的圆心放在 (100,100)。参数 p 以角为中心，锚点随角移动。
- **噼啪 `starAll`**：θ(p) = −90° + 2πp + rot + Σ bend_i·窗函数，r(p) = core + Σ ext_i·0.44·高斯(sharp)。尖角可单独伸缩、弯折，整体可旋转、变尖。

预计算：静止形样本 → `curvU` 定参数 u（随特征走，所有姿态共用）→ `fitOperator` 得到 K×N 矩阵 M =（AᵀA + λDᵀD）⁻¹Aᵀ。运行时（`Pet.genBody`）：`S = genAll(当前参数)` → `applyFit(M, S)` → 平滑果冻模态（2 瓣 / 3 瓣）→ `roundGuard` → 外凸角色 `convexGuard` → `groundSnap`（最低点贴地）。

本项目选出的拟合设置：小橙 K=16、c=4、λ=0.02（无拐点，误差 0.66，角半径 10.3）；噼啪 K=15、c=2、λ=0.002。

## 4. 表情与脸

- 眼睛目标形（`eyeTarget`）：胶囊、截顶胶囊（半眯/难过/生气）、粗线弧（闭眼/开心/眨眼/皱眼）。拟合后把最低点钉回 y = 0（下眼睑）。
- 嘴目标形（`mouthTarget`）：ω（参考重建）、弧形笑、小笑、圆 O、哈欠、D 形大笑、咧嘴、波浪、撅嘴、直线。
- 粗线一律用 `strokeLoop`（圆头），半宽 ≥ 2.3；波浪的波长要让内侧曲率半径大于线宽，否则轮廓折叠。
- `PtsSpring`：每个锚点坐标一根弹簧；`setFace` 只改目标。眨眼期间表情弹簧刚度 ×2.6。
- 脸的位置：`Pet.place` 把身体局部坐标映射到舞台（跟随压扁时的位置变化、整体旋转、贴地位移，但不缩放形状），脸的每个部件以锚点为原点刚体旋转；再加滞后弹簧（`fox/foy`）和视线（`gx/gy`，x、y 刚度不同 → 走弧线）。

## 5. 渲染与填色互动（`Pet.render`）

- 身体路径写进 `<mask>`，填色层（线性渐变矩形 + 两团径向色团 + 指针光斑 + 点击色波 + 高光）都在遮罩内，外层套内发光滤镜。
- 渐变端点和高光用 `place(q, false)`：跟着身体走但不随身体旋转（光从左上来）；色团用 `place(q)` 随身体转。渐变轴按横向速度转向。
- 互动：指针靠近 → 光斑跟随（按下更亮）；点击 → `ripple`；拖拽 → 色团按加速度反向晃荡（欠阻尼弹簧 `slx/sly`）、整体提亮（`speed`）；落地 → 色团下压；情绪 → `warm` / `cool` / `grey` 弹簧混色。

## 6. 状态机与行为

- `S`：pet-forge 的 14 个状态 + `intro`（C，登场动画），`c` = A / B / C，B 有 `ms`（可 `then` 链），C 有 `next`，A 可有 `after`。
- `setState`：只设目标与表情，登记定时器（代数 `gen_` 防串台）。睡眠中收到事件先 `wake` 再处理（`queued`）。
- `behave(P, st, t, ctx)`：每帧返回姿态参数目标 `g.p`、视线、情绪、特效、圆角下限 `g.rFloor`；一次性冲量用 `ctx.once`；跳跃 `ctx.hop`（先预备下蹲）；整圈旋转 `ctx.spin(±1)`（累加到 `pet.spin`，转完自动归零）。噼啪的工具：`droop(a)` 让尖角朝下耷拉，`seq(t, t0, gap, from, to)` 让五个角依次变化。

## 7. 物理与舞台

- 宿主 `#pet-host` 用 translate 移动；`phys` 记录 x、离地高度 y、速度。
- 拖拽：宿主用弹簧跟随指针（产生滞后）；身体偏向拉长 + 按速度倾斜。
- 松手：抛出速度封顶 → 重力 → 落地按冲击速度给 `sq` 冲量、果冻抖动、色团下压 → 恢复系数 0.34 回弹 → 速度小于阈值站稳。
- 地面阴影是舞台上独立的 div，随高度缩放变淡。
- 主循环只驱动当前角色；舞台离屏（IntersectionObserver）时跳过；dt 夹到 33ms，必要时两次子步。

## 8. 特效图层（`renderFx`）

舞台上的 `#fx-layer`（像素坐标）。锚点 `fxA` 用弹簧滞后跟随头部右上方；Z、汗滴是粒子，生成后独立运动；思考点、感叹号、键帽跟随锚点。所有字形（`glyph`）预先拟合，并备有同点数的小圆点版本用于出现/消失。

## 9. QA 钩子

`window.__pet` 暴露：`state`、`phys`、`pet`、`CHARS`、`eyeFit`、`mouthFit`、`curvePts`、`bspline`、`OMEGA_FIT`、`OMEGA`、`setState(s)`、`mount(key)`、`g2(points)`。`scripts/qa_pet.js` 依赖这些名字，改引擎时保持兼容。

## 10. 新增一个角色

1. 写 `genAll(params)`：保证 G2、参数跟着特征走；先在 Python 里画出各参数极值并检查曲率（外凸角色 ρ>0，无拐点）。
2. 选 K、c、λ：网格搜索「曲率不变号（或等于设计值）」前提下误差最小、K 最少的组合；报告误差和角半径。
3. 定脸：白色简单形，按身体大小放大；跑「五官在体内」检查，尤其是融化 / 压扁形。
4. 写 `behave` 里的性格分支和 `FACE` 表情映射。
5. 跑 `qa_pet.js`，读截图，再更新页面文案、README 和迪士尼对照表。
