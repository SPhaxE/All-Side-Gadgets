# 验收清单

自动部分：`node .claude/skills/ip-to-desktop-pet/scripts/qa_pet.js <页面.html> [截图目录]`（放后台跑）。它覆盖报错、G2、下眼睑、圆角、五官包含、抛落轨迹、手机宽度和性能；任一不过退出码为 1。

自动检查只说明「没坏」，以下必须看图（Read 截图）：

| 看什么 | 怎么做 | 通过标准 |
|---|---|---|
| 复刻像不像 | 原图 \| 复刻 \| 50% 混合三联图；嘴、眼按原分辨率放大单独比 | 轮廓、眼、嘴重合；嘴的臂粗、洞形一致 |
| 剪影是否可分 | 各角色静止形纯黑填充，48px 并排 | 不看脸和颜色也能认出 |
| 外形联动 | 每个状态稳定后截一张，按角色排成两行 | 不看脸也能分辨状态（角翘起 / 耷拉 / 变尖 / 侧躺…） |
| 参数与锚点 | 把每个姿态参数扫到极值，画出轮廓并标锚点（起点加粗） | 同一编号锚点始终落在同一特征上（角、尖角）；轮廓无拐点或拐点数等于设计值 |
| 表情过渡 | 状态切换后每 60～120ms 截一帧做胶片 | 眼嘴是形变过去的，不是换图或缩放；任何帧无尖点 |
| 填色互动 | 远 / 近指针、点击后一帧、拖拽中、落地帧，各一对截图 | 每对之间体内颜色有肉眼可见差异 |
| 特效滞后 | 让宠物从高处落下，逐帧读特效路径相对宿主的偏移 | 偏移先变大再回到静止值 |
| 抗锯齿 | 1× 设备像素比截图，边缘放大 4 倍（最近邻） | 边缘有半透明过渡、无台阶 |
| 分享页 | 390×844 深浅色 + 桌面各一张 | 一屏内；名字、性格、实时心情、角色切换、手势提示都在，层次靠版式 |

数值参考（本项目最终版）：ω 拟合偏差约 0.5（全部来自中缝倒圆）；身体拟合误差 小橙 0.66 / 噼啪 1.56；小橙所有状态曲率变号 0，噼啪恒为 10；噼啪生气时最小曲率半径约 3.3。

另外要看的：曲率梳（每个状态各一张，外凸角色梳齿全朝外）、登场 / 旋转 / 睡姿的参数轨迹（`rot`、`ext` 逐帧打印，确认真的转了、依次升起了）。

回复用户时按他们的反馈逐条说明「改了什么、在哪里看」，附关键数字，并把有意的取舍（例如中缝倒圆、教程复刻保留 G1 圆角矩形）写清楚。
